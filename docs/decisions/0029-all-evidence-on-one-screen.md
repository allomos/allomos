## 说明

一个任务做完、等人检查时，人要判断"能不能放行"。现在要的东西分散在任务面板的好几处：检查步骤在最上面，风险和理由在字段表里，AI 决定在下面一节，提交和合并在「链接」一节，测试结果只写在描述的 **Evidence** 段落里（每个代理写法不一样），截图只在 AI 决定里写一个本机路径（换一台电脑就打不开）。人要上下翻、打开描述、自己去找截图，才拼得出一张完整的图。

这个决定定下：一屏放什么、按什么顺序、每样从哪里取。原则是**只用代理交来的数据和项目自己的 git**：任务袋里的记录（代理用 `alm` 写下的）、任务记下的链接所指的提交（在项目自己的 git 里只读）。不去读代理应用自己的文件（会话记录等）。

## 决定

1. **一个「证据」一屏。** 在「待你处理」窗口右边、以及一个待检查任务的任务面板里，最上面是「证据」一屏：不用翻、不用打开别的地方，就能决定放行还是退回。其余记录照 0025 收在下面。
2. **一屏里的顺序**，从上到下（没有的那一样不显示，不留空栏）：
   1. **要你做什么**（0028 的那一句）和**风险**：等级和代理写的一句理由（0027）；没分级的写"未分级"。
   2. **检查步骤**：要几分钟、哪一步最要紧（现有的人工检查步骤）。跳过人工检查完成的，写明理由（现有的例外记录）。
   3. **改动摘要**：交接说明的第一句（0025 要求它是给人看的话）；下面是任务记下的提交和合并，每个一行（提交说明的第一行），合起来改了哪些文件、各加减几行。
   4. **测试结果**：每项检查一行：名字、通过 / 没通过 / 没跑。没通过和没跑的排在前面，标出颜色。没通过的那一行下面是它的截图（第 6 条）。代理没交测试结果的任务（第 5 条之前的旧任务），这一栏显示"代理没有交测试结果，见描述的 Evidence"，并给一个跳到那里的链接。
   5. **待审的 AI 决定**：只列要审的两种（用户看得到的、实现方法的原理，0025）；"其他细节"只写条数，点开才看。
   6. **交接说明**全文，默认收起。
3. **改动摘要从项目自己的 git 只读取。** 应用按任务记下的 `commit` / `merge` 链接，在项目文件夹的 git 里读提交说明和改动的文件、行数（只读，不 fetch，不写；和「接手…」读原工作树的做法一样）。提交在这台电脑上找不到时，只列链接，写"这台电脑上没有这个提交"。不另存一份到任务袋。
4. **`alm` 也给出同一屏的文字版**：`alm show <id> --evidence`（或同样意思的输出）按第 2 条的顺序列出，代理和人看到的一样。这只改 `alm` 的输出：缺了哪一样只说"没有"，不拒绝、不判断。
5. **测试结果记成结构化的记录**（改数据格式，在此批准）。代理用一条新命令记下每项检查，例如 `alm check-result <id> --name "<检查>" --result pass|fail|not-run [--detail "<一句话>"]`。像 `traces` 一样只记在任务的历史里（一个新的事件变更），`task.json` 不加字段。同一个名字再记一次就以最后一次为准。AGENTS.md 的"报告 PASS / FAIL / NOT RUN"规则改成用这条命令记（改共享规则，H6）。
6. **只有测试没通过时才交截图，一个任务最多 3 张**（改数据格式、任务袋变大，在此批准）。截图跟着一条没通过的测试结果交上来，例如 `alm check-result <id> --name "<检查>" --result fail --screenshot <文件>`（可以给几次）。`alm` 把文件复制到任务旁边（`tasks/<id>/evidence/`），在那条测试结果的历史里记下文件名。这样换一台电脑、在网页和手机上也看得到。
   - `alm` 拒绝：`--screenshot` 跟着 `pass` 或 `not-run`；一个任务的第 4 张截图（先说已有哪 3 张）；不是 PNG / JPEG / WebP 的文件；一张超过 2 MB 的（说怎么缩小）。这几条是 `alm` 多做的检查（0027 的 H7），批准者在此批准。
   - 测试都通过的任务没有截图；"用户看得到的" AI 决定照旧可以写截图的本机路径（AGENTS.md），不放进任务袋。

## 不在这里定的

- 一次批准多条、附理由退回：`A01-lily020`（它的「退回」按钮会放在这一屏的底部，由它定）。
- 手机上的证据一屏：和手机上的队列（`A04-swan575`）一起另定；第 6 条的截图放进任务袋，就是为了以后手机也能看到。
- 让 `alm` 判断证据"够不够"（例如没测试结果就不让完成）：那是 `alm` 多做的检查，要另外批准，这里不做。

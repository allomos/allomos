Main set · Switch between AI agents

Claude runs out. Codex picks up.

  • A seabag in your repo. Tasks, proven steps and handoff notes live as readable files in .fliphopper/seabag/, versioned by your own Git, not inside one agent's memory or one account.
  • The same commands for every agent. Claude Code, Codex and others claim, update and release tasks through the fliphopper command and MCP.
  • Resume in one step. A new session asks for the next task and gets its step and the last handoff note.
  • Start or reopen a session in the agent you choose, straight from the task.

Set 2 · AI skills

Get better at working with agents.

  • Learn each agent. What Claude Code and Codex are each good at, and how to set one up for your project.
  • Switch cleanly. What to hand over when a task moves to another agent or account.
  • Run the vibe-coding process. One task per outcome, a working copy per session, proven steps, and your approval before anything leaves your machine.

Set 3 · Progress management

Know where it stands and when it lands.

  • Progress by area, with each task's proven step.
  • Waiting on you. The decisions only you can make, with the evidence.
  • A finish date, honestly. From your real pace: the date you have a 50% chance of hitting, and the date you have an 85% chance of hitting.

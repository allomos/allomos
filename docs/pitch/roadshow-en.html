01 · Manage your project while vibe coding

The board your agents keep up to date.

  • A seabag in your repo. Tasks live as readable files in .fliphopper/seabag/, versioned by your own Git.
  • Agents report as they work. Claude Code and Codex claim, update and finish tasks through the fliphopper command and MCP.
  • Progress you can trust. Each task climbs proven steps, and only you mark it done.
  • A finish date, honestly. From your team's real pace: the date you have a 50% chance of hitting, and the date you have an 85% chance of hitting.
  • Start or reopen an agent on any task, straight from the app.

How it works

Plain files, real Git, one hub.

  • Seabag: readable JSON and Markdown in .fliphopper/seabag/, inside your repository.
  • Your Git: commit, push and pull run your own git, with your keys and hooks.
  • One set of rules: the app, the command line and MCP all go through the same checks and history.

01 · 一边 Vibe Coding，一边管好项目

看板由智能体自己来更新

  • 任务箱就放在你的代码仓库里。任务是 .glidebox/ 下的普通文本文件，用你自己的 Git 管理版本。
  • 智能体干活时顺手汇报。Claude Code 和 Codex 通过 glidebox 命令或 MCP 认领任务、更新进度、标记完成。
  • 进度经得起推敲。每个任务都要一级一级通过验证，最后由你亲自确认完成。
  • 交付日期有据可依。燃尽图按团队的真实速度给出两个日期：有五成把握的，和有八成五把握的。
  • 一键启动智能体。在应用里就能为任意任务开启智能体，或回到之前的会话。

02 · 随时随地工作

电脑前、浏览器里、手机上，进度随时掌握

  • 桌面应用是核心。功能最全，数据存在自己电脑上，断网也能用。
  • 浏览器、手机随时查看。不论在家还是在外，都能连上正在运行的桌面应用。
  • 审批不必守在电脑前。“等我处理”把需要你拍板的事项连同依据一起列出来。
  • 配对简单又安全。输入邮箱，桌面端同意后会发来一次性验证码。

03 · 团队协作

一个项目，几位队友，一群智能体

需要多人协作时，把项目放上云端：用邮箱邀请队友，给每人分配角色，所有改动实时同步。大家同时修改时会像 Git 一样自动合并，真正冲突的地方会清楚标出来，不会悄悄丢失。

工作原理

普通文件 + 真正的 Git + 一个核心应用

  • 任务箱：仓库里 .glidebox/ 目录下可以直接阅读的 JSON 和 Markdown 文件。
  • 用你自己的 Git：提交、推送、拉取都调用本机的 git，沿用你的密钥和钩子。
  • 一套规则管到底：应用、命令行和 MCP 走同一套校验，留下同一份历史。

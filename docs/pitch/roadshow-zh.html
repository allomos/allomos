主线 · 在 AI 智能体之间切换

Claude 额度用完，Codex 接着干

  • 任务包就放在你的代码仓库里。任务、验证阶段和交接笔记都是 .allomos/taskbag/ 下的普通文本文件，用你自己的 Git 管理版本，不锁在某个智能体的记忆或某个账号里。
  • 所有智能体用同一套命令。Claude Code、Codex 等通过 alm 命令或 MCP 认领、更新、释放任务。
  • 一步接手。新会话领取下一项任务时，就能拿到它的验证阶段和上一条交接笔记。
  • 一键启动智能体。从任务出发，在你选的智能体里开启新会话，或回到之前的会话。

第 2 组 · AI 技能

和智能体合作，越做越好

  • 了解每个智能体。Claude Code 和 Codex 各自擅长什么，怎样为你的项目把它配置好。
  • 干净利落地切换。任务换到另一个智能体或账号时，该交接哪些东西。
  • 把 Vibe Coding 流程跑顺。一个成果一张任务卡，每个会话一份独立的工作副本，一级一级地验证，任何东西离开你的电脑前都要你同意。
  • 提升产出质量。为每个任务选合适的模型和推理强度，有风险的改动再请人复查一遍。

第 3 组 · 进度管理

走到哪了，何时落地，一目了然

  • 按领域看进度，每个任务处在哪一级验证都清清楚楚。
  • 等你处理。只有你能拍板的事项，连同依据一起列出来。
  • 交付日期有据可依。按真实速度给出两个日期：有五成把握的，和有八成五把握的。
  • 随时随地。在电脑前、浏览器里或手机上，连上你的桌面应用就能看。

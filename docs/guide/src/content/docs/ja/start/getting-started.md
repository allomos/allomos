このページでは、はじめてアプリを開いてから、AI エージェントがタスクバッグを使って働きはじめるまでを案内します。5 分ほどで終わります。

## 1. アプリを手に入れる

[リリースページ](https://github.com/mypals-ml/allomos/releases/latest)から最新版をダウンロードします。

- **macOS**（Apple シリコンの Mac：M1 以降）：`Allomos_<バージョン>_aarch64.dmg`。開いて、Allomos を「アプリケーション」にドラッグします。
- **Windows**：`Allomos_<バージョン>_x64-setup.exe`。実行するだけです。管理者の権限はいりません。`alm` コマンドも一緒に入ります。

バージョン 1.0 までは署名がないため、はじめてアロモスを開くときにシステムが警告します。

- **macOS** は、アロモスにマルウェアがないか確認できないと表示します。**完了** を選び、**システム設定 › プライバシーとセキュリティ** を開き、下へスクロールして、アロモスの横の **このまま開く** を選びます。
- **Windows** は「Windows によって PC が保護されました」と表示します。**詳細情報** を選び、**実行** を選びます。

macOS では `alm` コマンドは別のダウンロードです：`alm_<バージョン>_macos_arm64.tar.gz`。開いて、`alm` を PATH の通ったフォルダー（たとえば `/usr/local/bin`）に移します。

## 2. はじめる

プロジェクトを開いていないとき、アロモスにはボタンが一つだけ表示されます。**はじめる** を押すと、準備のウィザードが開きます。「ステップ 1／4」のように番号のついた、短い 4 つのステップです。

## 3. タスクバッグを作る

1. **タスクバッグとは？** 最初のステップで数行の説明があります。**フォルダーを選ぶ…** を押して、プロジェクトのフォルダーを選びます。タスクバッグはその中に `.allomos/` として作られます。
2. **タスクバッグのフォルダー。** まだタスクバッグがなければ **タスクバッグを作る** を押します。すでにあれば、アロモスはそう伝えてそれを使います。そのあと **次へ** を押します。

アロモスはタスクバッグを Git に保存するので、履歴が残ります。フォルダーがまだ Git リポジトリでなければ、アロモスがリポジトリにします。コミットするのはタスクバッグ自身のファイルだけで、インターネットには何も送りません。

## 4. プロジェクトのフォルダーを選ぶ

プロジェクトのフォルダーには、コードと、AI エージェントがセッションの始めに読む説明ファイル（`AGENTS.md` と `CLAUDE.md`）があります。ふつうはステップ 3 で選んだのと同じフォルダーです。違うときは **ほかのフォルダーを選ぶ…** を押します。そのあと **次へ** を押します。

## 5. AI エージェントとつなぐ

AI エージェントを一つ選び、**つなぐ** を押します。アロモスはそのエージェントをプロジェクトのフォルダーで開き、依頼文をあらかじめ入力しておきます。**あなたが自分で送るまで、何も送られません。**

依頼文はエージェントに次のことを頼みます。

- `AGENTS.md` と `CLAUDE.md` にアロモスについての短い節を加え、新しいセッションがいつもタスクバッグの使い方を知っているようにする
- タスクボードや ToDo リストなど、プロジェクトがすでに持っているタスクを探す

エージェントがタスクを見つけると、その計画がアロモスに表示されます。**進める** を選ぶとタスクがタスクバッグに移り、**キャンセル** を選ぶと元の場所に残ります。

このステップは **今はしない** で飛ばし、あとで **ファイル › AI エージェントとつなぐ…** から行うこともできます。

:::note
すでに動いているエージェントのセッションは、始まったときにしか `AGENTS.md` と `CLAUDE.md` を読みません。新しいセッションを始めて、エージェントがアロモスを知るようにしてください。
:::

## 6. 仕事を始める

新しいエージェントのセッションで、まず `alm next` を実行するよう頼みます。エージェントは次に取りかかれるタスクと最新の引き継ぎメモを受け取り、タスクを引き受け、進み具合をタスクバッグに書きます。あなたはアロモスのウィンドウで同じタスクを見られます。

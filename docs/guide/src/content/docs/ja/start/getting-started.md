このページでは、はじめてアプリを開いてから、AI エージェントがタスクバッグを使って働きはじめるまでを案内します。5 分ほどで終わります。

## 1. アプリを手に入れる

[リリースページ](https://github.com/allomos/allomos/releases/latest)から最新版をダウンロードします。

- **macOS**（Apple シリコンの Mac：M1 以降）：`Allomos_<バージョン>_aarch64.pkg`。開いてインストーラーに従います。Mac のパスワードを一度たずねられ、「肩代」を「アプリケーション」に入れ、`alm` コマンドも一緒に入れます。（または `Allomos_<バージョン>_aarch64.dmg`：開いて Allomos を「アプリケーション」にドラッグします。そのあと「肩代」が **alm コマンドをインストール** を勧めます。一度クリックし、Mac のパスワードを入力します。以後「肩代」を更新すると `alm` も一緒に更新されます。）
- **Windows**：`Allomos_<バージョン>_x64-setup.exe`。実行するだけです。管理者の権限はいりません。`alm` コマンドも一緒に入ります。

バージョン 1.0 までは署名がないため、はじめて「肩代」を開くときにシステムが警告します。

- **macOS** は、「肩代」（またはそのインストーラー）にマルウェアがないか確認できないと表示します。**完了** を選び、**システム設定 › プライバシーとセキュリティ** を開き、下へスクロールして、「肩代」の横の **このまま開く** を選びます。
- **Windows** は「Windows によって PC が保護されました」と表示します。**詳細情報** を選び、**実行** を選びます。

macOS の `alm` は「肩代」の中にあるものへのリンク（`/usr/local/bin/alm`）なので、「肩代」を更新すると `alm` も更新されます。ほとんどの人には上のインストーラーが合っています。`alm-only` のファイルは `alm` コマンドだけを含み、アプリを入れないコンピューター向けです。インストーラーではありません。

- **macOS**：`alm-only_<バージョン>_macos_arm64.tar.gz`。開いて、`alm` を PATH の通ったフォルダー（たとえば `/usr/local/bin`）に移し、ターミナルから `alm` を実行します。
- **Windows**：`alm-only_<バージョン>_windows_x64.zip`。展開して、`alm.exe` を PATH の通ったフォルダーに置き、ターミナルから `alm` を実行します（ダブルクリックしても、ウィンドウが一瞬開いて閉じるだけです）。

## 2. はじめる

プロジェクトを開いていないとき、「肩代」にはボタンが一つだけ表示されます。**はじめる** を押すと、準備のウィザードが開きます。「ステップ 1／4」のように番号のついた、短い 4 つのステップです。

## 3. タスクバッグを作る

1. **タスクバッグとは？** 最初のステップで数行の説明があります。**フォルダーを選ぶ…** を押して、プロジェクトのフォルダーを選びます。タスクバッグはその中に `.allomos/` として作られます。
2. **タスクバッグのフォルダー。** まだタスクバッグがなければ、**タスクの言語**（AI エージェントがタスクを書く言語。ほかの言語にしないなら「画面に合わせる」のまま）を選んでから **タスクバッグを作る** を押します。すでにあれば、「肩代」はそう伝えてそれを使います。そのあと **次へ** を押します。

「肩代」自身は Git を一切実行しません。最後の手順でつなぐ AI エージェントがタスクバッグを Git に保存するので、履歴が残ります。フォルダーがまだ Git リポジトリでなければ、エージェントがリポジトリにするかどうかをあなたに尋ね、タスクバッグ自身のファイルだけをコミットします。あなたが頼まない限り、インターネットには何も送りません。

## 4. プロジェクトのフォルダーを選ぶ

プロジェクトのフォルダーには、コードと、AI エージェントがセッションの始めに読む説明ファイル（`AGENTS.md` と `CLAUDE.md`）があります。最初のフォルダーは、ふつうステップ 3 で選んだのと同じです。違うときは **変更…** を押します。1 つのタスクバッグで、コード、ウェブサイト、モバイルのリポジトリなど複数のフォルダーを扱えます。それぞれ **別のフォルダを追加…** を押します（あとから設定 → プロジェクトフォルダで追加することもできます）。そのあと **次へ** を押します。

## 5. AI エージェントとつなぐ

AI エージェントを一つ選び、**つなぐ** を押します。「肩代」はそのエージェントをプロジェクトのフォルダーで開き、依頼文をあらかじめ入力しておきます。**あなたが自分で送るまで、何も送られません。**

依頼文はエージェントに次のことを頼みます。

- `AGENTS.md` と `CLAUDE.md` に「肩代」についての短い節を加え、新しいセッションがいつもタスクバッグの使い方を知っているようにする
- タスクボードや ToDo リストなど、プロジェクトがすでに持っているタスクを探す

エージェントがタスクを見つけると、その計画が「肩代」に表示されます。**進める** を選ぶとタスクがタスクバッグに移り、**キャンセル** を選ぶと元の場所に残ります。

このステップは **今はしない** で飛ばし、あとで **ファイル › AI エージェントとつなぐ…** から行うこともできます。

:::note
すでに動いているエージェントのセッションは、始まったときにしか `AGENTS.md` と `CLAUDE.md` を読みません。新しいセッションを始めて、エージェントが「肩代」を知るようにしてください。
:::

## 6. 仕事を始める

新しいエージェントのセッションで、まず `alm next` を実行するよう頼みます。エージェントは次に取りかかれるタスクと最新の引き継ぎメモを受け取り、タスクを引き受け、進み具合をタスクバッグに書きます。あなたは「肩代」のウィンドウで同じタスクを見られます。

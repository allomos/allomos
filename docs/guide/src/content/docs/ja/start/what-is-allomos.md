Claude Code や Codex などの AI エージェントでソフトウェアを作ると、仕事はたくさんのセッションに分かれます。アカウントの使用量が尽きるとセッションは予告なく止まり、次のセッションは何も知らないところから始まります。チームメイトに仕事を渡すときも同じです。

「肩代」は、プロジェクトの状態を、すべてのエージェントとすべての人が読む一か所にまとめます。それが**タスクバッグ**です。

## できること

- **切り替え。** AI エージェントやアカウントから別のものへ、あるいはチームメイトへプロジェクトを渡し、止まったところからそのまま続けます。
- **タスク管理。** バイブコーディングの過程をすべて記録に残します。タスクとその状態はチャットに散らばらず一か所に。人の目で確かめやすく、開発中も何年先の保守も楽になります。
- **AI スキル**（開発中）。使うほどうまくなる、エージェントとの協力のしかた。
- **進捗管理**（開発中）。プロジェクトがどこまで進み、いつ着くかを見ます。

## タスクバッグ

タスクバッグは、プロジェクトの中にあるフォルダー `.allomos/taskbag/` です。中身はただのテキストファイルです。

- **タスク**：何を予定しているか、それぞれ何を達成するか
- 各タスクを**持っている人**：人、またはエージェントのセッション
- 各タスクが**どこまで進んだか**：*implemented*（実装済み）や *locally verified*（ローカルで確認済み）などのラベル
- タスクが**何を待っているか**
- あるセッションが次のセッションに残す**引き継ぎメモ**

リポジトリにあるふつうのファイルなので、Git が履歴を残し、プロジェクトと一緒にどこへでも移ります。

## 誰が、どう使うか

| 誰 | どう使うか |
|---|---|
| あなた | 「肩代」のデスクトップアプリで、領域ごとのタスク、誰が何を持っているか、引き継ぎメモを見ます。 |
| AI エージェント | `alm` コマンドを使います。`alm next` で次のタスクとその引き継ぎメモを受け取り、`alm claim` で引き受け、`alm release` でメモを残して手放します。 |
| チームメイト | 同じリポジトリを開きます。全員が同じタスクを見ます。 |

あるエージェントの使用量が尽きたら、どこで止まったかを書き残します。次のエージェントは、別のアカウントでも別の会社の製品でも、`alm next` で続きから始めます。

## あなたのパソコンでは無料

デスクトップアプリは無料で、アカウントもいりません。共有すると決めない限り、タスクはあなたのリポジトリにとどまります。チーム向けの有料クラウドは予定です。

2026-11-08 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.42)。

## 新しいこと

- **アプリが新しい形でラベルを表示します。** タスク一覧とタスクのパネルに、タスクに付いたすべてのラベルが小さなチップで表示されます。2つの「by human」ラベルは塗りつぶしで表示されます。タスクのパネルの **ラベル → 変更** で、プロジェクトのラベル表にあるすべてのラベルをチェックして付けたり外したりできます。**確認済み** は **locally verified by human** を付けます。エージェントがそのタスクをデプロイして確認済みなら **deployed and verified by human** を付け、ボタンの下にどちらを付けるかが書かれます。**設定 → タスク → ラベル** には、5つの組み込みラベルとそれぞれの意味、その下にプロジェクト独自のラベルがあり、名前の変更、追加、削除ができます。ラベルには順番がないので、古い「進捗のはしご」の設定はなくなりました。
- **「表示」フィルターは表になりました。** タスク一覧の上の **表示** を開くと、状態ごとに1行の表が出ます。行はその状態の色で薄く色分けされます。列は **人が確認済み**（どちらかの「by human」ラベル）と、ほかの各ラベルで、それぞれに「はい」と「いいえ」があります。タスクは、その状態の行のどれか一つのチェックに当てはまれば表示されます。状態の前のチェックはその行のまとめ（全部、一部、なし）で、クリックすると行全体をチェックしたり外したりできます。最初はすべてチェックされていて、すべてのタスクが表示されます。
- **プリセットと「あなたの対応が必要」。** 「表示」フィルターに **プリセット** と **カスタム**（表）の2つのタブができました。プリセットは、すべてのタスク、未完了、着手できる、取りかかり中、あなたの対応が必要、終わったもの です。それぞれ、何をチェックするかと、今何件のタスクが表示されるかを示します。**あなたの対応が必要** は `alm human` と同じタスクを表示します：完了してまだ人が確認していないもの、待機中のすべて、確認待ちの AI の判断があるタスクです。プリセットは「カスタム」のチェックを設定するだけで、そこで一つでも変えるとそのプリセットではなくなります。自動監視の実行であなたの対応が必要なことが残ると、**準備完了のタスクを自動で監視** の横の行の最後に「あなたの対応が必要 K 件」と出ます。クリックすると「あなたの対応が必要」が選ばれます。

## 直したこと

- **「表示」フィルターを開いてもウィンドウが固まらなくなりました。** 0.1.41 では、形式 `allomos/7` のタスクバッグで **表示** を開くと、ウィンドウが真っ白になって反応しなくなり、「肩代」を終了して開き直すしかありませんでした。今はパネルがすぐに開きます。
- **どの組み込みラベルにも意味があります。** タスクバッグを `allomos/7` に更新したあと、3つの組み込みラベルの意味が `alm labels` とラベル表で空になることがありました。今は組み込みの意味が表示されます。

2026-10-23 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.21)。

## 新しいこと

- **引き継ぎはタスクに書きます。** `alm handoff <id>` は、どこで止まったか、次の一歩、誰を待っているかをタスクの引き継ぎメモに書き、二度実行してはいけない操作を説明の Evidence の下に加え、誰が引き継いだかをタスクの履歴に残します。次のセッションは `alm next` や `alm show` で読めるので、引き継ぎが別のファイルの中で古くなることはありません。
- **引き継ぎファイルはなくなりました。** 「引き継ぎ」タブ、タスクパネルの「最新の引き継ぎ」、検索の引き継ぎファイルはなくなり、タスクの引き継ぎメモは残ります。**引き継ぎの設定…** は「ファイル」メニューに移りました。古い `handoffs/` フォルダーが残っているタスクバッグでは **タスクバッグを更新…** が表示され、まだ役に立つ内容を各タスクに移してフォルダーを削除するようエージェントに頼みます。
- **計画の前にファイルの大きさを確かめるよう促します。** `alm claim` のあとと `alm guide workflow` で、変更するファイルが大きすぎないかを確かめ、大きすぎるときは触る部分だけのリファクタリングを計画するようエージェントに促します。

2026-10-27 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.27)。

## 新しいこと

- **タスクバッグを好きな言語に翻訳できます。** タスクバッグの設定の **タスク** に **タスクバッグを翻訳…** が加わりました。言語（アプリの表示言語に限らず、どの言語でも）と AI エージェントを選ぶと、エージェントがすべてのタスク、カードファイル、引き継ぎメモをその言語で書き直し、タスクの言語をその言語にします。いつもの進行状況のポップアップで、どこまで進んだかがわかります。
- **翻訳のチェックボックスが言語メニューになりました。** **タスクバッグを更新** のダイアログとセットアップウィザードのステップ 4 で、翻訳のチェックボックスが言語メニューに変わり、最初は **翻訳しない** になっています。言語を選ぶと、エージェントが同じ実行の中でタスクバッグの内容をその言語に翻訳し、タスクの言語もその言語にします。
- **ウィザードでタスクバッグを作るときにタスクの言語を選べます。** セットアップウィザードで新しいタスクバッグを作るとき、ステップ 2 で、AI エージェントがタスクを書く言語を **タスクバッグを作る** の前に選べます。
- **ウィザードで1つのタスクバッグに複数のプロジェクトフォルダをつなげます。** セットアップウィザードのステップ 3 で、2つ以上のプロジェクトフォルダをタスクバッグにつなげられるようになりました。
- **タスクパネルの上からセッションを開けます。** タスクにセッションが記録されていると、**Claude で開く** または **ターミナルで再開** のボタンが、タイトルの下の行の右端、**確認済み** の隣にも表示されます。セッションの行までスクロールしなくても開けます。

## 直したこと

- **ダイアログで、チェックボックスとその文字が1行に並ぶようになりました。** たとえば **ネットワーク上のデバイス** の **ネットワーク上のデバイスに表示を許可** です。

## そのほか

- タスクバッグの設定の **プロジェクトフォルダ** に、1つのタスクバッグで多くのフォルダを扱えることが書かれ、ボタンは **プロジェクトフォルダを追加…**、フォルダを1つ追加した後は **別のフォルダを追加…** になりました。

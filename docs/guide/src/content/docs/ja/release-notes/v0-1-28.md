2026-10-27 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.28)。

## 新しいこと

- **セッションのボタンがタスクのタイトルに移りました。** タスクにセッションが記録されていると、**Claude で開く** または **ターミナルで再開** のボタンが、タイトルの下の行ではなく、タイトルの **変更** ボタンの後ろに表示されます。タイトルの下の行は、0.1.27 より前と同じく人による確認だけになりました。セッションの行のボタンはそのまま残ります。

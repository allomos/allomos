2026-11-16 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.66)。

## 新しいこと

- **一つのタスクを編集したときの更新が速くなりました。** タスクの状態、タイトル、説明などを変えると、「肩代」はそのタスクと影響を受ける部分をその場で更新します。このプロジェクトのタスクバッグでは、一回の変更が以前の約二秒から約四分の一秒になりました。

## 直したこと

- **準備完了タスクを自動で見守るエージェントの設定が見つけやすくなりました。** エージェントを選ぶと、その案内と設定がリスト内のそのエージェントのすぐ下に出ます。選んでいないときは表示されません。

## そのほか

- Git がこの Mac の Claude 作業用ファイルを無視するようになりました。

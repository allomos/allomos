2026-11-12 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.59)。

## 新しいこと

- **実行中のモニターを1つのダイアログで編集します。** **モニターを編集…** ダイアログで、スコープとモードも変更できます。自動モニターの欄では、各モニターを折りたためるパネルで表示します。`alm monitor set` でも、コマンドラインから同じように変更できます。
- **実行中に別のモニターを開始できます。** モニターの実行中は、そのボタンが **開始** ではなく **別のモニターを開始…** と表示されます。

## 直したこと

- **引き継ぎで未プッシュの作業を失いません。** 引き継ぎ時に、前のワークツリーでまだプッシュしていない内容をコミットしてプッシュできるようになりました。何も失われません。

## そのほか

- 決定 0023 で、Allomos がエージェントを完全自動で編成してよいことを記録しました。計画の非目標からは外しました。

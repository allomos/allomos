公開日： 2026-11-20. [GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.79).

## 新しいこと

- **複数のタスクをまとめて承認できます。** `alm checked` と `alm reviewed` は複数のタスク ID を受け付けます。ひとつでも記録できないものがあれば、どれも記録せず、どれがなぜだめかを伝えます。確認が通らなかったときは `alm reopen` を案内します。
- **共有していない変更の通知がわかりやすく。** アプリで直接した変更をひとまとめにし、同じ項目への変更は一つにまとめて表示します。通知が出る理由と、エージェントに共有を頼むと何が起きるかも短く説明します。

## 直したこと

- **済んだセッションをモニターが表示し続けなくなりました。** もう一度割り当てられたタスクや完了したタスクは「始まらなかったセッション」に残らず、別の日の時刻には日付も付きます。

2026-11-24 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.81)。

## 新しいこと

- **監視パネルのどのタスク ID からも詳細を開けます。** 監視パネルに表示される既存のタスク ID はすべてクリックでき、そのタスクの詳細を直接開けるようになりました。

## 直したこと

- **サイレント実行の Antigravity の権限ルールとハートビート案内を修正しました。** サイレント監視中の Antigravity セッションにおけるプッシュ・拒否ルール、タスクバッグの許可ルール、およびハートビートの案内を修正し、許可されたプッシュやタスクバッグ更新が誤って止まらないようにしました。
- **承認待ちマークはセッション自身のタブが開いている間だけ有効になりました。** 監視中の Antigravity ターミナルタブが閉じられたあと、別のセッションに確認マークが誤って引き継がれなくなり、閉じたセッションは承認待ちを解除して通常の失効ルールで引き継がれ、終了時に別セッションのマークを消すこともなくなりました。

2026-11-09 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.49)。

## 新しいこと

- **動いている監視を一か所に。** タブバーの **監視** ボタンと、ウィンドウメニューの **実行中の監視** が、このコンピューターで動いているすべての監視を並べます。それぞれに **開く**、**↻ 今すぐ確認**、**■ 停止** があります。
- **アプリなしで監視。** `alm monitor start`、`alm monitor check`、`alm monitor stop`、`alm monitor status`、`alm monitor list` は、アプリを閉じていても使えます。alm で開始した監視はアプリを開いていればステータスバーに表示され、アプリから今すぐ確認や停止もできます。`alm monitor list` はどのフォルダーからでも使え、このコンピューターの実行を一覧します。
- **エージェントごとに複数のセッション。** 1 つのエージェントが、準備完了のタスクの監視で同時に複数のセッションを持てます。各セッションは先に自分のタスクを引き受けます。
- **エージェントごとの難易度の範囲。** **準備完了のタスクを自動で監視** で、エージェントごとに難易度の範囲を決められます。既定は 1 から 5 です。

- **止まったタスクを引き継げます。** セッションが応答しなくなったタスク（アカウントの上限に達した、切り替えた場合）は「失われた」タスクです。準備完了のタスクを先に扱い、次に **準備完了のタスクを自動で監視** が失われたタスクを新しいセッションに渡します。タスクのペインは、タスクが失われているときだけ **開く** の隣に **引き継ぐ…** を出し、エージェントを選ぶダイアログを開きます。`alm claim` でも失われたタスクを引き継げます。

## 直したこと

- **監視の「待っています」通知はアプリの名前で出ます。** この通知はスクリプトエディターではなく、Allomos 自身から出ます。
- **ステータスバーの高さがそろいます。** リンクとボタンがバーの中央の行に並びます。

## その他

- 監視のセッション、タブ、通知、依頼の文言が、コードの共有部分にまとまりました。「肩代」アプリと alm が同じ方法で監視を動かします。

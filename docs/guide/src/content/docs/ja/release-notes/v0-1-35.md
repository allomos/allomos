2026-11-02 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.35)。

## 新しいこと

- **状態ごとに、より鮮やかな専用の色が付きました**。バックログは茶、準備完了は青、進行中は緑、待機中は黄、ブロック中は赤、完了は紫、中止は灰色で取り消し線付きです。ライトモードでもダークモードでも同じです。
- **状態の言葉は、同じ色の淡い背景に太字で載った小さなラベルになりました**。タスクの行でも詳細パネルでも同じで、状態をひと目で見分けられます。「表示」フィルターと「待っているもの」「ブロック元」の説明は、色だけで背景は付きません。

## 直したこと

- **`alm` がエージェントに使用量の報告を促すとき、示すコマンドにはエージェント**（`claude-code`、`codex`）**が入るようになりました**。セッションの名前ではありません。そのとおりに実行したエージェントがセッションをエージェントとして報告することはなくなり、アプリ上部の「AI エージェント：」の欄に loop-hourly のような灰色の項目が増えることもなくなりました。

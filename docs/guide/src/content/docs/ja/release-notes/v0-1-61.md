2026-11-15 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.61)。

## 新しいこと

- **ブロック中は状態ではなくなりました。** 先行タスクを設定してもタスクの状態は変わりません。先行タスクが終わっていない間、一覧とタスクパネルには「準備完了 · ブロック中」のように表示され、先行タスクが終わるとタスクは元の状態のままです。フィルターメニューに **ブロック中のタスクだけ** が加わりました。以前のバージョンのタスクバッグは先に更新が必要です（**タスクバッグを更新…**）。ブロック中だったタスクは、ブロック前の状態に戻ります。
- **並べ替えメニューで依存ツリーを表示できます。** **表示 › 依存ツリー** で、各タスクをそれをブロックしているタスクの下に、ガイド線付き・折りたたみ可能なツリーで表示します。ツリー同士と同じ親の下のタスクは、選んだ並べ替えのままです。複数の先行タスクがあるタスクは一度だけ表示し、ほかに何に依存しているかを添えます。
- **AI の決定が 3 種類に分かれました。** `alm ai-decided --kind` で、利用者が目にすること・作り方の考え方・細部のどれかとして記録します。前の 2 つはこれまでどおり **レビュー待ちの AI の決定** に入り、細部はタスクの中に記録され、タスクパネルの専用の欄で読めますが、レビューは求めません。

## そのほか

- 決定 0026 で、ブロック中を先行タスクから求めることを記録しました。決定 0027 で、何を高リスクとみなすか、リスクはエージェントが決めることを記録しました。
- 共有のエージェントルール（AGENTS.md セクション v38）とガイドを新しいブロックの規則に合わせました。

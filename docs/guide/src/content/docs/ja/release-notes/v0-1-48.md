2026-11-09 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.48)。

## 新しいこと

- **複数のエージェントを同時に。** **準備完了のタスクを自動で監視** の **エージェント** がチェックボックスになり、1 つでも複数でも選べます（無人で動かせないエージェントには理由が表示されます）。選んだエージェントはそれぞれ、準備完了のタスクを一度に 1 つ、自分のセッションで進めます。各セッションが先にタスクを引き受けるので、同じタスクを 2 つで進めることはありません。状態バーには各セッションがリンクつきで並び、そのメニューでエージェントを加えたり外したりできます。加えたエージェントは次の確認からタスクを受け取り、外したエージェントは作業中のタスクを終えたあと、もう受け取りません。**■ 停止**、**↻ 今すぐ確認**、確認の頻度はすべてのエージェントに効きます。
- **監視からの通知。** macOS では、タスクのセッションがあなたへの質問を保留にしたとき、**準備完了のタスクを自動で監視** がシステム通知を送ります。準備完了のタスクがないときも一度送ります。
- **難易度。** すべてのタスクに、追加したエージェントが判断した **1 · とても易しい** から **5 · とても難しい** までの難易度がつきます。難易度のないタスクは 3 として扱います。タスクの行とタスクのペインに表示され（既定値は灰色）、ペインで変えられます。alm では `alm add task --difficulty <1-5>`、`alm difficulty <id> <1-5>`（または `--none`）、一部のレベルだけを挙げる `alm next` / `alm list --difficulty 1-3`。古い「肩代」はこの項目をそのまま残します。
- **静かなモードは止まって尋ねません。** 共有ルール（alm が AGENTS.md に書く第 v34 節）と各ガイドに、次のことが書かれました。静かな実行では、言葉づかいと見た目はエージェントが自分で決めて作り、マージし、選んだことを `alm ai-decided` でレビュー用に記録します。承認者に先に尋ねるのは、データ形式、ものを消すこと、権限とセキュリティ、費用、外部への影響、計画の変更だけです。質問は計画のときにします。保留にした質問にはエージェントの提案をつけます。終わった作業は先にマージするので、保留の質問に止められません。

## 直したこと

- **タスクのペインは上端を見せたままスクロールします。** 長いタスクをスクロールしても、ペインの上端はいちばん上に残り、閉じるボタンと戻る矢印には見える枠がつきました。スマートフォン幅のウィンドウでは、ペインが画面の高さいっぱいになり、長いタスクもスクロールできます。

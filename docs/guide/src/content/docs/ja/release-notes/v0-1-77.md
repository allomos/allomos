## 新機能

- **チェックごとの結果を 1 行ずつ。** エージェントは実行した各チェックを成功・失敗・未実行として記録し、「エビデンス」画面では失敗と未実行を先頭に一覧します。
- **失敗したチェックのスクリーンショット。** エージェントは失敗したチェックに最大 3 枚のスクリーンショットを添付できます。「エビデンス」画面ではそのチェックの下にサムネイルを表示し、クリックすると大きく表示します。タスクバッグに保存されるので、別のコンピューターでも見られます。
- **ターミナルでエビデンスを確認。** `alm show <id> --evidence` は「エビデンス」画面と同じ内容を同じ順序で表示します。
- **止まったタスクをモニターから再投入。** モニターを再起動せずに、止まったタスクを 1 つキューに戻せます。ほかのタスクはそのまま続きます。

2026-11-02 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.34)。

## 新しいこと

- **タスク一覧の上の「表示」フィルターが、状態とラベルの 2 つのグループに分かれたチェックのパネルになりました。** 最初はすべてにチェックが入っていて、すべてのタスクが表示されます。チェックを外すと、そのタスクが隠れます。いくつもの状態を同時に表示できるようになりました。
- **ラベルごとに「はい」と「いいえ」があります**。「はい」はそのラベル以上に達したタスク、「いいえ」はまだ達していないタスクです。たとえば「人が確認済み」の「はい」を外すと、人がまだ確認していないタスクだけが見えます。
- **グループごとに「すべて選択」と「選択をすべて解除」があり、フィルターの横の ↻ ですべてのタスクがまた表示されます。** 使えないボタンは消えずに灰色になります。チェックの結果、一覧が空になるときは、パネルにその理由が出ます。

## そのほか

- **フィルターにあった「すべての状態」「未完了」「人の対応が必要」はなくなりました**。チェックで同じことができます。以前に選んでいた状態は、その状態だけにチェックが入った形で戻ります。

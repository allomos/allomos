2026-11-27 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.84)。

## 直したこと

- **新規タスクの承認が既定でオンになりました。** 未設定のプロジェクトでは、エージェントが作成したタスクが承認されるまでバックログに残ります。オフにした場合も明示的に保存され、設定を開き直してもオフのまま保たれます。
- **タスクバッグ設定のスクロールを見やすくしました。** 高さの低いウィンドウでは本文に細いスクロールバーと右余白を設けて文字が隠れないようにし、幅の狭いウィンドウではカテゴリ欄を横スクロールにして本文の縦スペースを確保しました。

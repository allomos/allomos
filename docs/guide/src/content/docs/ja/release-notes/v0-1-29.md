## 新しいこと

- **リリース後にインストールするかどうかを選べます。** 会話に `alm guide github release` と書くと、AI エージェントはリリースを公開して確かめたところで止まります。このコンピューターにダウンロードしてインストールするのは、`install` を付けたとき（`alm guide github release install`。`minor` や `major` とも組み合わせられます）だけです。`no install` はもう要りません。

公開日： 2026-11-20. [GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.76).

## 新機能

- **タスクの証拠を一か所で確認。** 確認待ちのタスクでは、タスクパネルと「あなたへ」の上部に「エビデンス」を表示します。リスクと必要な操作、確認手順、変更の要約、テストの証拠へのリンク、確認待ちの AI 判断、折りたためる引き継ぎをまとめて読めます。
- **コードの変更内容を表示。** 記録された各コミットやマージの説明の先頭行と、変更されたファイルごとの追加・削除行数を表示します。ローカルの Git 履歴だけを読み、このコンピューターにないコミットはリンクを残してその旨を示します。

2026-10-22 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.20)。

## 新しいこと

- **イテレーションに状態がつきます。** イテレーションは計画中・進行中・終了のどれかで、進行中は同時に最大1つです。新しいタスクは進行中のイテレーションに入り、`alm next` もそれを先頭に出します。進行中のものがないときは、最初の計画中のイテレーションが進行中として扱われます。進行中と終了のイテレーションには、それぞれ専用のバッジと色があり、終了したものはこれまでどおりの灰色です。タスクバッグを開くと、新しい形式（`allomos/5`）に移されます。
- **「表示」フィルターに「未完了」が加わりました。** 完了でも見送りでもないタスクをすべて表示します。「すべての状態」の次にあります。
- **マークの開始アニメーションが短くなりました。** 上部バーと「このアプリについて」で、8秒から3秒になりました。

## 直したこと

- **更新の行と名前の行が1行にまとまりました。** タスク一覧の上で、更新が先、「変更の記録名 …」があとに並び、一覧が少し上から始まります。

## そのほか

- AI エージェントは、承認を会話の中で求めます。`alm confirm` は、Allomos アプリから渡した作業にだけ使います。

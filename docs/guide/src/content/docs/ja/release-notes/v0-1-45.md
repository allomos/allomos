2026-11-09 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.45)。

## 新しいこと

- **設定はひとつのダイアログに。** アプリの設定ウィンドウと各タスクバッグの設定が、プロジェクトウィンドウのひとつのダイアログになりました。左側に 2 つのグループがあります。**Allomos**（**一般**、**このコンピューター**）はこのコンピューター上のアプリ全体に、タブのタスクバッグの名前のグループ（**一般**、**プロジェクトフォルダ**、**エージェント**、**タスク**、**引き継ぎ**、**監査**）はそのタスクバッグを使う全員に共有されます。各項目のいちばん上の行に、どちらのグループかが書いてあります。メニューの **設定…**（Cmd+, / Ctrl+,）は Allomos グループを、タスクバッグの名前の横の **設定** はタスクバッグのグループを開きます。
- **自動アップデートをオフにできます。** 設定 → Allomos → 一般 → **自動アップデート**。最初はオンです。オフにすると、「肩代」は自分から GitHub に新しいバージョンを確かめず、バックグラウンドでのダウンロードもしません。メニューの **アップデートを確認…** は引き続き使えます。
- **外部の証人をオンにできるようになりました。** 設定 → あなたのタスクバッグ → 監査 → **外部のタイムスタンプ証人**。**オンにして指紋を送る** で確認すると、各チェックポイントの指紋（タスクバッグの内容は送りません）をタイムスタンプサービス（RFC 3161）に送り、署名された受領証をチェックポイントに保存します。既定は FreeTSA で、DigiCert、Sectigo、GlobalSign も一覧にあり、利用している事業者のアドレスも入力できます。2 つ目のサービスも選べます。`alm audit` は受領証をそれぞれのチェックポイントと照らし合わせ、1 年以内に期限が切れる受領証を挙げます。オフラインのときは指紋を保存しておき、後のチェックポイントで送ります。alm では `alm audit-settings --witness on|off`。
- **証人がチェックポイントを作る頻度。** 外部のタイムスタンプ証人 → **頻度**：**毎日**（オンにしたときの既定）、**承認と人による確認のたびに**、**指示したときだけ**。alm では `alm audit-settings --witness-when`。
- **監査と規格。** ユーザーガイドに新しい[ページ](/allomos/ja/audit/standards-map/)ができました。「肩代」が常に記録するもの、監査の各設定がすること、ISO/IEC 27001、SOC 2、等保 2.0 などの規格を満たす助けとしてオンにする設定を説明します。監査の設定の **規格ごとに必要な設定を見る** で、ウィンドウの言語のページが開きます。
- **Google Antigravity。** 「肩代」は Antigravity の `agy` コマンドを見つけ、**Antigravity（ターミナル）** として表示します。共有ルールの設定を頼めるほか、**準備完了のタスクを自動で監視** で agy のセッションを始められ、Antigravity の名前で記録されたセッションは `agy --conversation` で開き直し、Antigravity の残量がヘッダーに出ます。

## 直したこと

- **残っていたブロック中のタスクも進みます。** ブロックしていたタスクが 0.1.44 より前にすべて終わっていたタスクは、ブロックされたままでした。これからは `alm next`、**準備完了のタスクを自動で監視** の開始、**↻ 今すぐ確認** でそうしたタスクが進み、監視の状態バーの下の行にどのタスクかが出ます。

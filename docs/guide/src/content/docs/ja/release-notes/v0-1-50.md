2026-11-10 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.50)。

## 新しいこと

- **再起動のあとも監視が続きます。** アプリを再起動・更新したあと（または実行が止まったあとにプロジェクトを開き直したとき）、**準備完了のタスクを自動で監視** はこのコンピューターに保存された設定からそのまま再開し、もう一度開始を押す必要はありません。作業中のセッションはステータスバーにそのまま表示され、完了後の 30 秒のタブ閉じカウントダウンも最後まで動き、アプリを閉じている間に終わった実行も「前回の実行」に数えられます。
- **監視でエージェントごとに複数のアカウント。** **準備完了のタスクを自動で監視** で、Claude Code と Codex に追加のアカウントを登録できます。アカウントごとに 1 行ずつ並び、セッション数と難易度の範囲を別々に設定でき、そのアカウントのフォルダーでセッションを起動します。
- **監視中の再起動・終了の前に確認が出ます。** 監視が動いているときに「再起動して更新」または終了を選ぶと、自動監視がバックグラウンドで動き続けることと、開いている何個のセッションがそのままタスクを終えるかを知らせる確認が出ます。キャンセルもできます。
- **Antigravity の接続で依頼を直接 `agy` に渡します。** Google Antigravity を接続するとき、依頼をクリップボード経由ではなくコマンドラインで直接 `agy` に渡すようになりました。

## 直したこと

- **押せない「開始」ボタンが灰色になります。** **準備完了のタスクを自動で監視** でエージェントが 1 つも選ばれていないとき、**開始** ボタン（および他の無効な主ボタン）が灰色で表示されます。

## その他

- **Running Monitors**（実行中の監視）がウィンドウメニューから表示メニューに移り、実行中の監視ダイアログの下部にあった案内文がなくなりました。

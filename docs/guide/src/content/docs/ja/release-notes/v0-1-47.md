2026-11-09 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.47)。

## 新しいこと

- **「肩代」の Codex 用ルール。** **準備完了のタスクを自動で監視** で Codex を選ぶと、ダイアログに **Codex が Git と alm を尋ねずに実行できるようにする** が出ます（最初からチェック済み）。これは「肩代」の Codex 用ルールファイル（`~/.codex/rules/allomos.rules`）を加えます。無人の各 Codex セッションは尋ねずにプル、コミット、プッシュ、マージし、alm を実行できるようになり、ほかのコマンドはこれまでどおり Codex のサンドボックスの中です。これまでの「Codex にフルアクセスを与える」という案内に代わるものです。**開始** を押すまで何も書かず、押すとファイルを書くか削除して、プロジェクトの履歴に記録します。`default.rules` に書いたあなた自身のルールは変えません。「肩代」のルールが古いとき、またはだれかがファイルを変えたときは、変える前にどのコマンドが加わり、外れるかを示します。新しい「肩代」のファイルはそのままにします。`alm guide codex-rules` はルールを表示し、`alm guide agent-files` には Codex のコンピューターごとに一度の手順が、`alm guide workflow` には Git が作業コピーに書き込めないときの対処があります。

## 直したこと

- **タスクが終わったあとに前のセッションが戻ってきたとき。** 引き継がれたタスクを新しいセッションがすでに終えていた（完了または取り下げ）場合も、前のセッションには、だれが引き継いで終えたかが知らされ、その変更は断られるようになりました。完了または取り下げたタスクへの `alm release` はどのセッションでも断られ、`alm reopen` を案内するので、引き受け手の記録が消えることはなくなりました。

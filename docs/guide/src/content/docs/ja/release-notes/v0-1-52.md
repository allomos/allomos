2026-11-10 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.52)。

## 直したこと

- **エージェントとの接続では Allomos の指示だけを依頼します。** エージェントを接続すると、Allomos は指示ファイル（AGENTS.md と CLAUDE.md）に Allomos の指示を追加するよう依頼するだけになりました。既存のタスクを探す、古いタスクバッグを移す、古くなったファイルを更新する、といった依頼はしなくなりました。それらは **タスクバッグを更新…** で行います。接続パネルのタスク検索の行も出なくなりました。
- **エージェントの行に Antigravity が常に出ます。** エージェントの行は、Claude Code や Codex と同じく Codex の後に Antigravity を並べます。Antigravity がまだ何も報告していなくても表示されます。

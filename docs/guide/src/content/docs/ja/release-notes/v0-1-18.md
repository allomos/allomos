2026-10-22 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.18)。

## 新しいこと

- **Allomos のマークがあいさつします。** ウィンドウを開くと、マークが元の大きさと位置で待機アニメーションを一度だけ見せ、そのあとは静止します。「このアプリについて」も同じです。
- **古い使用量の数字は、改めて報告を求めます。** エージェントの使用量がない、または 30 分より古いとき、`alm claim`・`label`・`release`・`done`・`handoff` が報告を求めます。使用量のチップは、古さを長い分数ではなく時間や日で表します。

## 直したこと

- **「Finder で表示」がタスクバッグのパスの隣に並びます。** ボタンはパスと同じ行、パスのすぐ後ろにあり、エージェントの行は別の行のままです。

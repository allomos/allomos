2026-11-17 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.72)。

## 新しいこと

- **静かなモードの Antigravity セッションが、ブランチを尋ねずにプッシュします。** 監視が静かなモードで開く Antigravity セッションは、`git push origin refs/heads/main` のようにブランチを完全な形で書いた `origin` への普通のプッシュでは止まりません。それ以外のプッシュ（引数なしの `git push`、`git push origin main`、追加のオプション、強制プッシュ、リモートブランチの削除、タグ、組み合わせたコマンド）は引き続き確認を求めます。通常のセッションと Antigravity の設定は変えません。

## 直したこと

- **状態と難易度のメニューが切れなくなりました。** イテレーションや領域の最後のタスクでは、メニューがリストの下端に隠れていました。いまはリストの上に浮かび、下に余白がなければ上向きに開きます。
- **静かなモードの説明が、auto モードは止まらないと約束しなくなりました。** Antigravity の auto モードでも、共有ブランチへのプッシュのような危険な操作や取り消せない操作の前には確認を求めると書いています。

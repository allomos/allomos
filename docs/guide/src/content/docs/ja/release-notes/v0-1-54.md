2026-11-11 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.54)。

## 新しいこと

- **わかりやすくなったスタートページ。** スタートページの 3 つの選択肢、**新しいプロジェクトを作る…**、**既存のプロジェクトを設定する…**、**最近使った項目を開く…** が、カードの中に縦に並びます。それぞれにアイコンと、名前の下に何をするかを伝える 1 行のヒント（例：「前に開いたプロジェクトに戻ります。」）が付きます。カードの下にはもう何も置かず、いつものウィンドウの大きさならスクロールせずに全体が見えます。

2026-11-16 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.67)。

## 新しいこと

- **すべてのブロッカーが一覧に表示されるようになりました。** 未完了のブロッカーがブロック色で先に表示され、完了または取り下げ済みのものが完了色で続きます。タスクパネルも同じ順序です。

## 直したこと

- **Finder から起動した Allomos が Node を必要とするターミナルエージェントを見つけられるようになりました。** Node がシステムの `PATH` にない場合でも、npm でインストールした Codex と Claude Code を検出できます。

## そのほか

- **待機中の情報とブロッカーの情報を同時に表示できます。** 人の対応を待ち、ブロッカーもあるタスクでは、両方の行が表示されます。

2026-10-24 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.23)。

## 新しいこと

- **イテレーションの ID は単語になりました。** ID は `I-` と短い単語（`I-knit`、`I-forge` など）で、計画の順番に見える数字ではなくなりました。`alm add iteration` で ID を省くと未使用のものを選び、`alm rename iteration <旧> <新>` はイテレーションの名前を、そこに計画されたすべてのタスクと一緒に変えます。
- **各イテレーションに順番の番号を表示します。** アプリで、イテレーションの ID の横に計画の中の位置（1、2、3…）が出るので、順番がひと目でわかります。
- **計画の中でイテレーションを移せます。** `alm move iteration <id> --before <id>`（または `--after <id>`）でイテレーションを新しい位置に移します。タスクバッグのファイルを手で直す必要はありません。

## 直したこと

- **見出しの件数が1行に収まります。** エリアやイテレーションの見出しの右にある件数（「142 件中 142 件完了」）が、タスク番号が長くなっても2行に折り返さなくなりました。
- **「タスクバッグを更新」ダイアログがスクロールします。** 古い引き継ぎファイルがたくさん並ぶとき、一覧がスクロールし、ボタンはいつも見えます。
- **バックログ状態の中国語名を「储备」にしました。** 「就绪」（準備完了）と紛らわしくなくなりました。

## そのほか

- AI エージェントはこれまでどおり `alm` で作業します。エージェント向けの MCP サーバーは当面見送ります。

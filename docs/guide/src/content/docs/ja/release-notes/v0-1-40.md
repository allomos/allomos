2026-11-07 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.40)。

## 新しいこと

- **準備完了のタスクを自動で監視。** デスクトップアプリの **▶ 準備完了のタスクを自動で監視**（上のバーと、今のイテレーションのカード）で、あなたがいなくても Allomos が準備完了のタスクを進めます。準備完了のタスクごとにターミナルで新しいエージェントのセッションを一つずつ開き、前のタスクが終わってから次を始めます。準備完了のタスクがないときは、選んだ間隔で待って、また確かめます。どのタスクか（今のイテレーション、準備完了のすべてのタスク、または一つのイテレーション）、エージェント（**Claude Code（ターミナル）** または **Codex（ターミナル）**）、実行モードを選べます。動いている間は状態の行に進めているタスクが出て、**↻ 今すぐ確認**、確認の間隔、**■ 停止**（今のタスクが終わってから止まります）があります。選んだエージェントが権限の確認で止まらずに動けるようにする方法もダイアログに書かれています。Allomos がエージェントの権限を変えることはありません。Claude アプリ、Codex アプリ、手動はまだ選べず、その理由がダイアログに出ます。

## そのほか

- **「続ける…」は「取りかかる…」になりました。** どのセッションも担当していないタスクのボタンと、そのダイアログ（**AI エージェントに取りかかってもらう**）が新しい名前になりました。働きは変わりません。
- **復元したタブは、切り替えたときに読み込まれます。** Allomos を起動し直すと、開いていたタスクバッグのタブはすべて戻りますが、読み込むのは前に出ているタブだけです。ほかのタブは保存されたプロジェクト名を表示し、初めて切り替えたときに読み込まれるので、起動が速くなります。

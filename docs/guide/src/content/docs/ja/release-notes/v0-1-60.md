2026-11-15 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.60)。

## 新しいこと

- **タスクパネルが必要な情報を先に表示します。** タスクの状態に応じて、確認手順・未回答の質問・ブロッカー・引き継ぎメモ・説明のいずれかを先に開き、すべての項目・説明全文・履歴は折りたたみます。
- **ラベルと状態をタスク言語で表示します。** アプリと `alm human` で、ラベルや状態などの固定語をプロジェクトのタスク言語で表示します。
- **プロジェクトウィンドウの上部をすっきりさせました。** 上部の AI エージェント行（クォータ表示、接続状態、未共有の変更の案内）を取り除きました。

## 直したこと

- **日本語・中国語入力の確定 Enter でフォームが保存されなくなりました。** 変換候補を確定する Enter キーで、タスク追加などのフォームが誤って送信される問題を直しました。

## そのほか

- **タグラインを更新しました。** アプリのウェルカム画面、バージョン情報ウィンドウ、Web サイト、ガイドのトップ、README に新しい日英中のタグラインを反映しました。
- 決定 0024 と 0025 で、特定のエージェントに縛られない引き継ぎの方向性と、人にとって読みやすい記録の方針をまとめました。

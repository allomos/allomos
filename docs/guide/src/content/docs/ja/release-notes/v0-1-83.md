## 新しいこと

- **新しいタスクを承認してから着手可能にできます。** 「タスクバッグ設定 → タスク」で新規タスクの承認を有効にすると、エージェントが作成したタスクは承認されるまでバックログに残ります。既定ではオフです。ゴール実行では、ゴール提出時の承認に基づき、エージェントが引き続きタスクを着手可能にできます。ターミナルからは `alm new-task-settings` で設定を確認・変更できます。

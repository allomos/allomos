2026-11-18 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.73)。

## 新しいこと

- **作成日時でタスクを並べ替えられます。** 「イテレーション」と「領域」ビューの並べ替えに「作成日時」が加わり、古い順か新しい順を選べます。依存関係ツリーの子タスクも作成日時順になります。
- **プロジェクトごとにファイルサイズ上限を設定できます。** タスクバッグの設定 →「ファイルサイズ」で上限を確認・変更できます。初期値は 1000 行で、\`alm file-size-settings\` からも同じ値を確認・更新できます。この設定は各プロジェクトが用意するファイルサイズ検査で使います。\`alm\` 自身がファイルを自動計測するわけではありません。

## 直したこと

- **更新日時順でタスクを編集しても、行が移動しません。** 状態や難易度を変えても、一覧での位置が意図せず変わらなくなりました。
- **定期的な動作通知を送っているセッションは、長時間停止として表示されません。** 通知が止まった後は、プロジェクトの失効時間を過ぎると停止として扱われます。
- **Antigravity の起動コマンドが長くても、macOS の Terminal が引用符待ちで止まりません。** 監視セッションは短い一時スクリプトから完全なコマンドを実行します。

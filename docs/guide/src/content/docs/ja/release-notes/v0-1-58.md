2026-11-12 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.58)。

## 新しいこと

- **「引き継ぎの準備…」が「別のエージェントに渡す…」に代わりました。** タスクのタイトルの横のボタンは、短いダイアログを開くようになりました。タスクを担当しているセッションに、引き継ぎメモを書き、作業をコミットして作業ブランチにプッシュし、タスクを手放してから止まるよう頼むプロンプトが出ます。**プロンプトをコピー** でコピーし、**そのセッションを開く** で担当のセッション（Claude アプリかターミナル）を開きます。開くときにもプロンプトはコピーされるので、そこに貼り付けて送るだけです。ダイアログは続ける人を尋ねず、待ち状態も出しません。いつでも閉じられます。タスクが手放されたら、続ける人を **取りかかる…** で始めてください。
- **担当者がいないようなら、そう教えます。** 担当のセッションが一度もハートビートを送っていないか、プロジェクトの時間を過ぎて黙っているときは、ダイアログがそう伝え、**引き継ぐ…** を出します。セッションを開けないとき（たとえば、取りかかったときにセッションが記録されなかった）は、その理由を示し、コピーだけを残します。

## そのほか

- **引き継ぎの準備はタスクバッグを変えません。** タスクに引き継ぎの依頼を書き込まなくなったので、`alm` も「引き継ぎの依頼」のお知らせを出さなくなりました。以前の版が書いた依頼はこれまでどおり読め、タスクに取りかかる、手放す、終える、やめるときに消えます。

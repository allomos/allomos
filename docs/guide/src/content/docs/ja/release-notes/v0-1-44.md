2026-11-08 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.44)。

## 新しいこと

- **監査の設定が一か所にまとまりました。** **プロジェクト設定 → 監査** は上から順に、**常に記録**（履歴にいつも残るもの）、**本人確認**、**職務の分離**、**外部のタイムスタンプ証人**、**個人情報を消去…** のある保存、**変更の種類** と並びます。外部のタイムスタンプ証人にはタスクバッグのチェックポイントと **今すぐチェックポイントを作る** があり、証人のサービスができるまで、そのスイッチは灰色のままです。**個人情報を消去…** は `alm redact` と同じ働きで、訴訟ホールドの間は断られます。変更はどれも履歴に残り、設定を無効にするときは理由を尋ねます。
- **設定 → このコンピューター。** このコンピューターの **署名鍵** と保管場所を表示し、**公開鍵を書き出す…** で公開鍵をファイルに保存できます。**最後に見た履歴** は、プロジェクトごとに、このコンピューターが最後に見たチェックポイントと、それがまだタスクバッグにあるかを示します。**鍵を交換…** は新しい署名鍵を作ります。最近のタスクバッグそれぞれで、古い鍵を署名つきの最後のイベントで退役させ、新しい鍵を加えます。古い鍵で署名した変更は、これからも確かめられます。
- **Windows での変更にも署名がつきます。** Windows では署名鍵を資格情報マネージャーに保管するので、`allomos/8` のタスクバッグには macOS だけでなく Windows からも署名つきの変更が入ります。
- **ブロックされていたタスクがひとりでに進みます。** あるタスクをブロックしていた最後のタスクが完了または取りやめになると（`alm done`、`alm drop`、アプリのボタン）、ブロックされていたタスクは `alm unblock` と同じように準備完了に戻ります（誰かが担当していれば進行中）。引き継ぎメモには、どのブロックが終わったかが書かれます。取りやめになったブロックも、終わったものとして数えます。

2026-10-23 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.22)。

## 新しいこと

- **タスクバッグの更新はバナー一つにまとまりました。** 説明が古い、タスクバッグの形式が古い、カードファイルがタスクバッグの外にある、古い引き継ぎファイルがある、という知らせは、これまでそれぞれ別のバナーでした。今は一つのバナーに理由を1行ずつ並べ、ボタンは **タスクバッグを更新…** 一つだけです。

## 直したこと

- **更新の知らせがメニューと同じになりました。** 新しいバージョンのダウンロードが済むと、ウインドウの知らせもメニューと同じく **再起動して「肩代」<バージョン> にアップデート** を出し、ダウンロードページに案内しなくなりました。

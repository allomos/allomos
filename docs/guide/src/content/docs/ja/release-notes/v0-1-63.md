2026-11-15 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.63)。

## 新しいこと

- **タスク一覧から状態を変えられます。** タスク一覧で開いた行の状態（たとえば **準備完了**）をクリックすると状態の一覧が開き、選ぶとすぐにタスクの状態が変わって履歴に残ります。タスクパネルを開く必要はありません。ルールはタスクパネルの状態メニューと同じで、選べない状態は灰色になり、その下に理由が書かれます（引き受けられているタスクは解放されるまで **バックログ** に戻せません。完了したタスクは `alm reopen` で開き直します）。**待機中** を選ぶと、保存する前に何を待っているかを聞かれます。Esc を押すか一覧の外をクリックすると、何も変えずに閉じます。

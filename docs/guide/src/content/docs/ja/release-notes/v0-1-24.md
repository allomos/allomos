2026-10-25 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.24)。

## 新しいこと

- **タスクバッグごとに設定があります。** ヘッダーにタスクバッグの名前と **設定** のリンクが出ます。**一般** には名前（**名前を変更** できます）、形式、場所（**Finder で表示** できます）があり、タスクバッグが古いときは **タスクバッグを更新…** が出ます。**タスク** ではタスクの言語と進捗のはしごを変えられます。**引き継ぎ** には引き継ぎのルールがあり、「ファイル」メニューの **引き継ぎの設定…** の代わりになります。
- **ネットワーク上のデバイスからタスクを見られます。** **ファイル › ネットワーク上のデバイス…** でローカルネットワークからの閲覧をオンにします。オンにするまではオフのままです。ウィンドウにはアドレス、QR コード、証明書のフィンガープリントが表示されます。スマートフォンや別のコンピューターでそのアドレスを開いて名前を入れて要求し、あなたが承認すると、ウィンドウに出る9桁のコードをそのデバイスで入力します。ペアリングしたデバイスは一覧に出て、いつでも削除できます。デバイスは読むだけで、何も変更できません。
- **1つのタスクバッグで複数のプロジェクトフォルダーを扱えます。** 各タスクに、属するフォルダーを書きます（`alm add task --folder`、または `--no-folder`。変えるときは `alm folders`）。`alm list --folder` でフォルダーごとに絞り込め、フォルダーの中で `alm next` を実行するとそのフォルダーのタスクだけが出ます。これにはタスクバッグの形式 `allomos/6` が必要です。今あるタスクバッグは `alm upgrade --confirm` で変換するまでそのまま使えます（`alm upgrade` だけなら、何をするかを表示します）。
- **タスクをバックログに戻せます。** 誰も持っていない準備完了・待ち・ブロック中のタスクは、アプリの状態メニューか `alm backlog <id>` でバックログに戻せます。戻せないときは、メニューが理由を示します。
- **タスクバッグの更新で翻訳もできます。** **タスクバッグを更新…** にチェックボックスがあり、タスク、カードのファイル、プロジェクトのメモをアプリの言語に翻訳するようエージェントに頼めます。毎回チェックなしから始まります。
- **「最近使った項目を開く」は新しいウィンドウで開きます。** **ファイル › 最近使った項目を開く** でタスクバッグを選ぶと、専用のウィンドウで開くか、すでに表示しているウィンドウが前に出ます。前面のウィンドウの内容を置き換えなくなりました。
- **`alm list --by iteration` で計画全体が見えます。** 空のものも含めてすべてのイテレーションに見出しがつき、アプリと同じく計画の中の位置（1、2、3…）が出ます。

## そのほか

- 新しいバージョンが書いたタスクバッグを、このバージョンの知らないフィールドや値のせいで開けないことはなくなりました。そうした内容はそのまま残り、リマインダーとして一覧に出ます。

2026-11-17 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.69)。

## 新しいこと

- **静かな監視から起動した Codex は、承認を求めずに作業できます。** プロジェクトファイルの編集、ネットワークへの接続、この Mac 上の Allomos の操作ができます。設定は Allomos が起動したそのセッションだけに適用され、ユーザー自身の Codex 設定は変わりません。
- **タスク詳細からブロッカーを開けます。** リンクされたタスク ID を押すと、同じ詳細ペインにそのタスクが表示されます。

## 直したこと

- **監視が利用上限に対応します。** セッションを開く前に上限を確認し、上限に達していればタスクを準備完了のまま保ち、次の確認時刻を表示して、上限が戻った後に再試行します。
- **タスクを取得しなかったセッションが「作業中」のまま残りません。** 10 分以内にタスクを取得しなければ未起動として記録し、理由が読める場合は表示します。枠を解放してタスクを再び割り当てます。
- **新しいセッションは、タスクを取得するまで起動中と表示されます。** 作業開始前に「作業中」と表示されることを防ぎます。

## そのほか

- **監視パネルと状態レポートで、セッションの状態がそろいます。** 一時停止中、起動中、起動できなかったセッションの詳細が両方に表示されます。

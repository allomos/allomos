2026-10-27 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.30)。

## 新しいこと

- **タスクにまだ足りないものを alm が伝えます。** タスクを変えるコマンド（引き受け、ラベルの更新、完了）のあと、`alm` はそのタスクにまだ足りないもの（Allomos アプリがエージェントのセッションを開き直すためのセッション情報、作業ブランチ、引き継ぎメモなど）を、それを補うコマンドと一緒に示します。新しい `alm session` コマンドでセッション情報をあとから入れられるので、そのタスクの **Claude で開く**（または使っているエージェント）ボタンがまた使えます。
- **タスクバッグの翻訳でイテレーション名も訳されます。** タスクバッグを別の言語に翻訳するとき、エージェントは各イテレーションの名前も変えるようになりました。タスクだけが新しい言語になり、計画が古い言語のまま残ることはもうありません。

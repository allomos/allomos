2026-10-21 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.16)。

## 新しいこと

- **新しいタスクに単語IDがつきます。** 別々のブランチでタスクを足すと、同じ「次の番号」を取ってぶつかることがありました。これからは、短い単語と3桁の数字で名づけます（例：`A01-tiger042`）。同時にタスクを足しても重なりません。すでにある番号のIDはそのままです。一覧では番号のIDが先、そのあとに単語IDが作った順に並びます。
- **スタートページがウィンドウに合います。** カードの余白、見出し、説明文が、幅だけでなく高さにも合わせて変わります。**最近使った項目を開く…** と **新しいアプリを作る…** が、スクロールせずにカードの下に見えます。

## 直したこと

- **Windows のアンインストールで、肩代が入れたものがすべて消えます。** アプリのフォルダー（`alm.exe` を含む）、PATH の項目、ショートカット、「設定 › アプリ」の項目です。AppData にあるあなた自身のデータは、**アプリケーションデータを削除する** にチェックを入れたときだけ消えます。
- **セッションの使用量が正しいエージェントに数えられます。** セッション名（`claude/…` など）で使用量を報告したセッションは、3つ目のエージェントとして現れず、Claude Code として数えます。薄く表示されたエージェントのチップにマウスを重ねても、ポップアップが薄くならなくなりました。

## そのほか

- 肩代のウェブサイト www.allomos.com に、ブログと製品ページができました。

2026-10-22 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.19)。

## 新しいこと

- **タスクペインが読みやすくなりました。** 担当者、エージェント、確認、セッションが、それぞれ別の行に表示されます。
- **履歴にエージェントの名前が出ます。** タスクの履歴の各変更に、どのエージェントが行ったかが書かれます。

## 直したこと

- **「X / Y 完了」が、中止したタスクを数えません。** 中止したタスクを除いてすべて終わったエリアやイテレーションは、25/26 ではなく 25/25 と表示されます。

公開日： 2026-11-20. [GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.78).

## 新しいこと

- **ターミナルの Claude Code がたずねる回数が減りました。** Allomos やモニターがターミナルで開いた Claude Code は、プロジェクトフォルダーとタスクバッグのファイルを毎回たずねずに編集し、`alm` とよく使うテストコマンドはそのまま実行します。ほかのコマンドとプロジェクト外への書き込みは引き続きたずねます。
- **起動の通知からターミナルとタスクへ。** Claude Code がターミナルで起動したときの通知から、そのターミナルとタスクの詳細を開けます。

## 直したこと

- **長い依頼が途中で切れなくなりました。** macOS でデスクトップアプリからターミナルの Claude Code を開いたとき、長い依頼が途中で切れて止まることがなくなりました。
- **再び準備完了にしたタスクをモニターが拾います。** 準備完了に戻したタスクを、動いているモニターがもう一度割り当てます。
- **再投入ボタンは止まったタスクの行に。** モニターパネルでは、止まったタスクごとにその行に再投入ボタンがあり、上に同じ通知が重ねて出ることはありません。

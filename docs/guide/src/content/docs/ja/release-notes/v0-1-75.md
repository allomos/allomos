2026-11-20 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.75)。

## 新しいこと

- **サイレント実行の Antigravity セッションが危険なコマンドを自動で拒否します。** サイレント監視では、プッシュ確認で止まる代わりに拒否リストで危険なコマンド（`git -C` や `git -c` を使う形を含む）を自動で止めます。
- **承認待ちのセッションを監視パネルに表示し、枠を空けます。** 監視中のセッションが確認プロンプトで止まったままになっても、失効扱いにせず「承認待ち」として監視パネルに表示し、枠を空けて他の待機中タスクを進めます。

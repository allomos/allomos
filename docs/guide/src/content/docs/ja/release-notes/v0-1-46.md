2026-11-09 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.46)。

## 新しいこと

- **ハートビート。** タスクを持つセッションが、まだ作業中であることを示すようになりました。`alm beat` はタスクにハートビートを書きます（ID なしなら、そのセッションが持つすべてのタスクに）。引き受け手が自分のタスクを変えるたびにも、ハートビートが一緒に書かれます。`alm beat --busy <時間>` は、ハートビートを送れない長い作業のために作業中の時間帯を宣言します。ハートビートはイベントを書かないので、バーンダウンとタイムラインは変わりません。
- **応答なしのタスク。** タスク一覧とタスクのペインに、引き受け中の各タスクの **最終ハートビート**（または **作業中（…まで）**）が出ます。応答なしの上限を過ぎてもハートビートがなく、作業中の時間帯もないタスクには、琥珀色の **応答なし** タグがつきます。`alm next` はそうしたタスクを *Lost, can be taken over*（応答なし、引き継ぎ可）の下に、引き継ぐためのコマンドとともに挙げます。alm は挙げるだけで、自分からは引き継ぎません。
- **応答なしのタスクを引き継ぐ。** 応答なしのタスクに `alm claim` を実行すると、それを引き継いで元の作業ブランチで続け、前の引き受け手を記録します。応答なしでない引き受け中のタスクは、これまでどおり断られます。アプリでは、応答なしのタスクの行に **引き継ぐ…** があり、新しい AI エージェントのセッションを開いてこれを行います。前のセッションが戻ってくると、タスクが引き継がれたことを知らされ、そのタスクへのそれ以降の変更は断られます。
- **設定 → ハートビート。** タスクバッグの設定に **ハートビート** の項目ができました。**ハートビート間隔**（既定 10 分）と **応答なしの上限**（既定 30 分）、それに **初期値に戻す** があります。alm では `alm heartbeat-settings`。
- **ハートビートの共有ルール。** alm が AGENTS.md に書く共有ルールは、すべてのエージェントに `--as` を渡すこと、10 分ごとにハートビートを送ること、長い作業では `--busy` を宣言すること、応答なしのタスクを引き継ぐこと、自分のタスクが引き継がれたら止まることを求めるようになりました。`alm guide agent-files` には、自動ハートビート（エージェント自身のプロジェクト設定に置くフック）を設定する手順が加わりました。設定するのは本人が承認したときだけです。
- **2 つのセッションが同時に 1 つのタスクを引き受けたとき。** 負けたセッションには、それが誰のタスクか、その最終ハートビート、自分の引き受けを取り下げる方法、次の準備完了のタスクが伝えられます。
- **Claude Code のターミナルセッションの残量。** **準備完了のタスクを自動で監視** が始めた Claude Code のセッションは、`claude -p /usage` で残量を読んで報告するので、ヘッダーにも最新の数字が出ます。

## 直したこと

- **設定ダイアログがスクロールします。** 長い項目が **閉じる** の下に隠れなくなりました。項目の一覧と内容がそれぞれスクロールし、最後の項目まで届きます。
- **残量ポップアップは、エージェント・アカウント・時間枠ごとに 1 行になりました。** 更新前の行が新しい行の横に残らなくなり、新しい報告が古いセッション名で保存されていた報告に置き換わります。

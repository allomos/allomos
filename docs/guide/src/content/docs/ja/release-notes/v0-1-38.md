2026-11-03 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.38)。

## 新しいこと

- **グループの「編集」がタイトルの行に並びます。** タスク一覧で、エリアやイテレーションのグループの **編集** が、進捗バーの下の行ではなく、グループ名（イテレーションでは状態のバッジ）のすぐ後ろに出るようになりました。**新しいタスク** は下の行に残ります。「編集」で開くフォームは今までと同じで、押してもグループは折りたたまれたり開いたりしません。**未計画** と、エリアが不明なグループには、これまでどおり「編集」はありません。
- **状態の言葉が標準の太さになりました。** タスクの状態は、タスクの行でも、詳細パネルでも、**表示** の絞り込みでも、太字ではなくなりました。色はそのままで、薄い下地の色があったところはそれも残ります。ライトモードでもダークモードでも同じです。

2026-11-17 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.71)。

## 直したこと

- **Antigravity のセッションがファイルへのアクセスを尋ねて止まらなくなりました。** 「換肩」が開くセッションは、タスクバッグのフォルダーとタスクバッグのほかのプロジェクトフォルダーをワークスペースに加えるので、auto モードではそれら（プロジェクトノートなど）を尋ねずに読み書きします。Antigravity の設定は変えません。
- **静かなモードの Codex セッションがタスクバッグへの書き込みで失敗しなくなりました。** 監視が開く Codex セッションは、タスクバッグのフォルダーとほかのプロジェクトフォルダーにも書き込めるので、そこでファイルを変えても黙って失敗しません。そこでのコミットとプッシュには、引き続き「換肩」の Codex 用ルールが要ります。Codex の設定は変えません。

## そのほか

- **`alm` の内部を整理しました。** コードを小さな部分に分けました。使える機能は変わりません。

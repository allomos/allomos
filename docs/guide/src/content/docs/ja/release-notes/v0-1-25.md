2026-10-26 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.25)。

## 新しいこと

- **コンパニオンページはデスクトップアプリと同じ見た目です。** ペアリングしたスマートフォンやコンピューターのブラウザに、デスクトップアプリと同じ画面でタスクバッグが表示されます。タブ、フィルター、検索、並べ替え、タスクパネル、各タスクが誰を待っているかまで見られます。広い画面とスマートフォン用の2つのレイアウトがあり、数秒で更新され、デスクトップアプリが閉じているときは開くよう案内します。
- **ペアリングしたデバイスからタスクを変更できます。** コンパニオンページで、タスクの状態とラベルを変え、タイトル、説明、引き継ぎメモを編集し、タスク、エリア、イテレーションを追加できます。デスクトップアプリが自分のルールで確かめて変更し、履歴には「Sam (iPhone)」のように人とデバイスの名前が残ります。
- **プロジェクトフォルダを設定で管理できます。** タスクバッグの設定に **プロジェクトフォルダ** の項目があり、フォルダの結び付け、名前の変更、場所の指定、結び付けの解除ができます。`alm folder` でも同じことができます。フォルダを結び付けると、そのフォルダの AGENTS.md に Allomos の節を書き込み、解除するとその節だけを削除します。
- **タスクにフォルダが表示されます。** タスクパネルでタスクのフォルダを確認・変更でき、タスク一覧ではフォルダが小さなラベルで表示され、**フォルダ：** で絞り込めます。
- **設定に「エージェント」の項目ができました。** AI エージェントごとに、タスクバッグのプロジェクトフォルダのうちいくつで設定済みかを示し、足りないフォルダには **設定…** があります。
- **「タスクバッグを更新…」で allomos/6 にアップグレードできます。** まだ `allomos/5` のタスクバッグは、更新が必要と表示されるようになりました。**タスクバッグを更新…** は、プロジェクトフォルダに必要な `allomos/6` へのアップグレードをエージェントに頼み、その前に、アップグレード後は古いバージョンの Allomos がこのタスクバッグを開けなくなることを知らせます。**進める** を選ぶまで何も変わりません。

## 直したこと

- **ヘッダーの「設定」ボタンがそろいました。** タスクバッグの名前と同じ高さに並び、歯車もきれいな円になりました。

## そのほか

- AI エージェントが引き継ぎの上限に従うのは、タスクを持っている間だけになりました。上限に達すると、エージェントは引き継ぎを書いてタスクを手放すので、次のセッションが続きを引き受けられます。

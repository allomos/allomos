2026-11-10 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.51)。

## 新しいこと

- **すべてのダイアログで Antigravity の依頼を直接送ります。** 更新、移動、アプリを作成、翻訳、カードを移動、続行、引き継ぎ、アップグレードの各ダイアログで、Antigravity の依頼は `agy` に直接送られるようになり、貼り付けて Enter を押す案内は出なくなりました。ほかのエージェントは変わりません。
- **イテレーション名からそのイテレーションを開けます。** 監視一覧で、イテレーション名がリンク（アイコン付き）になり、クリックすると計画でそのイテレーションが表示されます。別の **開く** ボタンはなくなりました。

## 直したこと

- **タブは、エージェントが待機状態になってから閉じます。** 完了したタスクのタブを閉じる予定のとき、30 秒のカウントダウンはエージェントの作業が止まるまで始まりません。まだ push や merge をしているタスクには表示も終了コマンドも出ず、コマンドを入力する前にもう一度待機状態かを確かめます。
- **監視を止めてもタブは閉じます。** カウントダウンは独自のバックグラウンドプロセスで動くため、監視を止めたり再起動したりしても Claude または Codex のタブが開いたままになりません。
- **長い名前がボタン内で折り返します。** 長い領域名やイテレーション名がボタン内で折り返すので、**編集** ボタンが横に残ります。

## その他

- 非公開のコマンド `alm monitor close-tab` はタスクバッグを必要としなくなり、どのフォルダーからでも実行できます。

2026-11-15 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.62)。

## 新しいこと

- **依存ツリーが見やすくなりました。** **表示 › 依存ツリー** をオンにすると、各行の左に丸いノードが付き、色は階層ごとに変わります。同じ色の線が親タスクから下へ伸び、その下の各タスクへ角を丸めて曲がります。ノードは折りたたみボタンでもあり、下にタスクがある行でクリックすると下のタスクがたたまれ（ノードは + になります）、もう一度クリックすると開きます。

## そのほか

- 決定 0028 で、人がすることを一つの列にまとめる方針を決めました。別ウィンドウの **あなたの対応待ち** が前面のプロジェクトに合わせて切り替わり、1 タスク 1 行で、エージェントが待っているものを先頭に、残りはリスク順に並べます。この機能はまだ作られていません。

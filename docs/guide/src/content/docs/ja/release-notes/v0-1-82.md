2026-11-25 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.82)。

## 直したこと

- **静かな自動監視での Claude Code 起動時に信頼確認やモード切り替え確認が出なくなりました。** 静かな監視では Claude Code を `auto` mode で起動し（すでに `bypassPermissions` が設定されている場合はそのまま維持）、`--add-dir` を付けないことで、未信頼のタスクバッグフォルダーによる起動停止や、コマンド実行時の auto mode 切り替え確認を防ぎます。
- **通常・デスクトップからの Claude Code 起動で既定モードと信頼済みフォルダーを尊重します。** 手動・通常モードの起動では Claude Code がすでに恒久的に信頼しているフォルダーだけ `--add-dir` で追加し、すでに `auto` mode を既定にしているユーザーを `acceptEdits` に下げなくなりました。`~/.claude/settings.json` は変更せず、アプリ内の Claude Code 権限説明文も新しい動作に合わせて更新しました。

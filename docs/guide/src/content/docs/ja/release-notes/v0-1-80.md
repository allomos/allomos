公開日： 2026-11-20. [GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.80).

## 新しいこと

- **「あなたへ」で複数のタスクをまとめて承認。** 承認したいタスクにチェックを入れるか「すべて選択」を押し、一度の確認でまとめて承認します。まだ承認できないタスクはチェックできず、その理由が表示されます。
- **理由を書いてタスクを差し戻す。** 確認待ちのタスクの「エビデンス」画面の下と、完了したタスクのパネルに「差し戻す…」があります。理由は必須で、タスクは準備完了に戻ります。デスクトップアプリでは画面のスクリーンショットを添付できます。AI 判断ごとに「同意しない…」があり、押すとその判断の文面が理由に入ります。
- **差し戻されたタスクは理由を先に表示。** `alm next`、`alm show`、`alm claim` は、引き継ぎの前に、だれがいつ差し戻し何を書いたかを新しい順に表示します。モニターが差し戻されたタスクのセッションを開くときは、エージェントにまず理由を読むよう伝えます。
- **差し戻されたタスクを先に割り当て。** 同じイテレーションの中で、`alm next` とモニターは差し戻されたタスクを先に並べます。

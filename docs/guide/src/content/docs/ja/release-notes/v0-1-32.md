2026-10-30 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.32)。

## 新しいこと

- **タブのドラッグが Chrome のようになりました。** タブはポインターと一緒に動き、ほかのタブは落とす位置をあけて待ちます。隣のタブの半分以上に重なったところで入れ替わり、**+** ボタンもよけます。
- **タブを別のウインドウに移しやすくなりました。** タブバーの上でなくても、そのウインドウの上ならどこで離しても入ります。そのウインドウはいちばん前に出て、自分のタブを見せたまま、落とす位置にドラッグ中のタブを表示し、そのタスクバッグももう見えています。
- **前にないタブには薄いグレーの枠が付き**、どれが前のタブかわかりやすくなりました。

## 直したこと

- **Retina ディスプレイと通常のディスプレイをつないだ Mac で、ドラッグ中のタブが飛ばなくなりました。**
- **macOS で、タブを別のウインドウのタブバーの上に持っていっても、元のウインドウが画面の左上に飛ばなくなりました。**

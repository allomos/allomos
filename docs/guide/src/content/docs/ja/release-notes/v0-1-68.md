2026-11-16 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.68)。

## 新しいこと

- **監視から起動した Codex がプロジェクトファイルを編集できるようになりました。** 自動で起動したセッションは、変更のたびに承認を求めずに編集でき、ユーザー自身の Codex 設定は変わりません。

## 直したこと

- **別のセッションがタスクを取得すると、監視はそのタスクと枠を解放します。** タスクは監視中の一覧から消え、誰が取得したかが表示されます。
- **ハートビートの案内が未共有の変更をローカルに残すのに役立ちます。** `alm` は保存するファイルを列挙し、タスクバッグで範囲の広い Git コマンドを使わないよう案内します。

## そのほか

- **Codex がタスクを持っているときは、そのまま実行できる Git コマンドが表示されます。** `alm` はタスクバッグのフォルダーを示し、`git -C` を使わず、コマンドを 1 つずつ表示します。

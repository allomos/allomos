2026-11-17 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.70)。

## 新しいこと

- **新しい「あなたの対応待ち」ウィンドウが、対応を待つタスクを並べます。** メインウィンドウ右上の件数つき「あなたの対応待ち」ボタン、またはメニューの「表示 → あなたの対応待ち」（⇧⌘Y）から開きます。左側に確認・回答・レビューするタスクが順に並び、右側にやることとそのタスクが表示されます。対応したタスクは一覧から消え、次のタスクが選ばれます。
- **監視パネルのタスク名から詳細を開けます。** 監視が開いたセッションの下でタスク名を押すと、そのタスクが詳細ペインに表示されます。「セッションを開く」は引き続きそのセッションを開きます。

## そのほか

- **アプリと `alm` の内部を整理しました。** コードを小さな部分に分けました。使える機能は変わりません。

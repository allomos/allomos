2026-11-08 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.43)。

## 新しいこと

- **履歴に、誰が、誰のために、どの承認で、なぜ行ったかが残ります。** 変更のたびに、誰が行ったかを記録します。人は仮名で、エージェントはセッション、モデル、effort、権限モード、ルールの版、`alm` の版で記録します。誰のために、どの承認にもとづいて行ったかも残ります。`alm --why "<理由>"` で理由を添えられ、状態の変更や計画の変更に理由がないときは `alm` がそう伝えます。
- **承認が記録になります。** `alm approve` は、誰がどの計画を、いつ、どこで、いつまで承認したかを記録し、`alm withdraw` で取り消せます。タスクのパネルの **承認** 欄に、各承認がまだ有効か、期限切れか、取り消されたか、説明が変わって合わなくなったかが出ます。**承認…** は承認する前に計画を書かれたとおりに表示し、バックログのタスクには **承認して準備完了にする** もあります。**取り消す…** は理由を尋ねます。承認してもタスクの状態は変わりません。
- **人による確認に、誰が、どの手順で、どうだったかが残ります。** **確認済み** と `alm checked` は、確認した人、従った確認手順の版、結果（`--result pass` または `partly`）、その人の言葉（`--words`）を記録します。
- **例外を書き残します。** 実行しなかった確認や、人による確認なしで終えたタスクを、理由とリスクを受け入れた人とともに記録します：`alm exception`、一覧は `alm exceptions`。`alm done --without-human-check` は自分で一件記録します。
- **変更の種類とリスク。** `alm classify` はタスクの変更の種類（標準、通常、緊急）、リスク、影響の範囲を記録します。緊急の変更は、誰かが承認するまで `alm human` の **To approve afterwards**（あとから承認） に並びます。
- **タスクをコード、リリース、要件、決定につなげます。** `alm link` はタスクのコミット、ブランチ、マージ、プルリクエスト、CI の実行、リリースを記録し、`alm links` はそのどれからでもタスクを探せます。タスクのパネルでは **コードとリリース** に出ます。`alm trace` はタスクを要件の番号や決定記録につなぎ、`alm traces` はそれに当たるタスクを探します。
- **外部への影響の台帳。** `alm effect` は外部への影響を、起きる前に（どこに、何を、どう戻すか、どの承認で）記録し、あとで結果を加えます。`alm effects` が一覧を出し、タスクのパネルでは **外部への影響** に出ます。
- **署名された履歴と alm audit。** 新しいタスクバッグの形式 `allomos/8` では、各コンピューターが自分の鍵（macOS のキーチェーンに保管）で書いたイベントに署名し、鎖のようにつなぎます。`alm checkpoint` はタスクバッグの署名つきの指紋を保存し、`alm audit` は変えられた、消された、署名のないイベントを一覧にします。新しく作るタスクバッグは `allomos/8` で始まります。`allomos/7` のタスクバッグは、`alm upgrade` を実行するまで、署名なしでこれまでどおり使えます。アップグレードすると Allomos 0.1.42 以前はそこに書き込めなくなるので、先にそのタスクバッグで作業するすべてのコンピューターに 0.1.43 を入れてください。
- **プロジェクト設定 → 監査。** 四つの設定があり、変更はどれも理由とともに履歴に残ります。**本人確認**：履歴には仮名だけが入ります。Allomos アカウントと会社のサインイン（SSO）にはクラウドのプロジェクトが必要で、まだ使えません。**保存**：履歴をどれだけの期間残すか。Allomos が自分で何かを消すことはありません。**訴訟ホールド**：有効な間は何も消せません。**職務の分離**：初めは無効です。有効にすると、同じ人やエージェントが同じタスクを行い、かつ確認することはできません。`alm redact` はタスクの履歴から項目の過去の値を消し、消したという記録だけを残して古い値は残しません。訴訟ホールドの間は断られます。
- **監視で開いたターミナルのタブが自分で閉じます（macOS）。** 監視しているタスクが完了すると、その Terminal のタブに 30 秒後に閉じると出ます。何かキーを押せば開いたままにできます。Windows の監視ウインドウは、これまでどおり開いたままです。

## そのほか

- **「表示」の絞り込みに閉じるボタンがつきました。** タブの行の右端の **×** でパネルを閉じても、絞り込みはそのままです。

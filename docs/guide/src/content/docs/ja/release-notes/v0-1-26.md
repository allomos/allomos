2026-10-26 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.26)。

## 新しいこと

- **タスクパネルからタスクの Claude Code セッションを開けます。** タスクパネルの **セッション** の行に、セッションがどこで動いているか（Claude アプリ内か、ターミナル内か）が表示され、ボタンが1つ付きます。**Claude で開く** は Claude アプリをその会話に切り替え、**ターミナルで再開** はタスクを引き受けたフォルダでターミナルを開き、`claude --resume` で会話を続けます。タスクを手放したり完了したりした後は **前回のセッション** と表示され、ボタンもそのまま使えるので、タスクを仕上げた会話に戻れます。Web とスマートフォンのコンパニオンでは、この行は文字だけです。
- **`alm claim` がエージェントのセッションを記録します。** エージェントはタスクを引き受けるときに `--session-agent`、`--session-id`、`--session-kind`、`--app-session-id` を渡せます。タスクは手放しても完了してもそのセッションを残し、新しく引き受けると置き換わります。何も渡さないと、何を渡せばよいかを表示します。

## そのほか

- AI エージェントは、タスクを引き受けるときに自分のセッションを渡すよう求められるようになり、Allomos アプリがそのセッションを開き直せます。

2026-11-12 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.57)。

## 新しいこと

- **変更がひとりでに、すぐ出る。** あなたやエージェントが `alm` でタスクを変えると、Allomos のウィンドウには約 1 秒で出ます。ウィンドウが裏にあっても同じです。Allomos はタスクバッグのファイルを時間ごとに見に行くのをやめ、変化をシステムから知らされるようになりました（macOS と Windows のファイル通知）。通知が届かなかったとき（ネットワークの場所やクラウド同期のフォルダーなど）に備えて、1 分に一度の確認も残っています。

## 直したこと

- **何もしていないときの CPU 使用がずっと少なく。** プロジェクトを開いてウィンドウを裏にしておくと、これまで Allomos は 1 分あたり約 2.3 秒の CPU を使っていましたが、今は約 0.15 秒です。ファイル通知に加えて、プロジェクトの監視バー、**監視 · N** の数、**Running Monitors** メニューが一つの読み取りを共有するようになりました（ウィンドウを使っているあいだは 3 秒ごと、それ以外は 15 秒ごと）。ウィンドウに戻るとすぐに新しくなります。

## そのほか

- **タスクバッグの更新のお知らせを確かめる回数が減りました。** タスクバッグの更新が要るかどうかは、プロジェクトを開いたときとタスクバッグが変わるたびに確かめ、4 秒ごとには確かめません。プロジェクトフォルダーの AGENTS.md だけを変えたときは、次にタスクバッグが変わるかプロジェクトを開き直したときにお知らせが出ます。

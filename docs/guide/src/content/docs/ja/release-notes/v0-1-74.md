2026-11-19 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.74)。

## 新しいこと

- **監視でエージェントごとにモデルと推論レベルを選べます。** 監視の開始ダイアログで、オンラインのモデル一覧（設定でアドレスを変更可能）からエージェントごとのモデルと推論レベルを指定できるようになりました。
- **失効した監視セッションを自動で引き継ぎます。** 監視パネルに失効したセッションと手放されたタスクが表示され、空いた枠を使って同じ作業ブランチ上の新しいセッションへ引き継ぎます。監視の即時終了時には、作業中タスクの警告を出しつつ未完了の作業を保持します。
- **高リスクタスクの制限に対応しました。** プロジェクト設定で有効にすると、`alm done --without-human-check` は高リスクタスクを拒否し、サイレント実行では高リスクのマージを承認者待ちにします。また、オプションなしの `alm classify` と `alm done` がリスク規則を表示し、リスク未記録のまま完了しようとすると知らせます。
- **For You ウィンドウが最後に使ったプロジェクトに追従します。** プロジェクトウィンドウを切り替えると、For You ウィンドウもそのプロジェクトに合わせて切り替わります。
- **アプリの変更共有が分かりやすくなりました。** 共有の詳細にタスク名が表示され、ダイアログの見た目も整理されました。共有対象は変更されたタスクファイルだけに絞られ、共有リマインダーも再起動をまたいで保持されます。

## 直したこと

- **タスクツリーで重複していたブロッカー表示を修正しました。** ツリーのタスク名に出ていた重複した「非表示」ブロッカーチップを取り除きました。
- **アプリのコマンドが環境変数 `ALLOMOS_TASKBAG` の影響を受けなくなりました。** デスクトップアプリから実行するコマンドで `ALLOMOS_TASKBAG` を消去し、別のプロジェクトのタスクバッグに誤って書き込まないようにしました。

公開日： 2026-11-19. [GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.74).

## 新機能

- **エージェントごとにモデルと推論の強度を選択。** タスク監視の開始時にオンライン一覧から選ぶか、「既定」のままエージェント自身の設定を使えます。一覧の更新や一般設定での URL 変更もでき、オフラインでは保存済みの一覧を使えます。
- **監視をすぐに終了。** 停止後にタスクの終了を待っている間、「今すぐ停止」でその監視を終了できます。開始済みのエージェントセッション、タスク、作業内容は保持されます。応答のないタスクには警告を表示します。

## 修正

- **タスク名の重複表示を整理。** 依存関係ツリーでタスク名の横に「非表示」のブロッカーを繰り返し表示しません。ブロッカー欄には引き続きすべて表示します。
- **追加アカウントを維持。** バックグラウンドで監視を開始するとき、選択した追加アカウントを正しく引き継ぎます。

## その他

- **ソースファイルの行数を確認。** ワークスペースのテストで上限を超えたファイルの増大を防ぎ、記録した上限の更新が必要な場合に知らせます。

2026-11-02 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.36)。

## 新しいこと

- **「表示」フィルターの「ラベル」の列は、「ラベルあり」の「はい」と「いいえ」から始まります。** **いいえ** を外すとラベルのないタスクが隠れ、**はい** を外すとラベルのあるタスクがすべて隠れます。「ラベルあり」の「はい」を外している間は、その下のラベルが灰色になり、チェックはそのまま残って、もう一度チェックすると元に戻ります。ラベルのないタスクは「ラベルあり」の「いいえ」だけで決まるようになり、各ラベルの「はい」「いいえ」はラベルのあるタスクに使われます。「すべて選択」「選択をすべて解除」と ↻ は「ラベルあり」も含み、ウインドウを開き直しても選んだ内容は残ります。

## そのほか

- **ウインドウのタブにオレンジの点が出なくなりました。** タブにはタスクバッグの名前と閉じるボタンだけが表示されます。

2026-11-10 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.53)。

## 新しいこと

- **始め方が 2 つ並びます。** スタートページで、**新しいプロジェクトを作る…**（以前の **新しいアプリを作る…**）が **既存のプロジェクトを設定する**（以前の **はじめる**）のすぐ隣に並びます。**最近使った項目を開く…** はその下のままです。開くダイアログの名前も **新しいプロジェクトを作る** になりました。
- **アップデートの確認とダウンロードを別々に切り替えられます。** **設定 › 一般 › アップデート** にスイッチが 2 つあり、どちらも最初はオンです。**自動的に更新を確認** をオンにすると、「肩代」は 1 日に 1 回 GitHub に新しいバージョンがあるか確かめます。**自動的にアップデートをダウンロード** をオンにすると、見つかった新しいバージョンのインストーラーをバックグラウンドでダウンロードして確かめます。確認がオフの間は、こちらは灰色になります。メニューの **アップデートを確認…** は、スイッチに関係なくダウンロードします。
- **ダウンロードの進み具合が見え、止められます。** 新しいバージョンのインストーラーをダウンロードしている間、アップデートのお知らせに進み具合（例：「インストーラーをダウンロード中：40%」）と **キャンセル** ボタンが出て、メニューの項目は **「肩代」0.1.53 をダウンロード中… 40%** になります。キャンセルするとダウンロードが止まり、途中までのファイルは消されます。

## 直したこと

- **インストーラーの準備ができてからアップデートを案内します。** アップデートのお知らせとメニューは、新しいインストーラーのダウンロードと確認が終わってから **再起動して「肩代」… にアップデート** を出すようになりました。それまでは、メニューの **「肩代」… をダウンロード…** はリリースページを開かず、灰色のまま待ちます。リリースにまだソースコードしかないときは、**アップデートを確認…** がインストーラーを準備中だと伝え、ダウンロードのバナーは出ません。リリースページを開くのは、お使いのコンピューター用のインストーラーが手に入らないときだけです。

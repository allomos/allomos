2026-11-16 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.64)。

## 新しいこと

- **更新のあと、監視は新しいバージョンに切り替わります。** 「肩代」が更新のために再起動するとき、動いている **準備完了のタスクを自動で監視** は古いバージョンの `alm` のまま残りません。アプリがいったん止めて新しいバージョンで起動し直し、設定はそのままです。通知とステータスバーの監視パネルの一行でそのことを知らせ、**再起動してアップデート** の前の案内にも書かれます。ソースからビルドした `alm` やほかの場所の `alm` で動かしている監視には手を付けません。

## 直したこと

- **タスクバッグを読めない監視は、そのことを知らせます。** タスクバッグの形式に新しい「肩代」が必要なときはすぐに、タスクバッグを 2 分以上読めないときはその時点で知らせます。通知が届き、ステータスバーの監視の横に警告色の一行が出て、**自動監視** の見出しに ⚠ が付きます（たたんでいても開いていても表示）。監視は数秒ごとに読み直しを続け、読めるようになると自分で続きを進め、警告も消えます。

## 新しいこと

- **タスクバッグをタブで開けます。** どのウインドウにもブラウザーのようなタブバーがあります。タブバーの最後の **+**、または **ファイル → 新規タブ**（macOS では ⌘T、Windows では Ctrl+T）で新しいタブが開きます。**ファイル → 最近使った項目を開く** はタスクバッグを新しいタブで開き、すでに開いていればそのタブを前に出します。タブをドラッグして並べ替えたり、外に出して別のウインドウにしたり、ほかのウインドウに入れたりできます。タブの点は、そのタスクバッグにあなたの対応が要ることを示します。
- **「肩代」の起動時に開くものを選べます。** アプリ全体の新しい **設定…** ウインドウ（macOS では ⌘,、Windows では Ctrl+,）に **「肩代」の起動時** があり、**ウインドウとタブを再び開く**（既定）、**最後のタスクバッグを開く**、**空白のウインドウを開く** から選べます。
- **新しいアプリを作る…で、先に話し合えます。** **先に話し合う** にチェックを入れると、エージェントは説明をゴールにまとめて待ちます。その会話で一緒にゴールを詰め、どんな言い方でも「始めて」と伝えれば、計画してアプリを作り始めます。
- **Windows では、ウインドウメニューに開いているすべての「肩代」ウインドウが並びます。** **ファイル → 新しいウインドウ…** で開いたものも含み、選ぶとそのウインドウが前に出ます。

2026-11-02 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.37)。

## 新しいこと

- **お知らせがウインドウの上端に並びます。** 更新の行（**今すぐ更新** つき）、「変更は … の名前で記録されます。」、「このプロジェクトにはまだイテレーションがありません」が一本の帯にまとまり、タスク一覧とタスクの詳細パネルの両方の上に出ます。詳細パネルの上端は一覧とそろい、パネルを開け閉めしてもお知らせは動きません。

## 直したこと

- **Claude デスクトップアプリで進めたタスクが、またそこで開くようになりました。** Claude デスクトップアプリのエージェントがタスクを取るときにセッション ID しか記録しなかった場合、`alm` がデスクトップの情報が足りないことと、それを加えるコマンドを示すようになりました。これで **Claude で開く** が Claude アプリでセッションを開き、**ターミナルで再開** が新しいターミナルを開くことはなくなります。ターミナルで作業するエージェントは `--session-kind terminal` を記録すれば、それ以上は案内されません。これより前に記録されたタスクは、そのタスク自身のセッションが `alm session` を実行するまで今のままです。

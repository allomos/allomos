2026-11-27 公開。[GitHub からダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.85)。

## 新しくなったこと

- **Antigravity のモデル一覧を更新し、モデルごとの推論強度に対応しました。** 設定がモデル一覧の version 2 形式を読み取れるようになり（version 1 との互換も維持）、各モデルで実際に対応する推論強度だけが表示されます。推論強度を取らないモデルは「既定」のみ表示されます。Antigravity には Gemini 4 Neon / Hydrogen / Carbon / Argon、Gemini 3.8 Flash、Claude Opus 5.5、Claude Sonnet 5.5、GPT-OSS 120B、3 つの Orchestrator を含む全 11 モデルが並びます。

## そのほか

- **エージェント用ワークツリーの配置先を統一しました。** 共有ルールと `alm` の案内を更新し、タスクごとのワークツリーをプロジェクト内の `.worktrees/<short-name>` に作るようにしました。

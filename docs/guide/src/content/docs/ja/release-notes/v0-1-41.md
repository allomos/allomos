2026-11-07 公開。[GitHub でダウンロード](https://github.com/allomos/allomos/releases/tag/v0.1.41)。

## 新しいこと

- **1つのタスクに複数のラベル、プロジェクトにラベル表。** タスクに一度に複数のラベルを付けられるようになりました。ラベルの間に順番はありません。どのプロジェクトにも5つの組み込みラベル **locally verified by agent**、**deployed and verified by agent**、**locally verified by human**、**deployed and verified by human**、**AI decisions to review** があり、プロジェクト独自のラベルと一緒にラベル表に入っています。`alm label <id> "<ラベル>"` はラベルを1つ付け、ほかのラベルはそのまま残します（`--remove` で1つ外します）。プロジェクトに初めて出てきたラベルはラベル表に加わり、打ち間違いに気づけるよう `alm` がそう伝えます。`alm labels` でラベル表を表示し、`alm labels add` と `alm labels remove` で変更します。デスクトップアプリのラベルに関する画面（「進捗のはしご」の設定を含む）は、今後のリリースで変わります。
- **人による確認はラベルになりました。** `alm checked <id>` は完了したタスクに **locally verified by human** を付けます。エージェントがデプロイして確認済みなら **deployed and verified by human** を付けます（`--deployed` か `--locally` で選べます）。`--without-human-check` を付けない `alm done <id>` には、このどちらかのラベルが必要になりました。完了していて「by human」のラベルがないタスクは、これまでどおり「確認待ち」です。`alm ai-decided` は **AI decisions to review** を付け、`alm reviewed` はそれを外します。
- **タスクバッグの形式 allomos/7。** これらのラベルにはタスクバッグの形式 `allomos/7` が必要です。このバージョンは古い形式のタスクバッグも読めますが、更新するまでは何も変更しません。デスクトップアプリの **タスクバッグを更新…** か、`alm upgrade --confirm` で更新します（`alm upgrade` だけなら、何をするかを先に表示します）。更新では、古い *drafted* と *implemented* をなくし、*locally verified* と *deployed and verified* を「… by agent」に変え、*human verified* を **locally verified by human**（先にデプロイされていたタスクは **deployed and verified by human**）に変え、AI の判断をまだ確認していないタスクに **AI decisions to review** を付けます。古い「肩代」は更新後のタスクバッグを開けないので、このタスクバッグを使うすべての場所に 0.1.41 を入れてから更新してください。

Released 2026-11-20. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.78).

## New

- **Claude Code in a terminal asks less.** When Allomos or the monitor opens Claude Code in a terminal, it edits files in the project folder and the taskbag without asking each time, and runs `alm` and common test commands directly. Other commands, and writes outside the project, still ask.
- **Go from a launch notice to the terminal and the task.** The notice shown when Claude Code starts in a terminal now opens that terminal and the task's details.

## Fixed

- **Long requests no longer get cut off.** On macOS, opening Claude Code in a terminal from the desktop app no longer cuts off and stalls a long request.
- **The monitor picks up a task made ready again.** A task that is set back to ready is dispatched again by the monitor that was already running.
- **Requeue sits on the stopped task's own row.** In the monitor panel, each stopped task has its requeue button on its own row, without a repeated notice above.

Released 2026-10-27. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.27).

## New

- **Translate a taskbag into any language.** In the taskbag's settings, the **Tasks** section has **Translate the Taskbag…**. Pick a language (any language, not only the ones the app is shown in) and an AI agent; the agent rewrites every task, card file and handoff note in that language and makes it the task language. The usual progress popup shows how far it has got.
- **A language menu instead of the translate checkbox.** In the **Update the taskbag** dialog and in step 4 of the setup wizard, the translate checkbox is now a language menu that starts at **Don't translate**. Pick a language, and the agent translates the taskbag's contents into it and sets the task language to it in the same run.
- **Choose the task language when the wizard creates a taskbag.** When the setup wizard creates a new taskbag, step 2 asks which language AI agents should write its tasks in, before **Create taskbag**.
- **Several project folders for one taskbag in the wizard.** Step 3 of the setup wizard can now connect more than one project folder to the taskbag.
- **Open a task's session from the top of its pane.** When a task has a recorded session, its **Open in Claude** or **Resume in terminal** button also sits at the far right of the row under the title, next to **Checked**, so you do not have to scroll down to the Session row.

## Fixed

- **A checkbox and its text sit on one line in dialogs**, for example **Allow devices on your network to view** in **Devices on your network**.

## Also

- In the taskbag's settings, **Project folders** says that one taskbag can serve many folders, and its button reads **Add a Project Folder…**, then **Add Another Folder…** once a folder is added.

Released 2026-11-27. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.84).

## Fixed

- **New-task approval defaults to on.** Projects without a saved setting now keep agent-created tasks in the backlog until you approve them. Turning the setting off saves explicitly so it stays off when you reopen settings.
- **Clean scrolling in Taskbag Settings.** Shorter windows scroll the settings body vertically with a thin scrollbar and right-hand spacing so text is never covered, and narrow windows scroll categories horizontally.

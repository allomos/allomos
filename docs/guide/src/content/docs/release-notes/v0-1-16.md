Released 2026-10-21. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.16).

## New

- **New tasks get a word ID.** Tasks added on different branches used to clash when both took the next number. Now a new task is named from a short word and three digits, for example `A01-tiger042`, so two people adding tasks at the same time no longer collide. Existing numbered IDs stay as they are. Lists show numbered IDs first, then word IDs in the order they were made.
- **The start page fits your window.** The card's padding, the headline and the introduction now follow the window's height as well as its width, so **Open recent…** and **Build a new app…** show under the card without scrolling.

## Fixed

- **Windows uninstall removes everything Allomos added.** That means the app folder (with `alm.exe`), the PATH entry, the shortcuts and the entry in Settings › Apps. Your own data in AppData is removed only if you tick **Delete the application data**.
- **A session's quota counts for the right agent.** A session that reports its quota under its session name (such as `claude/…`) is now counted for Claude Code instead of showing up as a third agent. A dimmed agent chip no longer fades its popup when you hover it.

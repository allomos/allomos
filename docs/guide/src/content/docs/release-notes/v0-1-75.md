Released 2026-11-20. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.75).

## New

- **Quiet Antigravity sessions refuse risky commands automatically.** In quiet monitored runs, Antigravity sessions use a deny list to block risky commands (including `git -C` and `git -c` forms) instead of stalling on push confirmations.
- **Monitor shows sessions waiting for approval and frees their slots.** When a monitored session still pauses at a confirmation prompt, the monitor panel displays it as waiting for approval, avoids marking it as lost, and frees its slot so other ready tasks can keep running.

Released 2026-11-18. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.73).

## New

- **Sort tasks by creation time.** The sort menu in Iteration and By area adds Created, with oldest or newest first. Child tasks in the dependency tree follow the same creation order.
- **Set a project's file-size limit.** The File size setting lets you view or change the project's source-file line limit; it defaults to 1,000 lines. \`alm file-size-settings\` reads and updates the same value. The setting is for the project's own file-size check; \`alm\` does not scan files automatically.

## Fixed

- **Edited tasks stay put under modified-time sorting.** Changing a task's status or difficulty no longer makes its row jump to a different spot.
- **Monitoring respects heartbeats.** A session that still sends heartbeats is not marked as stalled. After heartbeats stop, the project's timeout determines when it becomes stalled.
- **Long Antigravity launch commands no longer stop at an open-quote prompt.** On macOS, monitored Terminal sessions now run the full command from a short-lived script.

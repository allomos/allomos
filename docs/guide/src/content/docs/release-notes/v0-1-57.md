Released 2026-11-12. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.57).

## New

- **Changes show up by themselves, at once.** When you or an agent change a task with `alm`, the Allomos window shows it within about a second, also while the window is in the background. Allomos now hears about changes from the system (file notifications, on macOS and Windows) instead of looking at the taskbag's files on a timer. A check once a minute still catches anything a notification misses, for example in a network or cloud-synced folder.

## Fixed

- **Much less CPU while idle.** With a project open and its window in the background, Allomos used about 2.3 seconds of CPU a minute; it now uses about 0.15 seconds. Besides the file notifications, the project's monitor bar, the **Monitors · N** count and the **Running Monitors** menu now share one reading (every 3 seconds while a window is in use, every 15 seconds otherwise), and coming back to the window updates them at once.

## Also

- **The taskbag update notice is checked less often.** Allomos checks whether the taskbag needs updating when the project opens and whenever the taskbag changes, no longer every 4 seconds. A change to a project folder's AGENTS.md alone shows the notice the next time the taskbag changes or the project is opened.

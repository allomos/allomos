Released 2026-11-17. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.72).

## New

- **Quiet Antigravity sessions push their branch without asking.** Antigravity sessions the monitor starts in quiet mode no longer stop for a plain push of a branch to `origin` written in full, such as `git push origin refs/heads/main`. Any other push (a bare `git push`, `git push origin main`, extra options, force pushes, deleting a remote branch, tags, combined commands) still asks. Normal sessions and your Antigravity settings stay as they are.

## Fixed

- **Status and difficulty menus are no longer cut off.** On the last task of an iteration or area, the menus used to be hidden by the bottom of the list. They now float above the list and open upwards when there is no room below.
- **The quiet-mode note no longer promises that auto mode never stops.** It now says that Antigravity's auto mode still asks before risky or irreversible steps, such as pushing a shared branch.

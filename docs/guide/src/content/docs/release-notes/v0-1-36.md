Released 2026-11-02. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.36).

## New

- **The Show filter's Labels column starts with Labeled, Yes and No.** Untick **No** to hide the tasks that have no label; untick **Yes** to hide every task that has one. While Labeled's Yes is unticked, the labels below it are greyed out and keep their ticks for when you tick it again. A task with no label now follows Labeled's No alone; the labels' own Yes and No apply to tasks that have a label. Select all, Clear all and ↻ include Labeled, and the choice is remembered when the window reopens.

## Also

- **Window tabs no longer show the orange dot.** A tab shows only the taskbag's name and its close button.

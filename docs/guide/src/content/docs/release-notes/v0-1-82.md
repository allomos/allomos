Released 2026-11-25. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.82).

## Fixed

- **Quiet monitored Claude Code sessions start without trust or mode-switch prompts.** Quiet monitoring now starts Claude Code in auto mode (keeping `bypassPermissions` if already configured) and omits `--add-dir`, so untrusted taskbag folders no longer stall startup on a directory trust prompt and commands no longer pause to ask about switching to auto mode.
- **Normal and desktop Claude Code launches keep your default mode and trusted folders.** Manual and normal-mode launches now add `--add-dir` only for folders Claude Code already trusts permanently, stop downgrading users who already default to auto mode back to `acceptEdits`, never edit `~/.claude/settings.json`, and update the in-app Claude Code permissions note to match.

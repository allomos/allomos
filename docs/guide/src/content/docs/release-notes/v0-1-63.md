## New

- **Change the state from the task list.** In an expanded row of the task list, click the state (for example **Ready**) and a list of states opens; pick one and the task changes at once, recorded in its history, with no need to open the task panel. The rules are the same as the panel's state menu: a state you cannot pick is greyed, with a line saying why (a held task cannot go back to **Backlog** until it is released; a done task is reopened with `alm reopen`). Picking **Waiting** asks what the task waits on before it saves. Press Esc or click outside to close the list without changing anything.

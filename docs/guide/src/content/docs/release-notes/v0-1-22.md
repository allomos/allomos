Released 2026-10-23. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.22).

## New

- **One banner when the taskbag needs updating.** Out-of-date instructions, an older taskbag, card files kept outside the taskbag and old handoff files used to show a banner each. Now one banner lists every reason, a line each, with a single **Update the taskbag…** button.

## Fixed

- **The update notice matches the menu.** Once the new version has been downloaded, the notice in the window offers **Restart to Update to Allomos <version>**, like the menu, instead of still sending you to the download page.

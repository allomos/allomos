Released 2026-11-15. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.61).

## New

- **Blocked is no longer a state.** Giving a task blockers keeps its state; the list and the task pane show it as, for example, "ready · blocked" while a blocker has not finished, and when the blockers finish the task simply stays as it was. The filter menu gains **Only blocked tasks**. A taskbag from an earlier version asks to be updated first (**Update the taskbag…**); tasks that were blocked get back the state they had before.
- **A dependency tree in the sort menu.** **Show › Dependency tree** puts each task under the task that blocks it, with guide lines and folding; the chosen sort still orders the trees and the tasks under each parent. A task with several blockers is shown once and notes what else it depends on.
- **AI decisions come in three kinds.** `alm ai-decided --kind` records what users see, how something is built, or a detail. The first two are listed under **AI decisions to review** as before; details are kept in the task, in a section of the task pane of their own, without asking for a review.

## Also

- Decision 0026 records that blocked is worked out from blockers; decision 0027 records what counts as high risk, with the agent assigning the risk.

Released 2026-11-07. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.40).

## New

- **Monitor ready tasks.** In the desktop app, **▶ Monitor ready tasks** (in the top bar, and on the current iteration's card) has Allomos work your ready tasks without you: it opens a new agent session in a terminal for each ready task, one at a time, and starts the next only when the last one is finished. When nothing is ready, it waits and checks again at the frequency you choose. You pick which tasks (the current iteration, all ready tasks, or one iteration), the agent (**Claude Code (terminal)** or **Codex (terminal)**) and the run mode. While it runs, a status line shows the task being worked, with **↻ Check now**, the check frequency and **■ Stop** (which ends after the current task). The dialog says how to let the chosen agent run without stopping to ask for permission; Allomos never changes an agent's permissions. The Claude app, the Codex app and Manual cannot be chosen yet, and the dialog says why.

## Also

- **Proceed… is now Work on it….** The button on a task nobody holds, and its dialog (**Work on it with an AI agent**), use the new name; what it does is unchanged.
- **Restored tabs load when you switch to them.** When Allomos starts again, it brings back every taskbag tab you had open but loads only the one in front. The others show their saved project name and load the first time you switch to them, so starting is quicker.

Released 2026-11-12. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.58).

## New

- **Prepare a handoff… replaces Hand over to another agent….** The button beside a task's title now opens a short dialog: it shows a prompt asking the session that holds the task to write its handoff note, commit and push its work to the working branch, release the task and then stop. **Copy the prompt** copies it; **Open its session** opens the session that holds the task (in the Claude app or a terminal) and copies the prompt too, so you paste it there and send it. The dialog no longer asks who goes on with the task and shows no waiting: close it at any time. Once the task is released, start whoever goes on with it with **Work on it…**.
- **It tells you when the holder looks gone.** When the session holding the task has never sent a heartbeat, or has gone silent past the project's limit, the dialog says so and offers **Take over…**. When the session cannot be opened (for example, it was not recorded when the task was claimed), the dialog says why and leaves only copying.

## Also

- **Preparing a handoff changes nothing in the taskbag.** No handoff request is written into the task any more, so `alm` no longer shows a "handover requested" notice. Requests written by earlier versions are still read, and are cleared as before when the task is claimed, released, finished or dropped.

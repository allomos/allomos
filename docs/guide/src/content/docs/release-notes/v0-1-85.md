Released 2026-11-27. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.85).

## New

- **Updated Antigravity model list with per-model reasoning efforts.** Settings now read format version 2 of the model list (while remaining compatible with version 1), so each model shows only the reasoning effort levels it actually supports—and models that take no effort show Default only. Antigravity now offers all 11 current models, including Gemini 4 Neon, Hydrogen, Carbon, Argon, Gemini 3.8 Flash, Claude Opus 5.5, Claude Sonnet 5.5, GPT-OSS 120B, and the three Orchestrator variants.

## Also

- **Standardized agent worktree location.** Updated shared agent instructions and `alm` prompts so task worktrees are placed under `.worktrees/<short-name>` inside the project folder.

Released 2026-11-10. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.52).

## Fixed

- **Connect with the agents asks only for Allomos's instructions.** When you connect an agent, Allomos now asks it only to add Allomos's instructions to its instruction files (AGENTS.md and CLAUDE.md). It no longer asks the agent to look for existing tasks, to move in an older taskbag, or to update out-of-date files. Those jobs stay in **Update the Taskbag…**. The Connect panel no longer shows the task-search line.
- **Antigravity always shows in the agent line.** The agent line lists Antigravity after Codex, as it lists Claude Code and Codex, even before Antigravity has reported anything.

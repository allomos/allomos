Released 2026-11-09. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.49).

## New

- **Running monitors in one place.** The tab bar's **Monitors** button and the Window menu's **Running Monitors** item list every monitor running on this computer, with **Open**, **↻ Check now** and **■ Stop** for each.
- **Monitors without the app.** `alm monitor start`, `alm monitor check`, `alm monitor stop`, `alm monitor status` and `alm monitor list` work with the app closed. A monitor started from `alm` shows in the app's status bar when the app is open, and the app can check or stop it. `alm monitor list` works from any folder and lists this computer's runs.
- **Several sessions per agent.** One agent can have several sessions at once on the monitor's ready tasks, each claiming its own task first.
- **Difficulty range per agent.** In **Monitor ready tasks**, each agent can be given a range of difficulties, from 1 to 5 by default.
- **Lost tasks are taken over.** A task whose session went quiet (its account ran out or was switched) is lost. Ready tasks come first; then **Monitor ready tasks** offers lost ones to a new session. The task pane shows **Take over…** beside **Open** only while a task is lost; it opens a dialog to pick an agent. `alm claim` takes a lost task over too.

## Fixed

- **The monitor's waiting notice names the app.** The "waiting for you" notice comes from Allomos itself, not from the script editor.
- **The status bar lines up.** Its links and buttons sit on the bar's middle line.

## Also

- The monitor's sessions, tabs, notifications and request text now live in one shared part of the code, so the app and `alm` run monitors the same way.

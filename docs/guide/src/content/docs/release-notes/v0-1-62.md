Released 2026-11-15. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.62).

## New

- **A clearer dependency tree.** With **Show › Dependency tree** on, each row starts with a round node whose colour changes with the level, and a line in the same colour runs down from the parent and turns into each task under it with a rounded corner. The node is the fold button: click it on a task with tasks under it to fold them away (it shows +) and click again to unfold them.

## Also

- Decision 0028 sets out the plan for one queue of everything that needs a person: a separate **Waiting for you** window that follows the project in front, one row per task, with agents waiting on you first and then by risk. It is not built yet.

Released 2026-11-24. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.81).

## New

- **Open task details from any task ID in monitor panels.** Every existing task ID shown in the monitor panels is now clickable and opens that task's details directly.

## Fixed

- **Quiet Antigravity permission rules and heartbeat prompts.** Fixed push/deny rules, taskbag allow rules, and heartbeat prompts for quiet monitored Antigravity sessions so allowed pushes and taskbag updates run without false blocks.
- **Approval-waiting status only counts while the session's tab is open.** Once a monitored Antigravity terminal tab closes, its confirmation mark is no longer reused by another session, the closed session stops showing as waiting for approval and recovers under normal heartbeat rules, and finishing it no longer clears another session's mark.

Released 2026-10-22. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.18).

## New

- **The Allomos mark greets you.** When a window opens, the mark plays its waiting animation once, in its own size and place, then stays still. The About window does the same.
- **Old quota figures are asked for again.** When an agent's quota is missing or more than 30 minutes old, `alm claim`, `label`, `release`, `done` and `handoff` ask the agent to report it. The quota chip now says old ages in hours or days instead of a long run of minutes.

## Fixed

- **Show in Finder is next to the taskbag path.** The button now sits on the path's own line, right after the path, and the agents line keeps its own row.

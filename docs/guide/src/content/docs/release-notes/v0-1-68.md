Released 2026-11-16. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.68).

## New

- **Monitored Codex sessions can edit project files.** Automatically started sessions can now edit project files without a prompt for each change, while your own Codex settings stay the same.

## Fixed

- **Monitoring frees a slot when another session claims a task.** The task leaves the monitor's active list, and the panel says who claimed it.
- **Heartbeat instructions help keep unshared changes local.** `alm` lists the files to save and warns against broad Git commands in the taskbag.

## Also

- **Codex gets Git commands it can run directly.** When Codex holds a task, `alm` names the taskbag folder and prints commands without `git -C`, one command at a time.

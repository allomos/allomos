Released 2026-11-08. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.44).

## New

- **Every audit setting in one place.** **Project settings → Audit** now reads from top to bottom: **Always recorded** (what the history always keeps), **Identity**, **Separation of duties**, **Outside witness**, Retention with **Remove personal details…**, and **Change types**. Outside witness shows the taskbag's checkpoints and has **Make a checkpoint now**; its own switch stays greyed out until the witness service is built. **Remove personal details…** does what `alm redact` does, and is refused during a legal hold. Every change is recorded in the history, and turning a control off asks why.
- **Settings → This computer.** It shows this computer's **Signing key** and where it is kept, **Export public key…** saves the public key to a file, and **Last seen history** shows, for each project, the last checkpoint this computer saw and whether the taskbag still has it. **Replace key…** makes a new signing key: in every recent taskbag, the old key is retired with a last signed event and the new key is added, and changes signed with the old key still check.
- **Changes made on Windows are signed too.** On Windows the signing key is kept in the Credential Manager, so a taskbag in `allomos/8` gets signed changes from Windows as well as from macOS.
- **A blocked task goes on by itself.** When the last task blocking another one is done or dropped (with `alm done`, `alm drop` or the app's buttons), the blocked task becomes ready again (or in progress, if someone holds it), as `alm unblock` would; its handoff note says which blockers finished. A dropped blocker now counts as finished.

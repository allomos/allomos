Released 2026-10-24. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.23).

## New

- **Iterations have word IDs.** An iteration's ID is `I-` and a short word, such as `I-knit` or `I-forge`, instead of a number that looks like its place in the plan. `alm add iteration` without an ID picks an unused one, and `alm rename iteration <old> <new>` renames an iteration together with every task planned in it.
- **Each iteration shows its place number.** In the app, an iteration's place in the plan (1, 2, 3…) appears beside its ID, so the order stays easy to read.
- **Move an iteration in the plan.** `alm move iteration <id> --before <id>` (or `--after <id>`) puts an iteration in a new place, with no taskbag files edited by hand.

## Fixed

- **Heading counts stay on one line.** The count on the right of an area or iteration heading ("142 of 142 done") no longer wraps "done" onto a second line as task numbers grow.
- **The Update the taskbag dialog scrolls.** When it lists many old handoff files, the list scrolls and the buttons stay in view.
- **The Chinese name of the backlog state is 储备.** It no longer reads like ready (就绪).

## Also

- AI agents keep working through `alm`; an MCP server for agents is put off for now.

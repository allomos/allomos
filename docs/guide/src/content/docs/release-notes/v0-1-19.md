Released 2026-10-22. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.19).

## New

- **The task pane is easier to read.** The responsible person, the agent, the check and the session each have a row of their own.
- **History names the agent.** Each change in a task's history says which agent made it.

## Fixed

- **"X of Y done" leaves dropped tasks out.** An area or iteration whose tasks are all finished, apart from one that was dropped, now reads 25/25 instead of 25/26.

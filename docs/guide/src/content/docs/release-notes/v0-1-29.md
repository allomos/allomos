Released 2026-10-27. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.29).

## New

- **Installing after a release is now your choice.** When you write `alm guide github release` in the conversation, the AI agent publishes the release and checks it, then stops. It downloads and installs the release on this computer only when you add `install` (`alm guide github release install`, also with `minor` or `major`). `no install` is no longer needed.

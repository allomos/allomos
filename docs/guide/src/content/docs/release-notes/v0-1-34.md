Released 2026-11-02. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.34).

## New

- **The Show filter above the task list is a panel of ticks in two groups, State and Label.** Everything starts ticked, so every task is listed; untick a box to hide those tasks. Several states can now be shown at once.
- **Each label has a Yes and a No**: Yes is the tasks that have reached that label or a higher one, No the tasks that have not. For example, untick human verified's Yes to see what a person has not checked yet.
- **Each group has Select all and Clear all, and the ↻ beside the filter shows every task again.** A button that has nothing to do turns grey instead of disappearing, and when the ticks leave the list empty the panel says why.

## Also

- **The filter's earlier choices All states, Not done and Needs a human are gone**: the ticks cover them. A state you had chosen comes back as that state alone.

Released 2026-11-11. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.56).

## New

- **Check the agent line again now.** The line under the taskbag's name (whether the instruction files tell the agents about Allomos, the quota left, and how many changes made here are not shared yet) ends with a **↻** button. Press it to check again at once; hovering it says what it checks.

## Fixed

- **Much less CPU in the background.** The agent line used to check every 4 seconds and read the taskbag's whole change history each time, so a project with a long history kept Allomos busy even with its window in the background. It now checks when the project opens, every 30 minutes, and when you press **↻**, and it reads the history again only when it has changed. On a project with about 4,800 changes, Allomos used about a tenth of the CPU it used before while idle.

Released 2026-11-12. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.59).

## New

- **A running monitor is edited in one dialog.** Its **Edit monitor…** dialog changes the monitor's scope and mode too. The Auto-monitor section shows each monitor in a panel you can fold. `alm monitor set` changes a monitor from the command line the same way.
- **Start another monitor while one runs.** While a monitor runs, its button reads **Start another monitor…** instead of **Start**.

## Fixed

- **A takeover keeps unpushed work.** A takeover can now commit and push what the former worktree has not yet pushed, so nothing is lost.

## Also

- Decision 0023 records that Allomos may orchestrate agents fully automatically; the plan no longer lists this as a non-goal.

Released 2026-11-07. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.41).

## New

- **Several labels per task, and a label table.** A task can now carry several labels at once, with no order between them. Every project starts with five built-in labels: **locally verified by agent**, **deployed and verified by agent**, **locally verified by human**, **deployed and verified by human** and **AI decisions to review**; the project's own labels join them in its label table. `alm label <id> "<label>"` adds a label and keeps the others (`--remove` takes one off). A label new to the project joins the table, and `alm` says so, in case it was a typo. `alm labels` shows the table; `alm labels add` and `alm labels remove` change it. The desktop app's screens for labels (its Progress ladder settings among them) change in a later release.
- **The human check is a label.** `alm checked <id>` gives a finished task **locally verified by human**, or **deployed and verified by human** when an agent had deployed and verified it (`--deployed` or `--locally` chooses). `alm done <id>` without `--without-human-check` now needs one of these two labels. A finished task without a "by human" label is *to check*, as before. `alm ai-decided` adds **AI decisions to review** and `alm reviewed` removes it.
- **Taskbag format allomos/7.** These labels need the taskbag format `allomos/7`. This version still reads an older taskbag, but changes nothing in it until it is upgraded: **Update the taskbag…** in the desktop app, or `alm upgrade --confirm` (`alm upgrade` alone first says what it will do). The upgrade drops the old *drafted* and *implemented* steps, renames *locally verified* and *deployed and verified* to "… by agent", turns *human verified* into **locally verified by human** (or **deployed and verified by human** when the task had been deployed first), and adds **AI decisions to review** to tasks whose AI decisions are not reviewed yet. Older Allomos versions refuse an upgraded taskbag, so install 0.1.41 wherever the taskbag is used before you upgrade it.

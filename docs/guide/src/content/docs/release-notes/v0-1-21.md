Released 2026-10-23. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.21).

## New

- **Handoffs are written into the task.** `alm handoff <id>` writes where the work stopped, the one next step and who it waits on into the task's handoff note, adds anything that must not run twice under the description's Evidence, and records who handed it off in the task's history. The next session sees it with `alm next` or `alm show`, so a handoff no longer goes stale in a file of its own.
- **No more handoff files.** The Handoffs tab, "Latest handoff" in the task pane and handoff files in search are gone; the task's handoff note stays. **Handoff Settings…** is now in the File menu. A taskbag that still has an old `handoffs/` folder shows **Update the taskbag…**, which asks the agent to move what is still useful into the tasks and remove the folder.
- **A reminder to check file size before planning.** After `alm claim`, and in `alm guide workflow`, agents are reminded to check whether a file they will change is too big, and if so to plan a refactoring of only the part they will touch.

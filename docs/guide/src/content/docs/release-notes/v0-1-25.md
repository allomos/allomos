Released 2026-10-26. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.25).

## New

- **The companion page looks like the desktop app.** On a paired phone or computer, the browser shows the taskbag with the desktop app's own interface: tabs, filters, search, sorting, the task pane and who each task waits on. It has a wide layout and a phone layout, updates within seconds, and asks you to open the desktop app when it is closed.
- **Change tasks from a paired device.** From the companion page you can change a task's state and label, edit its title, description and handoff note, and add tasks, areas and iterations. The desktop app checks and makes each change with its own rules, and the history names the person and the device, like "Sam (iPhone)".
- **Project folders in Settings.** The taskbag's settings have a **Project folders** section to bind, rename, locate and unbind its folders; `alm folder` does the same. Binding a folder writes Allomos's section into that folder's AGENTS.md, and unbinding removes only that section.
- **Folders on tasks.** The task pane shows and changes a task's folders, and the task list shows them as chips, with a **Folder:** filter.
- **An Agents section in Settings.** It shows, for each AI agent, in how many of the taskbag's project folders it is set up, with **Set Up…** for the folders it is missing from.
- **Update the Taskbag… can upgrade to allomos/6.** A taskbag still in `allomos/5` now shows as needing an update. **Update the Taskbag…** asks the agent to upgrade it to `allomos/6`, which project folders need, and warns first that older Allomos versions will then refuse the taskbag. Nothing changes until you choose **Go ahead**.

## Fixed

- **The header's Settings button lines up.** It sits level with the taskbag's name, and its gear is evenly round.

## Also

- AI agents follow the handoff limits only while they hold a task. When one is reached, the agent writes the handoff and releases the task, so the next session can pick it up.

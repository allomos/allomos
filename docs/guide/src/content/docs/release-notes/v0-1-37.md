Released 2026-11-02. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.37).

## New

- **The notices run across the top of the window.** The refresh line (with **Refresh now**), "Changes are recorded as …" and "This project has no iterations yet" now sit in one band above both the task list and the task's details panel, and the details panel starts level with the list. They stay in place when the panel opens or closes.

## Fixed

- **Tasks worked in the Claude desktop app open there again.** When an agent in the Claude desktop app takes a task and records only its session ID, `alm` now says the desktop details are missing and gives the command that adds them, so **Open in Claude** opens the session in the Claude app instead of **Resume in terminal** opening a new terminal. An agent working in a terminal records `--session-kind terminal` and is asked nothing more. Tasks recorded before this stay as they are until their own session runs `alm session`.

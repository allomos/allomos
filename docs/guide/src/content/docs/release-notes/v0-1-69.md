Released 2026-11-17. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.69).

## New

- **Quiet monitored Codex sessions can work without approval prompts.** They can edit project files, access the network and use Allomos on this Mac. These settings apply only to the session Allomos starts; your Codex settings remain unchanged.
- **Open a blocker from task details.** Click a linked task ID to show that task in the same details pane.

## Fixed

- **Monitoring handles exhausted quotas.** It checks quota before opening a session, keeps the task ready when quota is gone, shows when it will check again, and retries after quota returns.
- **Sessions that never claim a task no longer appear as working.** Monitoring marks them as not started after 10 minutes, shows the reason when it can read it, releases their slot and gives the task out again.
- **New sessions show as starting until they claim the task.** This keeps the panel from suggesting work has begun too early.

## Also

- **The monitor panel and status report show matching session states.** Paused, starting and not-started sessions include the same details.

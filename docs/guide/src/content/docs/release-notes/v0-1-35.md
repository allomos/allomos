Released 2026-11-02. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.35).

## New

- **Each state has a brighter colour of its own**: backlog brown, ready blue, in progress green, waiting yellow, blocked red, done purple, and dropped grey and struck through, in light and dark mode.
- **The state word is a small semibold label on a light tint of its colour**, in a task's row and in the details pane, so you can tell states apart at a glance. The Show filter and the Waiting on / Blocked by text use the colour alone.

## Fixed

- **When `alm` reminds an agent to report its quota, the command it suggests names the agent** (`claude-code`, `codex`), not the session's name. Agents that copy it no longer report a session as an agent, so the AI agents line at the top of the app no longer gains grey entries such as loop-hourly.

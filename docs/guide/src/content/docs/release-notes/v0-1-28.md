Released 2026-10-27. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.28).

## New

- **The session's button sits in the task's title.** When a task has a recorded session, its **Open in Claude** or **Resume in terminal** button now follows the title's **Change** button, instead of the row under the title. That row shows only the human check again, as before 0.1.27. The button in the Session row stays.

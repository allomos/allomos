Released 2026-11-10. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.50).

## New

- **Monitoring continues after a restart.** When the app restarts or updates (or reopens a project after a run stopped), **Monitor ready tasks** continues from its saved settings on this computer without asking to start again. Open sessions still appear in the status bar, their 30-second tab-close countdowns finish, and a run that ended while the app was closed is counted in the last-run summary.
- **Multiple accounts per agent in the monitor.** In **Monitor ready tasks**, extra accounts can be added for Claude Code and Codex. Each account has its own row with its own session count and difficulty range, and its sessions start with that account's folder.
- **Reminder before restarting or quitting while monitoring.** Restarting to update or quitting the app while monitoring is running brings up a reminder saying that automatic monitoring keeps running in the background and how many open sessions will finish their tasks, with a choice to cancel.
- **Antigravity receives the Connect request directly.** Connecting Google Antigravity now passes the request directly to `agy` on the command line instead of copying it to the clipboard.

## Fixed

- **Disabled Start button is grey.** In **Monitor ready tasks**, the **Start** button (and other disabled primary buttons) appears grey when no agent is ticked.

## Also

- **Running Monitors** is now in the View menu instead of the Window menu, and the running monitors dialog no longer shows the footer note at the bottom.

Released 2026-11-17. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.71).

## Fixed

- **Antigravity sessions no longer stop to ask for file access.** Sessions Allomos starts add the taskbag's folder and the taskbag's other project folders to their workspace, so in auto mode they read and write them, such as the project notes, without asking. Your Antigravity settings stay as they are.
- **Quiet Codex sessions no longer fail when they write to the taskbag.** Codex sessions the monitor starts can also write the taskbag's folder and its other project folders, so changing a file there no longer fails without a word. Committing and pushing there still needs Allomos's rules for Codex. Your Codex settings stay as they are.

## Also

- **`alm` was reorganized inside.** Its code is split into smaller parts; nothing you use changes.

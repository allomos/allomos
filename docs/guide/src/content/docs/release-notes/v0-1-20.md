Released 2026-10-22. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.20).

## New

- **Iterations have a state.** An iteration is planned, active or closed, and at most one is active. New tasks go into the active iteration, and `alm next` lists it first. When none is marked active, the first planned one counts as active. Active and closed iterations have badges and colours of their own, and a closed one keeps the usual grey look. Taskbags are moved to the new format (`allomos/5`) when you open them.
- **The Show filter has Not done.** It lists every task that is neither done nor dropped, right after All states.
- **The mark's opening animation is shorter.** In the top bar and the About window it now takes 3 seconds instead of 8.

## Fixed

- **The refresh line and the name line share one line.** Above the task list, the refresh comes first and "Changes are recorded as …" second, so the list starts higher.

## Also

- AI agents now ask for approval in the conversation; `alm confirm` is kept for jobs given from the Allomos app.

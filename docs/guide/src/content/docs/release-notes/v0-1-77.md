Released 2026-11-20. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.77).

## New

- **Every check's result, one line each.** Agents now record each check they ran as passed, failed or not run, and the Evidence screen lists them with failed and not-run checks first.
- **Screenshots of failed checks.** An agent can attach up to three screenshots to a failed check. The Evidence screen shows them as thumbnails under that check; click one to see it full size. They are kept in the taskbag, so they show on another computer too.
- **Evidence in the terminal.** `alm show <id> --evidence` prints the same evidence as the Evidence screen, in the same order.
- **Requeue a stalled task from the monitor.** In the monitor panel you can send one stuck task back to the queue without restarting the monitor; the rest of the run carries on.

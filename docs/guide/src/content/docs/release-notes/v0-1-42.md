Released 2026-11-08. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.42).

## New

- **The app shows labels the new way.** The task list and the task pane show every label a task carries as a small chip; the two "by human" labels are drawn solid. In the task pane, **Labels → Change** opens a list of every label in the project's label table to tick or untick. **Checked** adds **locally verified by human**, or **deployed and verified by human** when an agent had deployed and verified the task, and the line under the button says which. **Settings → Tasks → Labels** shows the five built-in labels with what each means, then the project's own labels, which you can rename, add or remove. The old Progress ladder settings are gone, since labels have no order.
- **The Show filter is a grid.** **Show**, above the task list, opens a table with one row per state, each row tinted in its state's colour. Its columns are **Checked by a human** (either "by human" label) and then each other label, each with Yes and No. A task is listed when it matches any tick in its state's row. The tick in front of a state sums up its row (all, some or none ticked); click it to tick or untick the whole row. Everything starts ticked, so every task is listed.
- **Presets, and Needs you.** The Show filter has two tabs, **Presets** and **Custom** (the grid). The presets are All tasks, Not finished, Ready to start, In hand, Needs you and Finished; each says what it ticks and how many tasks it lists now. **Needs you** lists the same tasks as `alm human`: finished tasks no person has checked yet, every waiting task, and any task with AI decisions to review. A preset only sets the ticks in Custom; change one there and it is no longer that preset. After a monitor run that left something for you, the line beside **Monitor ready tasks** ends with "K need you": click it to pick Needs you.

## Fixed

- **Opening the Show filter no longer freezes the window.** In 0.1.41, opening **Show** on a taskbag in format `allomos/7` turned the window blank and it stopped responding, until Allomos was quit and opened again. The panel now opens at once.
- **Every built-in label has its meaning.** After a taskbag was upgraded to `allomos/7`, three built-in labels could show no meaning in `alm labels` and in the label table. They now show the built-in meaning.

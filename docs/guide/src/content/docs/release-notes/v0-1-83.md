## New

- **Review new tasks before they become ready.** In Taskbag Settings → Tasks, enable the new-task approval setting to keep tasks created by agents in the backlog until you approve them. The setting defaults to off. In goal runs, agents can still make tasks ready under the approval already given for the goal. Use `alm new-task-settings` to view or change the setting from a terminal.

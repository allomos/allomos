Released 2026-11-16. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.66).

## New

- **Editing one task now updates much faster.** When you change a task's status, title, description or other details, Allomos updates that task and the affected parts of the view in place. On this project's taskbag, one edit now takes about a quarter of a second instead of about two seconds.

## Fixed

- **The agent options for automatically monitoring ready tasks are easier to find.** The notice and option for a selected agent now appear right below that agent in the list. They stay hidden until that agent is selected.

## Also

- Local Claude workspace files are ignored by Git.

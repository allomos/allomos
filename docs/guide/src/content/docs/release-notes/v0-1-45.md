Released 2026-11-09. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.45).

## New

- **One Settings dialog.** The app's Settings window and each taskbag's settings are now one dialog in the project window. On the left are two groups: **Allomos** (**General**, **This computer**), which affects the whole app on this computer, and a group named after the tab's taskbag (**General**, **Project folders**, **Agents**, **Tasks**, **Handoff**, **Audit**), which is shared with everyone who uses that taskbag. The top line of each section says which group it is in. **Settings…** in the menu (Cmd+, / Ctrl+,) opens it at the Allomos group; **Settings** beside the taskbag's name opens it at the taskbag's group.
- **Automatic updates can be turned off.** Settings → Allomos → General → **Automatic updates**, on by default. When it is off, Allomos no longer asks GitHub for a newer version by itself or downloads one in the background; **Check for Updates…** in the menu still works.
- **The outside witness can be turned on.** Settings → your taskbag → Audit → **Outside witness**. Once you confirm with **Turn on and send fingerprints**, each checkpoint's fingerprint (never the taskbag's content) is sent to a time-stamp service (RFC 3161), and the signed receipt it sends back is kept in the checkpoint. FreeTSA is the default; DigiCert, Sectigo and GlobalSign are listed, or you can enter your own provider's address, with an optional second service. `alm audit` checks each receipt against its checkpoint and lists receipts that expire within a year. Without a connection, fingerprints wait and are sent with a later checkpoint. With alm: `alm audit-settings --witness on|off`.
- **How often the witness makes checkpoints.** Outside witness → **How often**: **Every day** (chosen when you turn it on), **At each approval and human check**, or **Only when I ask**. With alm: `alm audit-settings --witness-when`.
- **Audit and standards.** A new [user guide page](/allomos/audit/standards-map/) says what Allomos always records, what each audit setting does, and which settings help meet ISO/IEC 27001, SOC 2, 等保 2.0 and other standards. **See which settings each standard needs** in the Audit settings opens it in the window's language.
- **Google Antigravity.** Allomos finds Antigravity's `agy` command and lists it as **Antigravity (terminal)**: it can ask it to set up the shared rules, **Monitor ready tasks** can start agy sessions, a session recorded under Antigravity reopens with `agy --conversation`, and Antigravity's quota shows in the header.

## Fixed

- **Left-over blocked tasks go on too.** A task whose blockers had all finished before 0.1.44 stayed blocked. Now `alm next`, starting **Monitor ready tasks** and **↻ Check now** let such tasks go on, and the monitor says which ones in a line under its status bar.

Released 2026-10-25. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.24).

## New

- **Each taskbag has its own settings.** The header shows the taskbag's name with a **Settings** link. **General** shows the name (with **Rename**), the format and the location (with **Show in Finder**), and offers **Update the Taskbag…** when the taskbag is older. **Tasks** sets the task language and changes the progress ladder. **Handoff** holds the handoff rules, which replace **Handoff Settings…** in the File menu.
- **Devices on your network can view your tasks.** **File › Devices on Your Network…** turns on viewing from your local network; it is off until you turn it on. The window shows the address, a QR code and the certificate's fingerprint. A phone or another computer opens the address and asks with a name; once you approve, it types the 9-digit code the window shows. Paired devices are listed and can be removed at any time. Devices can only read, not change anything.
- **One taskbag can track several project folders.** Each task names the folders it belongs to (`alm add task --folder`, or `--no-folder`; `alm folders` changes them), `alm list --folder` filters by folder, and `alm next` run inside a folder lists only that folder's tasks. This needs the taskbag format `allomos/6`: an existing taskbag keeps working as it is until `alm upgrade --confirm` converts it (`alm upgrade` alone shows what it will do).
- **A task can go back to backlog.** A ready, waiting or blocked task that nobody holds can return to backlog from the app's state menu, or with `alm backlog <id>`. When it can't, the menu says why.
- **Update the taskbag can translate it.** A checkbox in **Update the taskbag…** asks the agent to also translate the tasks, card files and project notes into the app's language. It is unchecked each time.
- **Open Recent opens a new window.** Choosing a taskbag under **File › Open Recent** opens it in its own window, or brings forward the window already showing it, instead of replacing what the front window shows.
- **`alm list --by iteration` shows the whole plan.** Every iteration has a heading, empty ones too, with its place in the plan (1, 2, 3…) as the app shows it.

## Also

- A taskbag written by a newer Allomos no longer fails to open because of a field or value this version doesn't know: it is kept as it is, and listed as a reminder.

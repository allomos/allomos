Released 2026-11-09. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.48).

## New

- **Several agents at once.** In **Monitor ready tasks**, **Agents** is now a set of check boxes: choose one or more (an agent that cannot run unattended is shown with why). Each chosen agent works one ready task at a time, in a session of its own; each session claims its task first, so no two work the same one. The status bar lists each session with its link, and its menu adds an agent or takes one off: an agent added gets tasks from the next check on, and one taken off finishes the task it is working, then gets no more. **■ Stop**, **↻ Check now** and how often it checks apply to all of them.
- **Notifications from the monitor.** On macOS, **Monitor ready tasks** sends a system notification when a task's session parks a question for you, and once when no task is ready.
- **Difficulty.** Every task has a difficulty from **1 · Very easy** to **5 · Very hard**, as the agent that added it judged; a task without one counts as 3. The task row and the task pane show it (the default greyed), and the pane changes it. With alm: `alm add task --difficulty <1-5>`, `alm difficulty <id> <1-5>` (or `--none`), and `alm next` / `alm list --difficulty 1-3` to list only some levels. Older Allomos keeps the field as it is.
- **Quiet mode never stops to ask.** The shared rules (alm's section v34 in AGENTS.md) and the guides now say: in a quiet run, the agent decides wording and look itself, builds and merges them, and records each choice with `alm ai-decided` for review. Only data formats, removing things, permissions and security, cost, outside effects and changes to the plan go to the approver first. Questions are asked while planning; each parked question carries the agent's proposal; finished work is merged first, so a parked question does not hold it back.

## Fixed

- **The task pane scrolls with its head in view.** The pane's head stays at the top while a long task scrolls, and its close button and back arrow have a visible border. On a phone-width window the pane fills the screen's height, so long tasks can be scrolled.

Released 2026-11-10. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.51).

## New

- **Antigravity requests are sent at once in every dialog.** In the Update, Move, Build an App, Translate, Move cards, Proceed, Take over and Upgrade dialogs, Antigravity's request is now sent directly to `agy` and no longer asks you to paste it and press Enter. Other agents are unchanged.
- **The iteration name opens that iteration.** In the Monitors list, the iteration name is a link (with an icon) that shows that iteration in the plan. The separate **Open** button is gone.

## Fixed

- **The tab closes only after the agent is idle.** When a done task's tab is due to close, the 30-second countdown now waits until the agent has stopped working. A task that is still pushing or merging gets no line and no exit command, and idleness is checked again before the command is typed.
- **The tab still closes if the monitor stops.** The countdown now runs in its own background process, so a stopped or restarted monitor no longer leaves the Claude or Codex tab open.
- **Long names wrap inside their button.** A long area or iteration name wraps inside its button, so **Edit** stays beside it.

## Also

- The hidden `alm monitor close-tab` command no longer needs the taskbag, so it runs from any folder.

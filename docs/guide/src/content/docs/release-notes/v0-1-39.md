Released 2026-11-04. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.39).

## New

- **Hand a task to an AI agent from its row.** Every task row now shows **Held by**: the session that holds it, or a grey **Nobody**. In the desktop app, a task nobody holds that is not done or dropped also shows **Proceed…**. It opens a dialog that says what Allomos found and what will happen; choose an agent and click **Open**, and Allomos opens it in your project folder with a request already typed in, asking it to claim the task and work on it. Nothing is sent until you send it yourself. A task in Backlog is approved when you click Open. For a blocked or waiting task the dialog becomes **Ask an AI agent about this task**: the agent tells you why it is stopped and asks what you want before changing anything. **Edit the request…** lets you change the text for this one time, and **Manual** shows the request with **Copy** to paste into an agent yourself.

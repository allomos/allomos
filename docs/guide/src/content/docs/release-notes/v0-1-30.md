Released 2026-10-27. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.30).

## New

- **alm says what a task is still missing.** After a command that changes a task (claiming it, a new label, finishing it), `alm` lists what the task still lacks, such as the session details the Allomos app needs to reopen the agent's session, a working branch or a handoff note, each with the command that fixes it. The new `alm session` command fills in the session details later, so the task's **Open in Claude** (or your agent) button works again.
- **Translate the taskbag also translates iteration names.** When you translate a taskbag into another language, the agent now renames each iteration too, so the plan no longer stays in the old language while the tasks move to the new one.

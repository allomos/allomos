Released 2026-11-11. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.54).

## New

- **A clearer start page.** The start page now shows its three choices inside the card, one under the other: **Create a new project…**, **Set up an existing project…** and **Open recent…**. Each has an icon and a one-line hint under its name that says what it does, for example *Go back to a project you opened before.* Nothing sits under the card any more, and the page fits the usual window without scrolling.

Released 2026-11-10. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.53).

## New

- **Two ways to start, side by side.** The start page now shows **Create a new project…** (formerly **Build a new app…**) right beside **Set up an existing project** (formerly **Start**). **Open recent…** stays below them. The dialog it opens is now called **Create a new project**.
- **Separate switches for checking and downloading updates.** Under **Settings › General › Updates** there are two switches, both on by default. **Check for updates automatically** asks GitHub once a day for a newer version. **Download updates automatically** then downloads and checks its installer in the background; it is greyed out while checking is off. **Check for Updates…** in the menu always downloads, whatever the switches say.
- **See the download, and stop it.** While a new version's installer downloads, the update notice shows how far it has got (for example *Its installer is downloading: 40%*) with a **Cancel** button, and the menu item reads **Downloading Allomos 0.1.53… 40%**. Cancel stops the download and removes the partial file.

## Fixed

- **An update is offered only once its installer is ready.** The update notice and the menu now offer **Restart to Update to Allomos …** only after the new installer is downloaded and checked. Before that, the menu's **Download Allomos …** item waits, greyed out, instead of opening the release page. When a release has only its source code so far, **Check for Updates…** says the installer is being prepared, and no Download banner appears. The release page opens only when no installer can be had for your computer.

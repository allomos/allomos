Released 2026-11-19. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.74).

## New

- **Choose a model and reasoning effort for each agent.** When starting task monitoring, pick values from the online model list or keep Default to use the agent’s own settings. Refresh the list in the dialog, or change its address in General settings; a saved list remains available offline.
- **Exit a monitor immediately.** While waiting for tasks to finish after stopping, Stop now exits that monitor and keeps started agent sessions, tasks and existing work. Lost tasks now have a clear warning.

## Fixed

- **Less clutter in task titles.** Dependency trees no longer repeat “not shown” blocker labels beside task titles; the blocker column still lists them.
- **Extra accounts keep their identity.** Starting a background monitor preserves the selected additional agent account.

## Also

- **Source-file size checks.** Workspace tests now keep oversized source files from growing and report when their recorded limit needs updating.

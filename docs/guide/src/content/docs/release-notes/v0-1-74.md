Released 2026-11-19. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.74).

## New

- **Pick model and effort per agent when monitoring.** The monitoring dialog lets you choose the model and reasoning effort for each agent, reading the available models from the online list (configurable in settings).
- **Automatic recovery for lost monitoring sessions.** The monitor panel shows lost sessions and tasks given up, frees their slots, and hands those tasks to a new session on the former branch. Stopping monitoring immediately warns about active tasks while keeping unfinished work intact.
- **Risk limits for high-risk tasks.** When enabled in project settings, `alm done --without-human-check` refuses high-risk tasks and quiet runs park high-risk merges for the approver. `alm classify` (without options) and `alm done` also list the risk rules, and `alm done` reminds you when no risk is recorded.
- **For You window follows the active project.** Switching between project windows updates the For You window to match the project you used last.
- **Clearer change sharing in the app.** Sharing details now show task titles with cleaner dialog styling, limit sharing to changed task files, and keep sharing reminders across restarts.

## Fixed

- **No duplicate blocker chips in the task tree.** Removed duplicate "not shown" blocker chips from tree task titles.
- **App commands ignore stray `ALLOMOS_TASKBAG` settings.** Commands run by the desktop app clear `ALLOMOS_TASKBAG` so they never write to another project's taskbag by mistake.

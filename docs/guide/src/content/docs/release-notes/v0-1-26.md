Released 2026-10-26. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.26).

## New

- **Open a task's Claude Code session from its pane.** The task pane's **Session** row now says where the session runs, in the Claude app or in a terminal, and has one button: **Open in Claude** brings the Claude app forward on that conversation, and **Resume in terminal** opens a terminal in the folder where the task was claimed and continues it with `claude --resume`. After the task is released or done, the row reads **Last session** and the button still works, so you can go back to the conversation that finished it. On the web and phone companions the row shows the text only.
- **`alm claim` records the agent's session.** An agent can pass `--session-agent`, `--session-id`, `--session-kind` and `--app-session-id` when it claims a task; the task keeps that session after release and done, and a new claim replaces it. A claim without them says what to pass.

## Also

- AI agents are asked to pass their session when they claim a task, so the Allomos app can reopen it.

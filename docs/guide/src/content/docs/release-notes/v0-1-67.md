Released 2026-11-16. [Download from GitHub](https://github.com/allomos/allomos/releases/tag/v0.1.67).

## New

- **Blocker lists now show every blocking task.** Unfinished blockers appear first in the blocking color, followed by completed or dropped blockers in the completion color. The same order appears in the task panel.

## Fixed

- **Finder-launched Allomos can now find terminal agents that need Node.** Codex and Claude Code installed with npm can be detected even when Node is outside the system `PATH`.

## Also

- **Waiting and blocked details can appear together.** A task that is waiting on a person and has blockers now shows both lines.

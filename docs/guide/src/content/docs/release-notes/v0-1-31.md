## New

- **Taskbags open as tabs.** Each window has a tab bar, like a browser. The **+** at the end of the bar, or **File → New Tab** (⌘T on macOS, Ctrl+T on Windows), opens a new tab; **File → Open Recent** opens a taskbag in a new tab, or brings its tab to the front if it is already open. Drag tabs to reorder them, drag one out to make a window of its own, or drop it into another window. A dot on a tab means that taskbag needs you.
- **Choose what opens when Allomos starts.** A new **Settings…** window for the whole app (⌘, on macOS; Ctrl+, on Windows) has **When Allomos starts**: **Reopen windows and tabs** (the default), **Open the last taskbag**, or **Open a blank window**.
- **Discuss first in Build a new app….** Tick **Discuss first** and the agent turns your description into the goal and waits; shape it together in that conversation, then tell the agent to go ahead, in any words, and it plans and builds the app.
- **On Windows, the Window menu lists every open Allomos window**, including ones opened with **File → New Window…**; choosing one brings it to the front.

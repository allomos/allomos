这一页带你从第一次打开应用，走到 AI 智能体按任务包开始工作。大约需要五分钟。

## 1. 获取应用

Allomos 0.1 运行在 macOS 上；Windows 版将在 0.2 推出。目前还没有下载：以后会出现在[发布页](https://github.com/mypals-ml/allomos/releases)。在那之前，需要从源代码运行应用（[开发者说明](https://github.com/mypals-ml/allomos/blob/main/docs/workflow/CODING_RULES.md#running-the-app)）。

## 2. 开始

Allomos 打开时如果没有项目，只显示一个按钮：**开始**。按下它，打开设置向导：一共四个简短的步骤，标着“第 1 步，共 4 步”等。

## 3. 建立任务包

1. **什么是任务包？** 第一步用几句话说明。按 **选择文件夹…**，选择你的项目文件夹。任务包会建在里面，名为 `.allomos/`。
2. **任务包文件夹。** 如果这个文件夹里还没有任务包，按 **建立任务包**。如果已经有了，Allomos 会说明并直接使用它。然后按 **下一步**。

Allomos 把任务包放在 Git 里保存，这样它的历史不会丢。如果文件夹还不是 Git 仓库，Allomos 会把它变成一个。它只提交任务包自己的文件，也从不向互联网发送任何内容。

## 4. 选择项目文件夹

项目文件夹里放着你的代码，以及 AI 智能体每次开始会话时读取的说明文件（`AGENTS.md` 和 `CLAUDE.md`）。它通常就是第 3 步选的文件夹。如果不是，按 **选择其他文件夹…**。然后按 **下一步**。

## 5. 连接 AI 智能体

选择一个 AI 智能体，按 **连接**。Allomos 会在你的项目文件夹里打开这个智能体，并预先填好一段请求。**在你自己发送之前，什么都不会发出。**

这段请求让智能体：

- 在 `AGENTS.md` 和 `CLAUDE.md` 里加一小节关于 Allomos 的说明，让以后每个新会话都知道怎样使用任务包；
- 找一找项目原有的任务，例如任务看板或待办清单。

如果智能体找到了任务，它会在 Allomos 里显示它的计划。选择 **继续**，把任务移进任务包；或选择 **取消**，让它们留在原处。

这一步可以按 **以后再说** 跳过，以后再从 **文件 › 连接 AI 智能体…** 进行。

:::note
已经在运行的智能体会话只在开始时读取 `AGENTS.md` 和 `CLAUDE.md`。请新开一个会话，让智能体知道 Allomos。
:::

## 6. 开始工作

在新的智能体会话里，请智能体先运行 `alm next`。它会取得下一项可以做的任务和最近的交接记录，认领任务，并把进度记进任务包。你在 Allomos 窗口里看到的是同样的任务。

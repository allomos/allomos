用 Claude Code、Codex 等 AI 智能体开发软件时，工作分散在很多个会话里。账号额度一用完，会话就可能突然停下，下一个会话什么都不知道。把工作交给队友时，也是同样的问题。

Allomos 的办法是：把项目的状态放在一个所有智能体和所有人都会读的地方——**任务包**。

## 任务包

任务包是项目里的一个文件夹 `.allomos/taskbag/`，里面是普通的文本文件：

- **任务**：计划做什么，每项任务要达到什么结果；
- 每项任务**由谁负责**：某个人，或某个智能体会话；
- 每项任务**做到了哪一步**，用标签表示，例如 *implemented*（已实现）、*locally verified*（本地已验证）；
- 任务在**等待什么**；
- 一个会话留给下一个会话的**交接记录**。

这些都是代码仓库里的普通文件，所以 Git 会保存它们的历史，项目到哪里，它们就跟到哪里。

## 谁在用，怎么用

| 谁 | 怎么用 |
|---|---|
| 你 | 在 Allomos 桌面应用里按领域查看任务、谁在做什么，以及交接记录。 |
| AI 智能体 | 用 `alm` 命令：`alm next` 取得下一项任务和它的交接记录，`alm claim` 认领任务，`alm release` 留下记录后交还任务。 |
| 队友 | 打开同一个代码仓库，大家看到的是同一批任务。 |

一个智能体的额度用完时，它会写下停在哪里。下一个智能体——换了账号，甚至换了一家公司的产品——运行 `alm next` 就能接着做。

发布于 2026-11-20。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.75)。

## 新功能

- **静默模式下的 Antigravity 会话自动拒绝高风险命令。** 在静默自动监测中，Antigravity 会话会通过拒绝规则直接拦截高风险命令（包括带 `git -C` 和 `git -c` 的写法），不再卡在推送确认上。
- **监测面板显示等待审批的会话并释放名额。** 当被监测的会话仍停在确认提示时，监测面板会将其标为等待审批、不会误判为失联，并释放该槽位让其他就绪任务继续运行。

## 新增

- **在「待你处理」里一次批准几个任务。** 勾选要批准的任务，或点「全选」，确认一次就一起批准。还不能批准的任务不能勾选，并说明原因。
- **写理由退回任务。** 待检查任务的「证据」一屏最下面、已完成任务的面板里，都有「退回…」：必须写理由，任务回到就绪。桌面应用里可以附上这一屏的截图。每条 AI 决定后面有「不同意…」，点了理由里先填好那条决定的原文。
- **被退回的任务先显示退回理由。** `alm next`、`alm show` 和 `alm claim` 在交接说明前列出谁、什么时候退回、写了什么，最近的在前。监测给被退回的任务开会话时，会先让代理读退回理由。
- **被退回的任务先派。** 同一迭代里，`alm next` 和监测把被退回的任务排在前面。

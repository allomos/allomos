发布于 2026-11-15。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.61)。

## 新增

- **「被阻塞」不再是一种状态。** 给任务设前置任务不再改它的状态；前置任务没完成时，列表和任务面板显示成比如「就绪 · 被阻塞」，前置任务完成后任务保持原来的状态。筛选菜单新增 **只看被阻塞的任务**。旧版本的任务包要先更新（**更新任务包…**），原来被阻塞的任务回到被阻塞前的状态。
- **排序菜单可显示依赖树。** **显示 › 依赖树** 把每个任务放在阻塞它的任务下面，带引导线，可以折叠；各棵树之间、同一父任务下的任务仍按所选排序排列。有多个前置任务的任务只显示一次，并注明它还依赖哪些任务。
- **AI 决定分成三种。** `alm ai-decided --kind` 可以记成用户看得到的、实现方法的原理或细节。前两种照旧列在 **待审阅的 AI 决定** 里；细节记在任务里，在任务面板中单独一段，不要求审阅。

## 其他

- 决定 0026 记录了「被阻塞」由前置任务算出；决定 0027 记录了什么算高风险，风险由智能体来定。
- 共享的智能体规则（AGENTS.md 第 v38 版）和各份指南都按新的阻塞规则改了。

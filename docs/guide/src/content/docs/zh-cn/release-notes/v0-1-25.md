发布于 2026-10-26。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.25)。

## 新增

- **伴侣网页和桌面应用一样。** 在配对的手机或电脑上，浏览器用桌面应用自己的界面显示任务包：标签页、筛选、搜索、排序、任务面板，以及每个任务在等谁。它有宽屏和手机两种布局，几秒内自动更新；桌面应用没开时，会提示你先打开它。
- **在配对的设备上修改任务。** 在伴侣网页上可以改任务的状态和标签，编辑标题、描述和交接笔记，新建任务、领域和迭代。桌面应用按自己的规则检查并执行每一处修改，历史里记下人名和设备，比如“Sam (iPhone)”。
- **在设置里管理项目文件夹。** 任务包的设置里有 **项目文件夹** 一节，可以绑定、重命名、定位和解除绑定文件夹；`alm folder` 也能做同样的事。绑定文件夹时，会把 Allomos 的一节写进这个文件夹的 AGENTS.md；解除绑定只删掉这一节。
- **任务上的文件夹。** 任务面板显示并修改任务所属的文件夹，任务列表把它们显示成小标签，并提供 **文件夹：** 筛选。
- **设置里的“智能体”一节。** 它显示每个 AI 智能体在任务包的几个项目文件夹里设置好了，缺少的文件夹旁边有 **设置…**。
- **“更新任务包…”可以升级到 allomos/6。** 还是 `allomos/5` 的任务包，现在会显示需要更新。**更新任务包…** 请智能体把它升级到项目文件夹需要的 `allomos/6`，并先提醒：升级后，较旧版本的 Allomos 会拒绝打开这个任务包。在你选择 **继续** 之前什么都不会改。

## 修复

- **顶栏的“设置”按钮对齐了。** 它和任务包的名字在同一水平线上，齿轮也圆得均匀。

## 其他

- AI 智能体只在持有任务时遵守交接限额。到达限额时，智能体写好交接并释放任务，下一个会话就能接着做。

发布于 2026-11-11。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.56)。

## 新增

- **立刻重新查看智能体信息行。** 任务包名称下面那一行（说明文件是否告诉了智能体 Allomos、剩余额度、在这里做的更改还有多少尚未共享）末尾多了一个 **↻** 按钮。按它就立刻重新查看；鼠标停在上面会说明它查什么。

## 修复

- **在后台时占用的 CPU 少得多。** 以前这一行每 4 秒查看一次，每次都把任务包的全部更改历史读一遍，所以历史很长的项目即使窗口放在后台，Allomos 也一直在忙。现在它只在打开项目时、每 30 分钟一次，以及按 **↻** 时查看，而且只有历史有变化时才重新读。在一个约有 4,800 条更改的项目上，闲置时 Allomos 占用的 CPU 约为原来的十分之一。

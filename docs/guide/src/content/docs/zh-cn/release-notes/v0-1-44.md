发布于 2026-11-08。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.44)。

## 新增

- **所有审计设置放在一处。** **项目设置 → 审计** 现在从上到下依次是：**一直记录**（历史总会留下的内容）、**身份**、**职责分离**、**外部时间戳见证**、带 **清除个人信息…** 的保留，以及 **变更类型**。外部时间戳见证显示任务袋的检查点，并有 **现在做一个检查点**；它自己的开关在见证服务做好之前保持灰色。**清除个人信息…** 的作用和 `alm redact` 相同，法律保全期间会被拒绝。每次改动都记入历史，关掉一项时会问原因。
- **设置 → 本机身份。** 显示这台电脑的 **签名密钥** 及其保存位置；**导出公钥…** 把公钥存成文件；**最后见过的历史** 按项目显示这台电脑最后见到的检查点，以及任务袋里是否还有它。**更换密钥…** 生成新的签名密钥：在每个最近的任务袋里，用一条签名的最后事件停用旧密钥，再加入新密钥；用旧密钥签过的改动仍然能核对。
- **在 Windows 上做的改动也带签名。** Windows 上的签名密钥存在凭据管理器里，所以 `allomos/8` 的任务袋从 Windows 和 macOS 都能得到签名的改动。
- **被阻塞的任务自己接着走。** 阻塞某个任务的最后一个任务完成或放弃时（用 `alm done`、`alm drop` 或应用里的按钮），被阻塞的任务重新变为就绪（有人持有时为进行中），和 `alm unblock` 的效果一样；它的交接说明会写明哪些阻塞任务已结束。放弃的阻塞任务现在也算结束。

## 新增

- **任务包以标签页打开。** 每个窗口都有一排标签页，像浏览器一样。点标签栏末尾的 **+**，或选 **文件 → 新建标签页**（macOS 上 ⌘T，Windows 上 Ctrl+T），就会打开一个新标签页；**文件 → 最近打开** 会在新标签页中打开任务包，如果它已经打开，就把那个标签页移到最前。拖动标签页可以调整顺序，拖出来就成为单独的窗口，也可以放进另一个窗口。标签页上的圆点表示那个任务包需要你处理。
- **选择「换肩」启动时打开什么。** 新的全应用 **设置…** 窗口（macOS 上 ⌘,，Windows 上 Ctrl+,）里有 **「换肩」启动时**：**重新打开窗口和标签页**（默认）、**打开上次的任务包**，或 **打开空白窗口**。
- **构建新应用…可以先讨论。** 勾选 **先讨论**，智能体会把你的描述写成目标后停下等你；你在那段对话里和它一起完善目标，然后用任何说法告诉它开始，它就会规划并构建这个应用。
- **在 Windows 上，窗口菜单会列出每个打开的「换肩」窗口**，包括用 **文件 → 新窗口…** 打开的窗口；选中一个就会把它移到最前。

发布于 2026-11-20. [从 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.78).

## 新增

- **终端里的 Claude Code 少问几次。** 由 Allomos 或监测在终端里打开的 Claude Code，改项目文件夹和任务袋里的文件不再逐个询问，`alm` 和常见测试命令直接运行；其他命令和项目外的写入仍会询问。
- **从启动提示直接打开终端和任务。** Claude Code 在终端里启动时显示的提示，现在能直接打开那个终端和任务详情。

## 修复

- **长提示词不再被截断。** 在 macOS 上从桌面端用终端打开 Claude Code 时，长提示词不再被截断卡住。
- **任务重新就绪后监测会再次派发。** 任务被重新设为就绪后，已经在运行的监测会再次派发它。
- **「重新排队」放在停下的任务自己那一行。** 在监测面板里，每个停下的任务在自己那一行下面有重新排队按钮，上方不再重复提示。

发布于 2026-11-16。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.67)。

## 新增

- **阻塞列表现在会列出所有阻塞任务。** 未完成的任务先显示，使用阻塞颜色；已完成或已放弃的任务随后显示，使用完成颜色。任务面板也采用相同顺序。

## 修复

- **从访达打开的「换肩」现在能找到需要 Node 的终端 agent。** 即使 Node 不在系统的 `PATH` 中，也能检测到通过 npm 安装的 Codex 和 Claude Code。

## 其他

- **等待和阻塞信息可以同时显示。** 一个任务既在等人处理又有阻塞任务时，现在会同时显示这两行信息。

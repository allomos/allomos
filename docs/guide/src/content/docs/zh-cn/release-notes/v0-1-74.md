## 新功能

- **自动监测可为每个代理选择模型和推理强度。** 监测对话框会读取在线模型列表（可在设置中配置地址），让你为每个代理分别指定模型和推理强度。
- **失联监测会话可自动接管。** 监测面板会显示失联的会话和被放弃的任务，释放名额后在原分支上交给新会话继续。立即停止监测时会提示未完成任务并保留已有进度。
- **支持高风险任务限制。** 在项目设置中开启后，`alm done --without-human-check` 会拒绝高风险任务，静默运行也会将高风险合并留给审批人处理。不带参数的 `alm classify` 和 `alm done` 会列出风险规则，未记录风险时 `alm done` 也会提醒。
- **“为你整理”窗口会跟随最近使用的项目。** 切换项目窗口时，“为你整理”窗口会自动同步到当前项目。
- **应用内分享变更更清晰。** 分享详情现在会显示任务标题并优化了弹窗样式，仅分享有变动的任务文件，且分享提醒会跨重启保留。

## 修复

- **修复任务树中重复的阻塞标记。** 移除了树形任务标题中重复出现的“未显示”阻塞标签。
- **应用命令不再受环境变量 `ALLOMOS_TASKBAG` 影响。** 桌面应用运行命令时会清除 `ALLOMOS_TASKBAG`，避免误写入其他项目的任务包。

发布于 2026-11-19. [从 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.74).

## 新增

- **为每个代理选择模型和推理强度。** 启动任务监测时，可从在线模型列表选择，也可保留“默认”，沿用代理自身设置。对话框支持刷新列表，通用设置里可修改列表网址；离线时仍可使用已保存的列表。
- **立即退出监测。** 停止监测、等待任务收尾时，可点“立即停止”退出该监测；已开的代理会话、任务和已有工作保留。失联任务现在有明确提示。

## 修复

- **任务标题更清爽。** 依赖树不再在标题旁重复显示“未显示”的阻塞标签；阻塞任务一栏仍完整列出依赖。
- **保留额外账号。** 后台启动监测时，正确保留所选代理的额外账号。

## 其他

- **源文件行数检查。** 工作区测试会阻止已超限的源文件继续变长，并在需要更新记录的上限时给出提示。

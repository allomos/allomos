发布于 2026-11-07。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.41)。

## 新增

- **一个任务可以有几个标签，项目有一张标签表。** 一个任务现在可以同时有几个标签，标签之间没有先后。每个项目都带着五个内置标签：**locally verified by agent**、**deployed and verified by agent**、**locally verified by human**、**deployed and verified by human** 和 **AI decisions to review**；项目自己的标签和它们一起放在标签表里。`alm label <id> "<标签>"` 加一个标签，别的标签保留（`--remove` 去掉一个）。项目里第一次出现的标签会加进标签表，`alm` 会说一声，以防是打错了。`alm labels` 显示标签表，`alm labels add` 和 `alm labels remove` 修改它。桌面应用里有关标签的界面（包括“进度阶梯”设置）会在以后的版本中更新。
- **人工检查是一个标签。** `alm checked <id>` 给已完成的任务加上 **locally verified by human**；如果智能体已经部署并验证过它，则加 **deployed and verified by human**（用 `--deployed` 或 `--locally` 选择）。不带 `--without-human-check` 的 `alm done <id>` 现在要求任务有这两个标签之一。已完成、没有 “by human” 标签的任务和以前一样是“待检查”。`alm ai-decided` 加上 **AI decisions to review**，`alm reviewed` 去掉它。
- **任务包格式 allomos/7。** 这些标签需要任务包格式 `allomos/7`。这个版本仍能读旧格式的任务包，但在升级之前不会改动它：在桌面应用里用 **更新任务包…**，或运行 `alm upgrade --confirm`（只运行 `alm upgrade` 会先说明要做什么）。升级会去掉旧的 *drafted* 和 *implemented*，把 *locally verified* 和 *deployed and verified* 改成 “… by agent”，把 *human verified* 改成 **locally verified by human**（任务之前部署过的，改成 **deployed and verified by human**），并给还有未审阅 AI 决定的任务加上 **AI decisions to review**。较旧版本的「换肩」会拒绝升级后的任务包，所以请先在每台使用这个任务包的电脑上装好 0.1.41，再升级。

发布于 2026-11-16。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.64)。

## 新增

- **更新后，监测换成新版继续运行。** 「换肩」重新启动来更新时，正在运行的 **自动监测就绪任务** 不再留在旧版的 `alm` 上：应用先停下它，再用新版重新启动，设置不变。系统通知和状态栏监测面板里的一行字会说明这件事，**重新启动以更新** 之前的提醒里也会提到。从源码构建或别处的 `alm` 启动的监测不受影响。

## 修复

- **监测读不了任务包时会告诉你。** 如果任务包的格式需要更新版的「换肩」，马上告诉你；如果连续 2 分钟以上读不了任务包，到时告诉你。你会收到系统通知，状态栏里监测旁边有一行警告色的字，**自动监测** 区块标题上有一个 ⚠（区块折起或展开都显示）。监测每隔几秒继续尝试，能读回任务包后自己接着运行，警告随之消失。

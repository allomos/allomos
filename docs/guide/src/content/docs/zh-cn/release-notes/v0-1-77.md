发布于 2026-11-20. [从 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.77).

## 新增

- **每项检查的结果一项一行。** 代理现在把跑过的每项检查记为通过、未通过或没跑；「证据」一屏逐项列出，未通过和没跑的排在最前面。
- **未通过检查的截图。** 代理可以给未通过的检查附上最多 3 张截图。「证据」一屏在那一项下面显示缩略图，点开看大图。截图存进任务袋，换一台电脑也能看到。
- **在终端里看证据。** `alm show <id> --evidence` 按「证据」一屏的顺序列出同样的内容。
- **在监测面板重新排队卡住的任务。** 不用重启监测，就能把一个卡住的任务放回队列，其余任务照常继续。

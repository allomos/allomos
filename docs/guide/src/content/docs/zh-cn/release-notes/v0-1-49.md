发布于 2026-11-09。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.49)。

## 新增

- **正在运行的监测集中列出。** 标签栏的 **监测** 按钮和窗口菜单里的 **正在运行的监测** 会列出这台电脑上每一个正在运行的监测，每个都有 **打开**、**↻ 立即检查** 和 **■ 停止**。
- **不开应用也能监测。** `alm monitor start`、`alm monitor check`、`alm monitor stop`、`alm monitor status` 和 `alm monitor list` 在应用没开时也能用。用 `alm` 开始的监测，应用开着时会显示在状态栏里，应用也能立即检查或停止它。`alm monitor list` 在任何文件夹里都能用，列出这台电脑上的运行。
- **每个智能体可以同时有几个会话。** 一个智能体可以同时在自动监测的就绪任务上开几个会话，每个会话先认领自己的任务。
- **每个智能体可以设难度范围。** 在 **自动监测就绪任务** 里，可以为每个智能体设一个难度范围，默认从 1 到 5。

- **接手失去联系的任务。** 会话沉默的任务（账户用完或已切换）就算失去联系。先领就绪的任务，然后 **自动监测就绪任务** 把失去联系的任务交给一个新会话。任务面板只在任务失去联系时，在 **打开** 旁显示 **接手…**；点开会弹出一个对话框选择智能体。`alm claim` 也能接手失去联系的任务。

## 修复

- **监测的“等你”通知以应用自己的名义显示。** 这条通知来自 Allomos 本身，而不是脚本编辑器。
- **状态栏对齐。** 它的链接和按钮都在状态栏的中线上。

## 其他

- 监测的会话、标签页、通知和请求文字现在放在代码的一个共享部分里，应用和 `alm` 用同样的方式运行监测。

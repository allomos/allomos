发布于 2026-11-09。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.47)。

## 新增

- **「换肩」给 Codex 的规则。** 在 **自动监测就绪任务** 里选 Codex 时，对话框提供 **让 Codex 不问就运行 Git 和 alm**，默认勾选。它会加上「换肩」给 Codex 的规则文件（`~/.codex/rules/allomos.rules`）：这样每个无人值守的 Codex 会话都能不问就拉取、提交、推送、合并，并运行 alm；其余命令照旧在 Codex 的沙箱里。这取代了原来让 Codex 完全访问的建议。按 **开始** 之前什么都不写；按下后写入或删掉这个文件，并记入项目历史；你自己写在 `default.rules` 里的规则从不改动。「换肩」的规则较旧或文件被人改过时，对话框会在改动之前说明会加上和去掉哪些命令；来自更新的「换肩」的文件保持原样。`alm guide codex-rules` 列出这些规则，`alm guide agent-files` 有 Codex 每台电脑做一次的步骤，`alm guide workflow` 说明 Git 无法写入工作副本时怎么办。

## 修复

- **任务完成之后，前一个会话回来。** 任务被接手、新会话又已把它完成（完成或放弃）时，前一个会话回来后现在仍会被告知是谁接手并完成的，它的改动会被拒绝。对已完成或已放弃的任务运行 `alm release`，对任何会话都会被拒绝，并指向 `alm reopen`，所以它再也不会抹掉持有者。

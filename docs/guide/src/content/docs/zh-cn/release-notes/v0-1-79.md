发布于 2026-11-20. [从 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.79).

## 新增

- **一次批准几个任务。** `alm checked` 和 `alm reviewed` 能一次接受几个任务 ID；其中有一个记不了，就一个都不记，并说明是哪一个、为什么。检查没通过时，提示改为用 `alm reopen`。
- **未共享改动的提示更清楚。** 在应用里直接做的修改归为一组，同一条目的多次修改合并显示，并用一句话说明提示为什么出现、请智能体共享会做什么。

## 修复

- **监测面板不再显示已经过去的会话。** 任务重新派出或完成后，不再留在“没开成的会话”里；不是当天的时间会带上日期。

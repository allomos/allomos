发布于 2026-10-23。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.22)。

## 新增

- **任务包需要更新时只有一条横幅。** 说明过时、任务包是旧格式、卡片文件放在任务包外、还有旧的交接文件，以前各自显示一条横幅。现在一条横幅列出所有原因，每个原因一行，只有一个 **更新任务包…** 按钮。

## 修复

- **更新提示和菜单一致。** 新版本下载好之后，窗口里的提示和菜单一样提供 **重新启动以更新到「换肩」<版本>**，不再仍然把你带到下载页面。

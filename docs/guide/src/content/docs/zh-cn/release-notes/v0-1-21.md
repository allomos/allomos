发布于 2026-10-23。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.21)。

## 新增

- **交接写进任务。** `alm handoff <id>` 把停在哪里、下一步和在等谁写进任务的交接笔记，把不能重复执行的操作加在描述的 Evidence 下，并在任务历史里记下由谁交接。下一个会话用 `alm next` 或 `alm show` 就能看到，交接不会再在单独的文件里过时。
- **不再有交接文件。** “交接”标签页、任务窗格里的“最新交接”和搜索里的交接文件都去掉了；任务的交接笔记保留。**交接设置…** 移到了“文件”菜单。任务包里还有旧的 `handoffs/` 文件夹时，会显示 **更新任务包…**，请智能体把仍然有用的内容搬进各任务，再删掉文件夹。
- **做计划前提醒检查文件大小。** 在 `alm claim` 之后和 `alm guide workflow` 里，提醒智能体看一下要改的文件是否太大；太大就只为要动的那部分计划重构。

发布于 2026-10-27。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.29)。

## 新增

- **发布后是否安装，由你决定。** 你在对话中写 `alm guide github release` 时，AI 智能体会发布新版本并检查它，然后停下。只有你加上 `install`（`alm guide github release install`，也可以和 `minor` 或 `major` 一起用），它才会在这台电脑上下载并安装这个版本。不再需要 `no install`。

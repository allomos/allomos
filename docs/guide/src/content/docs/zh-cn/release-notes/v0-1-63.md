## 新增

- **在任务列表里直接改状态。** 在任务列表展开的行里点状态（例如 **就绪**），会弹出状态列表；选一项，任务状态马上改好，并记进历史，不必先打开任务面板。规则与任务面板的状态菜单相同：不能选的状态灰掉，下面写着原因（有人持有的任务要等释放后才能退回 **储备**；已完成的任务用 `alm reopen` 重新打开）。选 **等待中** 时先要填在等什么，才会保存。按 Esc 或点列表外面就关掉，什么也不改。

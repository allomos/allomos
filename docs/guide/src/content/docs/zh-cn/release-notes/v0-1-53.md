发布于 2026-11-10。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.53)。

## 新增

- **两种开始方式并排显示。** 开始页面现在把 **新建项目…**（原来的 **构建新应用…**）放在 **设置现有项目**（原来的 **开始**）旁边。**打开最近的…** 仍在它们下面。它打开的对话框现在叫 **新建项目**。
- **检查更新和下载更新各有一个开关。** **设置 › 通用 › 更新** 下有两个开关，默认都开着。**自动检查更新**：「换肩」每天向 GitHub 检查一次有没有新版本。**自动下载更新**：检查到新版本后，在后台下载并核对安装包；关掉自动检查时，它变灰。菜单里的 **检查更新…** 不管开关怎样，总会下载。
- **能看到下载进度，也能取消。** 新版本的安装包下载时，更新提示显示下载到了哪里（例如“安装包正在下载：40%”），并带一个 **取消** 按钮；菜单项显示 **正在下载「换肩」0.1.53… 40%**。点取消会停止下载并删掉下了一半的文件。

## 修复

- **安装包准备好之后才提供更新。** 更新提示和菜单现在要等新安装包下载并核对完，才提供 **重新启动以更新到「换肩」…**。在那之前，菜单里的 **下载「换肩」…** 会变灰等待，而不是打开发布页面。一个版本暂时只有源代码时，**检查更新…** 会说安装包正在准备中，也不会出现下载横幅。只有你的电脑拿不到安装包时，才会打开发布页面。

发布于 2026-11-15。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.60)。

## 新增

- **任务面板按状态优先显示要看的内容。** 根据任务当前的状态，面板先展开检查步骤、待回答的问题、阻塞项、交接说明或描述，其余字段、完整描述和历史记录收起。
- **标签和状态用任务语言显示。** 在应用和 `alm human` 里，标签、状态这类固定的词按项目的任务语言显示。
- **项目窗口顶部更清爽。** 去掉了项目窗口顶部的 AI 智能体状态行（额度标签、连接状态和尚未共享提示）。

## 修复

- **输入法按回车选词不再误提交表单。** 用中文或日文输入法按回车确认候选词时，不再误把添加任务等表单直接提交。

## 其他

- **更新标语。** 应用欢迎页、「关于」窗口、网站、使用指南首页和 README 都换成了新版中英日标语。
- 决策 0024 与 0025 记录了不绑定单一智能体的换肩定位，以及记录首先写给人看的原则。

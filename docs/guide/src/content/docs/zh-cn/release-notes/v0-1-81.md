发布于 2026-11-24。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.81)。

## 新功能

- **监测面板中的任务 ID 可直接打开详情。** 监测面板里显示的每一个有效任务 ID 现在都可以点击，直接跳转到对应任务的详情页。

## 修复

- **修复静默模式 Antigravity 的权限规则与心跳提示。** 修正了静默监测下 Antigravity 会话的推送/拒绝规则、任务包允许规则及心跳提示，使合规的推送和任务包更新不再被误拦。
- **审批等待状态仅在会话所属终端标签页打开时生效。** 当被监测的 Antigravity 终端标签页关闭后，其确认标记不再被其他会话复用，已关闭的会话会退出审批等待状态并按正常失联规则接管，结束时也不会误清除其他会话的标记。

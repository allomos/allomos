发布于 2026-11-12。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.57)。

## 新增

- **更改自己出现，而且马上出现。** 你或智能体用 `alm` 改了一个任务，Allomos 窗口约 1 秒内就显示出来，窗口在后台时也一样。现在 Allomos 由系统告诉它有变化（macOS 和 Windows 上的文件通知），不再定时去看任务包的文件。另外每分钟还会检查一次，补上通知漏掉的情况，例如网络盘或云同步文件夹。

## 修复

- **闲置时占用的 CPU 少得多。** 打开一个项目、窗口放在后台时，Allomos 以前每分钟占用约 2.3 秒 CPU，现在约 0.15 秒。除了文件通知，项目的监测栏、**监测 · N** 计数和 **Running Monitors** 菜单现在共用一次读取（有窗口在用时每 3 秒一次，否则每 15 秒一次），回到窗口时立刻更新。

## 其他

- **任务包更新提示查得没那么勤了。** Allomos 在打开项目时、以及任务包每次有变化时查看任务包是否需要更新，不再每 4 秒查一次。只改了项目文件夹的 AGENTS.md 时，要等任务包下次有变化或重新打开项目，才会出现提示。

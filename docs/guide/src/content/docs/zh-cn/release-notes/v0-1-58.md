## 新增

- **「做好交接准备…」取代「交给另一个智能体…」。** 任务标题旁的按钮现在打开一个简短的对话框：它显示一段提示词，请持有任务的会话写好交接说明、把工作提交并推送到工作分支、释放任务，然后停下。**复制提示词** 把它复制下来；**打开它的会话** 打开持有任务的会话（Claude 应用或终端），同时也复制提示词，你贴进去发送就行。对话框不再问由谁接着做，也不显示等待，随时可以关掉。任务释放后，用 **执行…** 开始由谁接着做。
- **持有者看起来不在了，它会告诉你。** 持有任务的会话从没发过心跳，或者沉默超过了项目的时限，对话框会说明，并提供 **接手…**。会话打不开时（例如认领时没记下会话），对话框说明原因，只留下复制。

## 其他

- **做交接准备不改动任务包。** 任务里不再写入交接请求，所以 `alm` 也不再显示“请求交接”的提醒。旧版本写下的请求照样能读，认领、释放、完成或放弃任务时照旧清掉。

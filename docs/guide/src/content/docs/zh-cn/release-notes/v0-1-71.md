发布于 2026-11-17。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.71)。

## 修复

- **Antigravity 会话不再停下来请求文件访问。** 「换肩」启动的会话会把任务包文件夹和任务包的其他工程文件夹加进工作区，auto 模式下读写它们（例如项目笔记）不再询问。你的 Antigravity 设置不变。
- **安静模式的 Codex 会话写任务包不再失败。** 监测启动的 Codex 会话现在也能写任务包文件夹和它的其他工程文件夹，在那里改文件不会再悄悄失败。在那里提交和推送仍要靠「换肩」给 Codex 的规则。你的 Codex 设置不变。

## 其他

- **`alm` 的内部做了整理。** 代码拆成了更小的部分，你用到的功能没有变化。

发布于 2026-10-25。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.24)。

## 新增

- **每个任务包有了自己的设置。** 顶栏显示任务包的名字和 **设置** 链接。**通用** 显示名字（可 **重命名**）、格式和位置（可 **在访达中显示**），任务包较旧时提供 **更新任务包…**。**任务** 设置任务语言、修改进度阶梯。**交接** 放交接规则，取代“文件”菜单里的 **交接设置…**。
- **网络中的设备可以查看你的任务。** **文件 › 网络中的设备…** 打开从局域网查看；不打开就一直是关着的。窗口里显示地址、二维码和证书指纹。手机或另一台电脑打开这个地址，填一个名字发出请求；你批准后，它输入窗口里显示的 9 位配对码。已配对的设备列在这里，随时可以移除。设备只能读，不能修改任何东西。
- **一个任务包可以管理多个项目文件夹。** 每个任务写明它属于哪些文件夹（`alm add task --folder`，或 `--no-folder`；用 `alm folders` 修改），`alm list --folder` 按文件夹筛选，在某个文件夹里运行 `alm next` 只列出这个文件夹的任务。这需要任务包格式 `allomos/6`：已有的任务包照常使用，直到 `alm upgrade --confirm` 转换它（只运行 `alm upgrade` 会先说明要做什么）。
- **任务可以退回储备。** 没人持有的就绪、等待或阻塞的任务，可以在应用的状态菜单里退回储备，或用 `alm backlog <id>`。不能退回时，菜单会说明原因。
- **更新任务包时可以顺便翻译。** **更新任务包…** 里有一个复选框，请智能体同时把任务、卡片文件和项目备注翻译成应用的语言。每次都默认不勾选。
- **“最近打开”在新窗口中打开。** 在 **文件 › 最近打开** 里选一个任务包，会在它自己的窗口中打开，或者把已经显示它的窗口调到前面，不再替换最前面窗口里的内容。
- **`alm list --by iteration` 显示整个计划。** 每个迭代都有标题，空迭代也有，并像应用里一样显示它在计划中的序号（1、2、3…）。

## 其他

- 由更新版本写过的任务包，不会再因为本版不认识的字段或取值而打不开：这些内容原样保留，并列为提醒。

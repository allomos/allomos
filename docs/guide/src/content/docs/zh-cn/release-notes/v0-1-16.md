发布于 2026-10-21。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.16)。

## 新增

- **新任务用“单词编号”。** 以前在不同分支上各自添加任务，会拿到同一个下一个编号而冲突。现在新任务用一个短单词加三位数字命名，例如 `A01-tiger042`，两个人同时添加任务也不会撞号。已有的数字编号保持不变。列表里先显示数字编号，再按创建顺序显示单词编号。
- **开始页适应你的窗口。** 卡片的留白、标题和引言现在也随窗口高度调整，**打开最近的…** 和 **建立新应用…** 不用滚动就能在卡片下方看到。

## 修复

- **Windows 卸载会清除 Allomos 添加的一切。** 包括应用文件夹（含 `alm.exe`）、PATH 条目、快捷方式，以及“设置 › 应用”里的条目。只有勾选 **删除应用数据** 时，才会删除 AppData 里你自己的数据。
- **会话额度算到正确的智能体名下。** 以会话名（如 `claude/…`）上报额度的会话，现在算作 Claude Code，不再多出第三个智能体。变暗的智能体标签在鼠标悬停时不再让弹出框变淡。

## 其他

- Allomos 网站 www.allomos.com 新增了博客和产品页面。

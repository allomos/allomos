发布于 2026-11-03。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.38)。

## 新增

- **分组的“编辑”放在标题行。** 在任务列表中，每个领域分组和迭代分组的 **编辑** 现在紧跟在分组名称（以及迭代的状态标记）之后，而不再放在进度条下面那一行；**新任务** 仍留在下面那一行。“编辑”打开的表单和以前一样，点它不会折叠或展开分组。**未排期** 和领域未知的分组仍然没有“编辑”。
- **状态词改为常规字重。** 任务的状态，无论在任务行、详情面板还是 **显示** 筛选中，都不再加粗。它保留自己的颜色，原来有浅色底色的也保留底色，浅色和深色模式都一样。

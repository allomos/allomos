发布于 2026-10-27。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.30)。

## 新增

- **alm 会说出任务还缺什么。** 执行改变任务的命令（认领、更新标签、完成）之后，`alm` 会列出任务还缺的东西，例如 Allomos 应用重新打开智能体会话所需的会话信息、工作分支或交接说明，并给出补上它的命令。新的 `alm session` 命令可以事后补上会话信息，让该任务的**在 Claude 中打开**（或你的智能体）按钮重新可用。
- **翻译任务包时也会翻译迭代名称。** 把任务包翻译成另一种语言时，智能体现在也会重命名每个迭代，计划不再停留在旧语言，而任务已换成新语言。

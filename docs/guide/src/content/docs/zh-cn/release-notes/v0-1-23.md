发布于 2026-10-24。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.23)。

## 新增

- **迭代用单词作 ID。** 迭代的 ID 是 `I-` 加一个短单词，例如 `I-knit`、`I-forge`，不再是看起来像计划顺序的数字。`alm add iteration` 不给 ID 时会挑一个没用过的；`alm rename iteration <旧> <新>` 给迭代改名，并把计划在其中的所有任务一起改过去。
- **每个迭代显示序号。** 在应用里，迭代 ID 旁边显示它在计划中的位置（1、2、3…），顺序一眼就能看清。
- **在计划里移动迭代。** `alm move iteration <id> --before <id>`（或 `--after <id>`）把迭代放到新的位置，不用手改任务包文件。

## 修复

- **标题上的计数保持一行。** 领域或迭代标题右边的计数（“已完成 142/142”）在任务编号变长时，也不再折成两行。
- **“更新任务包”对话框可以滚动。** 列出很多旧交接文件时，列表可以滚动，按钮始终看得到。
- **backlog 状态的中文名改为“储备”。** 不再和“就绪”读起来一样。

## 其他

- AI 智能体继续通过 `alm` 工作；给智能体的 MCP 服务器暂缓。

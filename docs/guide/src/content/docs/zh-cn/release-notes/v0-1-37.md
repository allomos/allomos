发布于 2026-11-02。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.37)。

## 新增

- **提示横跨窗口顶部。** 刷新行（带 **立即刷新**）、“改动记在 … 名下”和“此项目还没有迭代”现在放在同一条横栏里，位于任务列表和任务详情面板之上，详情面板的顶部和列表对齐。打开或关闭面板时，它们不再移动。

## 修复

- **在 Claude 桌面应用中处理的任务又能在那里打开了。** Claude 桌面应用里的代理领取任务时如果只记下了会话 ID，`alm` 现在会指出缺少桌面信息，并给出补上它的命令，这样 **在 Claude 中打开** 会在 Claude 应用中打开会话，而不是由 **在终端中继续** 新开一个终端。在终端里工作的代理记下 `--session-kind terminal`，就不会再被提醒。之前已经记下的任务保持原样，直到它自己的会话运行 `alm session`。

发布于 2026-10-27。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.28)。

## 新增

- **会话按钮移到任务标题里。** 任务记录了会话时，**在 Claude 中打开** 或 **在终端中继续** 按钮现在紧跟在标题的 **修改** 按钮后面，不再放在标题下面那一行。那一行又像 0.1.27 之前一样只显示人工检查。会话一行里的按钮保留不变。

发布于 2026-11-25。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.82)。

## 修复

- **安静模式自动监测启动 Claude Code 时不再弹出信任或切换模式确认。** 安静监测现在以 `auto` mode 启动 Claude Code（若已配置 `bypassPermissions` 则保持不变）且不传 `--add-dir`，避免未信任的任务包文件夹在启动时卡在目录信任弹窗，也不再在执行命令时停下来询问是否切换为 auto mode。
- **普通与桌面端打开 Claude Code 保留默认模式与已信任文件夹。** 手动与普通模式启动现在只为 Claude Code 已永久信任的文件夹传 `--add-dir`，不再把已默认使用 `auto` mode 的用户降级为 `acceptEdits`，从不修改 `~/.claude/settings.json`，并同步更新了应用内的 Claude Code 权限说明文案。

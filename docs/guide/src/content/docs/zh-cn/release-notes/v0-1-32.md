发布于 2026-10-30。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.32)。

## 新增

- **拖动标签页像 Chrome 一样。** 标签页跟着指针移动，其他标签页会在它将要落下的地方让出空位；拖动的标签页盖过相邻标签页一半以上时才和它交换位置，**+** 按钮也会让开。
- **把标签页拖到另一个窗口更容易了。** 在那个窗口上方任何位置松开都可以，不必对准它的标签栏。那个窗口会移到最上面，它自己的标签页保持可见，空位里显示拖来的标签页，并且已经显示它的任务包。
- **不在最前的标签页有浅灰色边框**，更容易分辨哪个在最前。

## 修复

- **在同时连接 Retina 显示器和普通显示器的 Mac 上，拖动的标签页不再跳动。**
- **在 macOS 上，标签页拖到另一个窗口的标签栏上方时，它原来的窗口不再跳到屏幕左上角。**

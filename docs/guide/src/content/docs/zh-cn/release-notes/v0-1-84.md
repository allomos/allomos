发布于 2026-11-27。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.84)。

## 修复

- **新任务审批默认开启。** 未显式配置的项目现在会默认将代理新建的任务留在待办，直到你批准；手动关闭后也会明确保存，重新打开设置后保持关闭。
- **任务袋设置滚动不再遮字。** 较矮窗口下的设置正文改用细滚动条并保留右侧留白，避免遮挡文字；较窄窗口下的分类栏改为横向滚动，为正文留出更多纵向空间。

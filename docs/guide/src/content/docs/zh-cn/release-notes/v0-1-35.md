发布于 2026-11-02。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.35)。

## 新增

- **每个状态都有更鲜艳的专属颜色**：储备是棕色，就绪是蓝色，进行中是绿色，等待中是黄色，被阻塞是红色，已完成是紫色，已放弃是灰色并加删除线；浅色和深色模式都是这样。
- **状态词成了加粗的小标签，衬一层同色浅底**，在任务行和详情面板里都是这样，一眼就能分清各个状态。“显示”筛选器和“在等”/“被谁阻塞”的说明文字只用颜色，不加浅底。

## 修复

- **`alm` 提醒智能体报告额度时，给出的命令写的是智能体**（`claude-code`、`codex`），不再是会话名。照着做的智能体不会再把会话当成智能体报上来，应用顶部的“AI 智能体：”一栏也不会再多出 loop-hourly 这样的灰色项。

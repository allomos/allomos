发布于 2026-10-22。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.18)。

## 新增

- **Allomos 标志向你问好。** 窗口打开时，标志在原来的位置和大小上播放一次等待动画，然后保持静止。“关于”窗口也一样。
- **过旧的额度数据会被再次索取。** 当某个智能体的额度缺失或超过 30 分钟未更新时，`alm claim`、`label`、`release`、`done` 和 `handoff` 会请智能体上报。额度标签现在用小时或天表示较旧的时间，不再是一长串分钟数。

## 修复

- **“在访达中显示”紧挨着任务包路径。** 按钮现在位于路径所在的那一行、路径之后，智能体那一行仍单独占一行。

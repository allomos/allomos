发布于 2026-11-16。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.65)。

## 新增

- **每个任务都显示改动的风险。** 任务列表和任务面板显示 **高**、**中** 或 **低**，由做这件事的智能体用 `alm classify` 记下，附一句理由。还没有智能体评过的任务显示 **未分级**；「换肩」从不自己猜。`alm human` 也显示风险。
- **项目设置里新增「风险管理」一节。** 这里列出让改动算作高风险的固定规则，也可以添加、修改、删除项目自己的规则。针对高风险工作的两个限制也放在这里，默认都关着。
- **在列表里直接改任务难度。** 在任务列表展开的一行里点难度（例如「4 · 难」），从 1 到 5 里选一级。按 Esc 或点别处就关上，什么都不改。
- **`alm human` 一个任务一行，按顺序列出。** 有智能体在等你的排在最前（挡住更多任务的在前，再按等得久的在前）；然后是做完待检查的，风险高、等得久的在前；最后是更早迭代的任务。

## 修复

- **读写任务包时窗口不再卡住。** 打开任务包、保存改动、查看任务历史，以及其他读写任务包和设置的操作，现在都在后台进行，窗口一直能用。

## 其他

- 智能体现在完成任务前先记下它的风险；交接说明、AI 决定和检查步骤先写一句给你看的大白话，技术细节放最后。

发布于 2026-11-15。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.62)。

## 新增

- **依赖树更清楚。** 打开 **显示 › 依赖树** 后，每行左边有一个圆形节点，颜色随层级变化；同色的连线从父任务往下，以圆角拐进它下面的每个任务。节点就是折叠按钮：在下面有任务的那行点它，下面的任务收起（节点显示 +），再点一下展开。

## 其他

- 决定 0028 定下了「一个队列装下所有要人做的事」的方案：单独的 **待你处理** 窗口，跟着前面的项目；一个任务一行，有代理在等你的排最前，其余按风险排。这一功能还没做。

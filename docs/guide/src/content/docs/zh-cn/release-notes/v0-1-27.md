发布于 2026-10-27。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.27)。

## 新增

- **把任务包翻译成任意语言。** 在任务包的设置中，**任务** 一节有 **翻译任务包…**。选一种语言（任何语言，不限于应用界面的语言）和一个 AI 智能体，智能体会用这种语言重写每个任务、卡片文件和交接说明，并把它设为任务语言。平常的进度弹窗会显示进行到哪一步。
- **语言菜单取代翻译复选框。** 在 **更新任务包** 对话框和设置向导的第 4 步，翻译复选框换成了语言菜单，默认是 **不翻译**。选一种语言，智能体就会在同一次运行中把任务包的内容翻译成它，并把任务语言改成它。
- **设置向导建立任务包时选择任务语言。** 设置向导建立新任务包时，第 2 步会先问 AI 智能体用哪种语言写任务，然后才是 **建立任务包**。
- **在设置向导中为一个任务包连接多个项目文件夹。** 设置向导的第 3 步现在可以把不止一个项目文件夹连到任务包。
- **从任务面板顶部打开任务的会话。** 任务记录了会话时，**在 Claude 中打开** 或 **在终端中继续** 按钮也会出现在标题下面那一行的最右边，紧挨着 **已检查**，不用再往下滚到会话一行。

## 修复

- **对话框里的复选框和它的文字排在同一行**，例如 **网络中的设备** 里的 **允许局域网设备查看**。

## 其他

- 在任务包的设置中，**项目文件夹** 一节说明一个任务包可以服务多个文件夹，按钮显示 **添加项目文件夹…**，添加了一个文件夹后显示 **再添加一个文件夹…**。

## 新增

- **在任务行里把任务交给 AI 智能体。** 每个任务行现在都显示 **持有者**：持有它的会话，或灰色的 **无人**。在桌面应用里，没有会话持有、也没有完成或放弃的任务还会显示 **接着做…**。它打开一个对话框，说明 Allomos 找到了什么、接下来会发生什么；选一个智能体再点 **打开**，Allomos 就在你的项目文件夹里打开它，并已输入好请求，让它认领并接着做这个任务。在你自己发送之前，什么都不会发出。储备中的任务在你点“打开”时即获批准。受阻或等待中的任务，对话框改为 **请 AI 智能体看看这个任务**：智能体先告诉你它为什么停下，问你想怎么办，在你回答之前不做任何改动。**编辑请求…** 可以只为这一次修改请求文字；选 **手动** 会显示请求并附 **复制**，由你自己粘贴给智能体。

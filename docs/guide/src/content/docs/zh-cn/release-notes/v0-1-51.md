发布于 2026-11-10。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.51)。

## 新增

- **所有对话框中 Antigravity 的请求都直接发出。** 在「更新」「移动」「构建应用」「翻译」「移动卡片」「继续」「接管」和「升级」对话框中，Antigravity 的请求现在直接发送给 `agy`，不再提示你粘贴后按回车。其他智能体不变。
- **迭代名称可以打开该迭代。** 在监测列表中，迭代名称是一个链接（带图标），点击后会在计划中显示该迭代。单独的 **打开** 按钮已经去掉。

## 修复

- **标签页在智能体空闲后才关闭。** 已完成任务的标签页准备关闭时，30 秒倒计时现在会等智能体停止工作后才开始。仍在推送或合并的任务不会显示提示，也不会被发送退出命令；输入命令前会再次确认是否空闲。
- **监测停止后标签页仍会关闭。** 倒计时现在在自己的后台进程中运行，监测停止或重新启动后，Claude 或 Codex 的标签页不会再留着不关。
- **长名称在按钮内换行。** 较长的领域或迭代名称会在按钮内换行，**编辑** 按钮仍在旁边。

## 其他

- 隐藏的命令 `alm monitor close-tab` 不再需要任务库，因此在任何文件夹中都能运行。

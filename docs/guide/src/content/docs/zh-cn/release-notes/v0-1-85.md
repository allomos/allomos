发布于 2026-11-27。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.85)。

## 新增

- **更新 Antigravity 模型列表并按模型显示推理强度。** 设置现已支持读取 version 2 格式的模型列表（同时兼容旧版 version 1），每个模型只列出它实际支持的推理强度档位；不支持 `--effort` 的模型仅显示「默认」。Antigravity 现收录全部 11 个模型，包括 Gemini 4 Neon / Hydrogen / Carbon / Argon、Gemini 3.8 Flash、Claude Opus 5.5、Claude Sonnet 5.5、GPT-OSS 120B 以及三个 Orchestrator 变体。

## 其他

- **统一代理工作树位置。** 更新共享代理规则与 `alm` 提示，要求在项目目录的 `.worktrees/<short-name>` 下为任务创建工作树。

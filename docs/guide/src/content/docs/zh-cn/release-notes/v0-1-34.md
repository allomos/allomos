发布于 2026-11-02。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.34)。

## 新增

- **任务列表上方的“显示”筛选器改成一个勾选面板，分为状态和标签两组。** 默认全部勾上，列出所有任务；取消勾选就隐藏相应的任务。现在可以同时显示几种状态。
- **每个标签都有“是”和“否”**：“是”是已达到这一级或更高的任务，“否”是还没达到的任务。比如取消“人工已验证”的“是”，就只看还没经过人检查的任务。
- **每组都有“全选”和“清除所有选择”，筛选器旁边的 ↻ 让所有任务重新显示。** 用不了的按钮会变灰，不会消失；勾选使列表变空时，面板会说明原因。

## 其他

- **筛选器原来的“全部状态”“未完成”“需要人处理”三项去掉了**：勾选已经能做到。之前选过的某个状态，会恢复成只勾这一个状态。

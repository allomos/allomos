发布于 2026-11-02。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.33)。

## 新增

- **任务列表的每一行像详情面板一样列出事实**：每个值前面有灰色的小字名称，一行两项，不再挤成一整句灰字。点持有者可以打开它的会话。
- **每种状态都有自己的颜色**，就绪、进行中、等待中、被阻塞和已完成一眼就能分清。任务有标签时，行里才显示标签。
- **欢迎页和关于窗口说明了「换肩」的用处：任务总能接着做**，无论谁接手。标题下面的段落说明什么时候要换：智能体或账号的额度用完了，或者队友把任务转交给你。

## 修复

- **智能体问你问题时，进度框显示“等你回复”**和那个问题，不再在 10 分钟后提示智能体可能已经停下。你回复后，它又显示智能体正在做的事。
- **智能体用 `alm` 改任务就算在工作**，它认领、加标签、完成任务时，进度框不再提示它 10 分钟没有报告。
- **智能体真的 10 分钟没有动静时**，提示会说明它可能在它的窗口里等你回话，也可能已经停下。

发布于 2026-11-20. [从 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.76).

## 新增

- **一屏查看任务证据。** 等你检查的任务，在任务面板和“待你处理”窗口顶部显示“证据”面板，集中呈现风险和要你做什么、检查步骤、改动摘要、测试证据入口、待审的 AI 决定，以及可收起的交接说明。
- **看清代码改了什么。** 改动摘要列出每个已记录提交或合并的说明第一行，以及改动文件和各自增删的行数。内容只从本机 Git 历史读取；本机没有的提交保留链接并明确提示。

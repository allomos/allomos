发布于 2026-11-11。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.55)。

## 新增

- **把任务交给另一个智能体。** 有会话持有的任务，详情面板里现在有 **交给另一个智能体…**。对话框分三步：选新的智能体（列表下面显示它的 5 小时额度还剩多少），按 **请它交接**，然后等原会话写好交接说明并释放任务。原会话下一次运行 `alm` 时会看到这个请求；想让它更快知道，可以按 **打开它的会话** 或 **复制请求**，粘贴到那个会话里。任务释放后，对话框显示交接说明，按 **打开** 就让新的智能体在同一个工作分支上接着做。超过一个心跳间隔还没动静，它会改为提供 **接手…**。
- **任何持有中的任务都能接手。** 没做完、有持有者的任务，详情面板里现在都有 **接手…**，不再只限失联的任务。持有者还在发心跳时，对话框会说明这一点，列出最近一次心跳和工作分支，提醒两个会话可能有一段时间在同一个分支上工作，确认按钮写的是 **仍然接手**。任务列表里，和以前一样只有失联的任务显示这个按钮。
- **任务半途中断时，在哪台电脑上都知道它做到哪里。** 会话可以在每次心跳时说一句正在做什么（`alm beat --doing "…"`），它显示在详情面板的 **最近心跳** 一行、`alm next` 和 `alm show` 里，以及接手对话框里。项目的新设置 **心跳时推送半成品，为接手做准备** 开着时（**设置 › 心跳**，默认开启，也可以用 `alm heartbeat-settings`），`alm beat` 会提醒会话提交并推送还没做完的改动，这样在另一台电脑上接手时，最多丢一个心跳间隔的工作。接手对话框和 `alm claim` 现在都说明：只有推送过的东西才算数。

## 其他

- **更新了给智能体的规则。** Allomos 写进项目 AGENTS.md 的规则，现在说明了怎样交接、怎样接手没失联的任务，以及推送半成品。

发布于 2026-10-22。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.20)。

## 新增

- **迭代有了状态。** 迭代分为计划中、进行中或已关闭，同一时间最多一个进行中。新任务进入进行中的迭代，`alm next` 也先列出它。没有标为进行中的迭代时，第一个计划中的迭代视为进行中。进行中和已关闭的迭代各有自己的徽章和颜色，已关闭的仍保持通常的灰色外观。打开任务包时，会自动转为新格式（`allomos/5`）。
- **“显示”筛选新增“未完成”。** 它列出所有既没完成也没放弃的任务，排在“所有状态”之后。
- **标志的开场动画更短。** 在顶栏和“关于”窗口里，现在用 3 秒，而不是 8 秒。

## 修复

- **刷新行和名称行合为一行。** 在任务列表上方，先是刷新，再是“更改记录为 …”，列表因此起得更靠上。

## 其他

- AI 智能体现在在对话中请你批准；`alm confirm` 只用于从 Allomos 应用交给它的任务。

## 新增

- **新任务经批准后再进入就绪队列。** 在「任务袋设置 → 任务」中打开新任务审批开关，代理新建的任务就会留在待办，直到你批准。开关默认关闭。目标运行沿用提交目标时的批准，代理仍可自行将任务设为就绪。也可以在终端用 `alm new-task-settings` 查看或修改此设置。

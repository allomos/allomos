发布于 2026-11-18。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.73)。

## 新功能

- **任务可以按创建时间排序。** 迭代和按领域页面的排序菜单新增“创建时间”，可选最早或最新在前；依赖树中的子任务也按创建时间排列。
- **可以为项目设置文件大小上限。** 在任务包设置 →“文件大小”中可以查看或调整项目源文件的行数上限，默认是 1000 行。命令 \`alm file-size-settings\` 也能查看和更新同一数值。这项设置供项目自己的文件大小检查使用；\`alm\` 不会自动扫描文件。

## 修复

- **修改时间排序下编辑任务，列表不再跳动。** 更改任务状态或难度后，任务行会留在原来的位置。
- **监测会正确识别仍在发送心跳的会话。** 会话仍有心跳时不会被标为久未活动；心跳停止后，按项目设定的失联时间判断。
- **macOS 上的 Antigravity 启动命令过长时，终端不再卡在等待补齐引号的提示。** 自动监测现在通过短暂的脚本运行完整命令。

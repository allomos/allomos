发布于 2026-11-02。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.36)。

## 新增

- **“显示”筛选器的“标签”一栏以“有标签”的“是”和“否”开头。** 取消勾选 **否**，就隐藏没有标签的任务；取消勾选 **是**，就隐藏所有有标签的任务。“有标签”的“是”没勾时，下面各个标签变灰，原来的勾选保留，重新勾上就恢复。没有标签的任务现在只看“有标签”的“否”；各个标签自己的“是”和“否”只管有标签的任务。“全选”、“清除所有选择”和 ↻ 都包括“有标签”，重新打开窗口时也会记住你的选择。

## 其他

- **窗口的标签页不再显示橙色圆点。** 标签页上只有任务包的名字和关闭按钮。

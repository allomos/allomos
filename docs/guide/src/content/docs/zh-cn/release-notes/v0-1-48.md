发布于 2026-11-09。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.48)。

## 新增

- **同时用几个智能体。** 在 **自动监测就绪任务** 里，**智能体** 现在是一组勾选框：可以选一个或多个（不能无人值守运行的智能体会注明原因）。每个所选智能体一次做一个就绪任务，各自开一个会话；每个会话先认领自己的任务，所以不会有两个做同一个。状态栏列出每个会话和它的链接，它的菜单可以加上或去掉智能体：加上的从下次检查起领任务，去掉的做完手上的任务后不再领。**■ 停止**、**↻ 立即检查** 和检查频率对所有智能体都生效。
- **监测会发通知。** 在 macOS 上，任务的会话为你搁置一个问题时，**自动监测就绪任务** 会发一条系统通知；没有就绪任务时也会发一次。
- **难度。** 每个任务都有难度，从 **1 · 很容易** 到 **5 · 很难**，由添加它的智能体判断；没有难度的任务按 3 级算。任务行和任务面板会显示它（默认值显示为灰色），在面板里可以改。用 alm：`alm add task --difficulty <1-5>`、`alm difficulty <id> <1-5>`（或 `--none`），以及 `alm next` / `alm list --difficulty 1-3` 只列出某些级别。较旧的「换肩」会原样保留这个字段。
- **安静模式从不停下来问。** 共享规则（alm 写进 AGENTS.md 的第 v34 节）和各指南现在写明：在安静运行中，措辞和外观由智能体自己决定、做好并合并，每个选择用 `alm ai-decided` 记下供审阅。只有数据格式、删除东西、权限和安全、花费、对外影响和计划改动要先问批准者。问题在做计划时就问；每个搁置的问题都附上智能体的建议；做完的工作先合并，不会被搁置的问题拖住。

## 修复

- **任务面板滚动时顶部保持可见。** 长任务滚动时，面板顶部停在最上面，关闭按钮和返回箭头有清楚的边框。在手机宽度的窗口里，面板占满屏幕高度，长任务也能滚动。

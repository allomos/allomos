发布于 2026-11-11。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.54)。

## 新增

- **更清楚的开始页面。** 开始页面现在把三个选项放进卡片里，一行一个：**新建项目…**、**设置现有项目…** 和 **打开最近的…**。每个选项都有一个图标，名字下面有一句提示，说明它做什么，例如“回到以前打开过的项目。”卡片下面不再放别的按钮，在平常的窗口大小下，整页不用滚动就能看全。

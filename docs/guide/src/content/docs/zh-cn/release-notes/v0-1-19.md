发布于 2026-10-22。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.19)。

## 新增

- **任务面板更好读。** 负责人、智能体、检查和会话各占一行。
- **历史记录写明智能体。** 任务历史里的每次更改都会说明是哪个智能体做的。

## 修复

- **“已完成 X / Y”不再计入已放弃的任务。** 一个领域或迭代里，除一个已放弃的任务外全部完成时，现在显示 25/25，而不是 25/26。

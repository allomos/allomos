发布于 2026-11-16。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.68)。

## 新增

- **监测启动的 Codex 会话现在可以修改项目文件。** 自动启动的会话可以直接修改项目文件，不会为每次修改请求批准，也不会改变你自己的 Codex 设置。

## 修复

- **其他会话认领任务后，监测会释放该任务及其名额。** 任务会从当前监测的进行中列表移除，面板会说明是谁认领了它。
- **心跳说明帮助把尚未共享的改动留在本地。** `alm` 会列出需要保存的文件，并提醒不要在任务库中使用范围过大的 Git 命令。

## 其他

- **Codex 持有任务时，alm 会给出可直接运行的 Git 命令。** 它会写明任务库文件夹路径，不再使用 `git -C`，并提醒逐条运行。

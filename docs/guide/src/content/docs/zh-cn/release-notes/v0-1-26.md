发布于 2026-10-26。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.26)。

## 新增

- **从任务面板打开任务的 Claude Code 会话。** 任务面板的 **会话** 一行现在会说明会话在哪里运行（在 Claude 应用中，或在终端中），并有一个按钮：**在 Claude 中打开** 让 Claude 应用切到那段对话；**在终端中继续** 在认领任务时所在的文件夹打开终端，用 `claude --resume` 接着那段对话。任务释放或完成后，这一行显示 **上一个会话**，按钮照样能用，你可以回到完成这个任务的那段对话。在网页和手机伴侣上，这一行只显示文字。
- **`alm claim` 记下智能体的会话。** 智能体认领任务时可以传入 `--session-agent`、`--session-id`、`--session-kind` 和 `--app-session-id`；任务在释放和完成后仍保留这个会话，新的认领会替换它。没传这些时，认领会提示该传什么。

## 其他

- AI 智能体在认领任务时会被要求传入自己的会话，这样 Allomos 应用就能重新打开它。

发布于 2026-11-09。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.46)。

## 新增

- **心跳。** 持有任务的会话现在会表明自己还在做：`alm beat` 在任务上写一次心跳（不带 ID 时，给这个会话持有的全部任务写），持有者对自己任务的每次改动也顺带写心跳。`alm beat --busy <多久>` 声明一个忙碌窗口，用于没法发心跳的长时间工作。心跳不写事件，燃尽图和时间线不受影响。
- **失联的任务。** 任务列表和任务面板显示每个持有中任务的 **最近心跳**（或 **忙碌到 …**）。持有中的任务超过失联限度没有心跳、也没有未到期的忙碌窗口，就带上琥珀色的 **失联** 标签。`alm next` 把这样的任务列在 *Lost, can be taken over*（失联，可以接手）下，每个都附上接手命令；alm 只列出来，从不自己接手。
- **接手失联的任务。** 对失联的任务运行 `alm claim` 就会接手它，在它原来的工作分支上继续，并记下前一个持有者；没有失联的持有中任务仍会被拒绝。在应用里，失联任务那一行有 **接手…**，它开一个新的 AI 智能体会话来做这件事。前一个会话回来时会被告知任务已被接手，它对那个任务的后续改动会被拒绝。
- **设置 → 心跳。** 任务袋的设置里有 **心跳** 一节：**心跳间隔**（默认 10 分钟）和 **失联限度**（默认 30 分钟），还有 **恢复默认**。用 alm：`alm heartbeat-settings`。
- **关于心跳的共享规则。** alm 写进 AGENTS.md 的共享规则现在要求每个智能体传 `--as`、每 10 分钟发一次心跳、长时间工作时声明 `--busy`、接手失联的任务、自己的任务被接手时停下。`alm guide agent-files` 新增一步：设置自动心跳（智能体自己项目设置里的一个钩子），只在人同意后才做。
- **两个会话同时认领一个任务。** 抢输的会话会被告知任务归谁、它的最近心跳、怎么撤回自己的认领，以及下一个就绪的任务。
- **Claude Code 终端会话的额度。** **自动监测就绪任务** 开的 Claude Code 会话会用 `claude -p /usage` 读自己的额度并报告，顶栏里也有它们的最新数字。

## 修复

- **设置窗口可以滚动。** 长的一节不再压到 **关闭** 下面：左边的分节列表和右边的内容各自滚动，最后几项也能够到。
- **额度弹窗每个智能体、账号和时间窗只显示一行。** 刷新后旧的行不再留在新行旁边，新的报告会替换掉旧会话名下存的报告。

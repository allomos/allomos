发布于 2026-11-09。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.45)。

## 新增

- **只有一个设置窗口。** 应用的设置窗口和每个任务袋的设置合成了项目窗口里的一个对话框。左边分两组：**Allomos**（**通用**、**本机身份**），影响这台电脑上的整个应用；以及以当前标签页任务袋命名的一组（**通用**、**项目文件夹**、**智能体**、**任务**、**交接**、**审计**），分享给所有用这个任务袋的人。每一节最上面一行写明它属于哪一组。菜单里的 **设置…**（Cmd+, / Ctrl+,）打开 Allomos 组；任务袋名称旁的 **设置** 打开任务袋那一组。
- **可以关掉自动更新。** 设置 → Allomos → 通用 → **自动更新**，默认打开。关掉后，「换肩」不再自己向 GitHub 检查新版本，也不在后台下载；菜单里的 **检查更新…** 仍然可以用。
- **外部时间戳见证可以打开了。** 设置 → 你的任务袋 → 审计 → **外部时间戳见证**。点 **打开并发送指纹** 确认后，每个检查点的指纹（从不发任务袋的内容）都会发给一个时间戳服务（RFC 3161），它回签的回执存在检查点里。默认是 FreeTSA；列表里还有 DigiCert、Sectigo 和 GlobalSign，也可以填你们服务商的地址，并可选第二个服务。`alm audit` 逐份核对回执与检查点是否相符，并列出一年内到期的回执。没网时指纹先存着，随之后的检查点发出。用 alm：`alm audit-settings --witness on|off`。
- **见证多久做一次检查点。** 外部时间戳见证 → **多久一次**：**每天**（打开时默认选它）、**每次批准和人工检查时**，或 **只在我要求时**。用 alm：`alm audit-settings --witness-when`。
- **审计和标准。** 用户指南新增[一页](/allomos/zh-cn/audit/standards-map/)，说明「换肩」一直记录什么、每个审计设置做什么，以及要有助于满足 ISO/IEC 27001、SOC 2、等保 2.0 等标准各要打开哪几项。审计设置里的 **查看标准对照表：各标准要打开哪几项** 按窗口的语言打开这一页。
- **Google Antigravity。** 「换肩」能找到 Antigravity 的 `agy` 命令，列为 **Antigravity（终端）**：可以请它设置共享规则，**自动监测就绪任务** 可以开 agy 会话，记在 Antigravity 名下的会话用 `agy --conversation` 重新打开，Antigravity 的额度显示在顶栏里。

## 修复

- **遗留的被阻塞任务也会接着走。** 阻塞它的任务在 0.1.44 之前就都已结束的任务，原来一直停在阻塞。现在 `alm next`、开始 **自动监测就绪任务** 和 **↻ 立即检查** 都会让这样的任务接着走，监测会在状态栏下面用一行说明是哪些任务。

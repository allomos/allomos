发布于 2026-11-17。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.72)。

## 新功能

- **安静模式的 Antigravity 会话推送自己的分支不再询问。** 监测以安静模式启动的 Antigravity 会话，向 `origin` 做写全分支名的普通推送（例如 `git push origin refs/heads/main`）时不再停下来。其他推送（不带参数的 `git push`、`git push origin main`、带额外选项、强制推送、删除远端分支、推送 tag、组合命令）仍会询问。普通会话和你的 Antigravity 设置不变。

## 修复

- **状态和难度菜单不再被挡住。** 在迭代或领域的最后一个任务上，这两个菜单以前会被列表底部遮住；现在它们浮在列表之上，下方空间不够时向上展开。
- **安静模式的说明不再声称 auto 模式从不停顿。** 现在写明 Antigravity 的 auto 模式在有风险或无法撤销的操作前（例如推送共享分支）仍会请求确认。

发布于 2026-11-17。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.70)。

## 新增

- **新的「待你处理」窗口列出等你处理的任务。** 从主窗口右上角带数量的「待你处理」按钮，或菜单「显示 → 待你处理」（⇧⌘Y）打开。左边按顺序列出要你检查、回答和审阅的任务；右边先说要你做什么，再显示这个任务。处理完的一条会离开清单，并自动选中下一条。
- **监测面板里的任务名可以点开详情。** 在监测开的会话下点任务名，就会在详情面板里显示这个任务；「打开会话」仍然打开对应的会话。

## 其他

- **应用和 `alm` 的内部做了整理。** 代码拆成了更小的部分，你用到的功能没有变化。

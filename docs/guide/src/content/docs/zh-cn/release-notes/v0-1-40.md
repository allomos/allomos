发布于 2026-11-07。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.40)。

## 新增

- **自动监测就绪任务。** 在桌面应用里，**▶ 自动监测就绪任务**（在顶栏，以及当前迭代的卡片上）让 Allomos 在你不在时处理就绪任务：它为每个就绪任务在终端里新开一个智能体会话，一次一个，上一个做完才开始下一个。没有就绪任务时，它按你选的频率等待并再次检查。你可以选处理哪些任务（当前迭代、全部就绪任务或某一个迭代）、用哪个智能体（**Claude Code（终端）** 或 **Codex（终端）**）以及运行模式。运行时，一条状态栏显示正在处理的任务，并提供 **↻ 立即检查**、检查频率和 **■ 停止**（在当前任务做完后结束）。对话框会说明怎样让所选智能体运行时不停下来请求权限；Allomos 从不更改智能体的权限。Claude 应用、Codex 应用和手动暂时不能选，对话框会说明原因。

## 其他

- **「接着做…」改名为「执行…」。** 没有会话持有的任务上的按钮及其对话框（**交给 AI 智能体执行**）使用新名称，作用不变。
- **恢复的标签页在切换过去时才加载。** Allomos 重新启动时，会恢复你打开过的所有任务袋标签页，但只加载在前面的那个。其他标签页显示保存的项目名，第一次切换过去时才加载，因此启动更快。

发布于 2026-11-10。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.52)。

## 修复

- **「与智能体连接」只请求 Allomos 的说明。** 连接智能体时，Allomos 现在只请它把 Allomos 的说明添加到其说明文件（AGENTS.md 和 CLAUDE.md）中。它不再请智能体查找已有任务、迁入较旧的任务库或更新过时的文件；这些工作仍在 **更新任务库…** 中进行。「连接」面板也不再显示查找任务的一行。
- **智能体一行总是显示 Antigravity。** 智能体一行现在会在 Codex 之后列出 Antigravity，与 Claude Code 和 Codex 一样，即使 Antigravity 还没有报告任何内容也会显示。

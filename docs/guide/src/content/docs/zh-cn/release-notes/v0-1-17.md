发布于 2026-10-22。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.17)。

## 新增

- **“按领域”标签页也有排序菜单。** 它会给每个领域里的任务排序，并且两个标签页共用同一个选择，只需设置一次。
- **最近更改的任务排在最前。** 在你选择排序之前，任务列表把最近更改的任务放在最上面。
- **新窗口以合适的大小打开。** 窗口约占所在屏幕宽度的 80 %、高度的 85 %（在 720 × 480 到 1280 × 900 之间），并居中显示。

## 修复

- **开始页在任何窗口里都显得均衡。** 卡片撑满高度，内容居中，四周留白均为 20 px；窗口很高时不再继续拉伸。
- **调整窗口大小时，任务面板保持原来的比例。** 它的宽度按“列表加面板”区域的比例记住，而不是固定的像素数。

发布于 2026-11-12。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.59)。

## 新增

- **运行中的监视器在一个对话框里编辑。** 它的 **编辑监视器…** 对话框也能修改监视器的范围和模式。自动监视器区域里，每个监视器是一个可以折叠的面板。`alm monitor set` 也能在命令行以同样方式修改监视器。
- **监视器运行时可以再开一个。** 监视器运行时，它的按钮显示 **再开一个监视器…**，而不是 **启动**。

## 修复

- **接手会保留未推送的工作。** 接手时，可以先把原工作区尚未推送的内容提交并推送，什么都不会丢。

## 其他

- 决策 0023 记录了 Allomos 可以完全自动地编排智能体；计划里不再把这一点列为非目标。

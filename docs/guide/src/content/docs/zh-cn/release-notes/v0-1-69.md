发布于 2026-11-17。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.69)。

## 新增

- **安静模式监测启动的 Codex 可以直接工作。** 它可以修改项目文件、访问网络并操作这台 Mac 上的 Allomos。设置只对 Allomos 启动的这个会话生效，不会改动你自己的 Codex 设置。
- **在任务详情里打开阻塞任务。** 点击链接中的任务编号，就能在同一个任务面板里查看该任务。

## 修复

- **监测会处理额度耗尽的情况。** 启动会话前会先检查额度；额度不足时，任务仍保持就绪，面板显示下次检查时间，额度恢复后自动重试。
- **没有认领任务的会话不会一直显示为正在做。** 10 分钟内没有认领时，监测会把它标记为未开成；能读到原因时会显示原因，并释放名额、重新派发任务。
- **新会话在认领任务前会显示为正在启动。** 面板不会再提前显示任务已经开始处理。

## 其他

- **监测面板和状态报告会显示一致的会话状态。** 暂停、正在启动和未开成的会话会提供相同的信息。

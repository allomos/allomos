发布于 2026-11-08。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.42)。

## 新增

- **应用按新的方式显示标签。** 任务列表和任务面板把任务上的每个标签显示成一个小块，两个 “by human” 标签是实心的。在任务面板里，**标签 → 修改** 列出项目标签表里的每个标签，勾上或去掉即可。**已检查** 加上 **locally verified by human**；如果智能体已经部署并验证过这个任务，则加 **deployed and verified by human**，按钮下的说明写出会加哪一个。**设置 → 任务 → 标签** 显示五个内置标签和各自的意思，下面是项目自己的标签，可以改名、添加或移除。旧的“进度阶梯”设置去掉了，因为标签没有先后。
- **“显示”筛选是一张表格。** 任务列表上方的 **显示** 打开一张表：每个状态一行，行按状态的颜色淡淡着色。各栏是 **人已检查**（任一个 “by human” 标签），然后是其他每个标签，每栏有“是”和“否”。任务符合它所在状态那一行的任一勾选，就显示。状态前的勾汇总这一行（全勾、部分勾或都没勾），点它可以整行勾上或去掉。默认全勾，列出全部任务。
- **“常用”预设和“需要你”。** “显示”筛选有两个标签页：**常用** 和 **自定义**（就是那张表格）。预设有：全部任务、没做完的、可以开始的、正在做的、需要你、结束了的；每个写出它勾哪些、现在列出几个任务。**需要你** 列出的任务和 `alm human` 一样：人还没检查的已完成任务、所有等待中的任务，以及有 AI 决定待审阅的任务。预设只是把“自定义”里的勾选设好；在那里改了任何一项，就不再是这个预设。自动监测运行后如果有需要你的事，**自动监测就绪任务** 旁的那一行最后写着“K 个需要你”，点它就选“需要你”。

## 修复

- **打开“显示”筛选不再让窗口卡死。** 在 0.1.41 里，对格式为 `allomos/7` 的任务包打开 **显示**，窗口会变成空白、不再响应，只能退出「换肩」再打开。现在面板立即展开。
- **每个内置标签都有意思。** 任务包升级到 `allomos/7` 后，有三个内置标签在 `alm labels` 和标签表里可能没有意思。现在它们显示内置的意思。

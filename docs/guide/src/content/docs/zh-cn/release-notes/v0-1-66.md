发布于 2026-11-16。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.66)。

## 新增

- **改一个任务后更新得更快。** 改任务的状态、标题、说明或其他内容时，「换肩」会就地更新这个任务和受影响的部分。在本项目的任务包里，一次改动现在约需四分之一秒，原来约需两秒。

## 修复

- **自动监测就绪任务的 agent 选项更容易找到。** 选中某个 agent 后，它的提示和选项现在紧挨着显示在该 agent 的下面；没选中时不会显示。

## 其他

- Git 现在忽略本机的 Claude 工作区文件。

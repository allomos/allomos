发布于 2026-11-10。[在 GitHub 下载](https://github.com/allomos/allomos/releases/tag/v0.1.50)。

## 新增

- **重启后监测接着进行。** 应用重启或更新后（或运行中断后重新打开项目），**自动监测就绪任务** 会按保存在这台电脑上的设定自动接着进行，不用再按开始。还在做的会话照常显示在状态栏里，做完后的 30 秒关标签页倒计时照常走完，应用关闭期间结束的运行也会计入「上次运行」摘要。
- **同一个智能体在监测中可以用多个账号。** 在 **自动监测就绪任务** 中，可以为 Claude Code 和 Codex 添加额外账号。每个账号是单独的一行，各自设会话数和难度范围，并用该账号的文件夹启动会话。
- **监测运行中重启或退出前先提醒。** 监测正在运行时点「重新启动以更新」或退出应用，会先弹出提醒：说明自动监测会在后台继续运行、已开的多少个会话会照常做完，并可以取消。
- **连接 Antigravity 时直接把请求传给 `agy`。** 连接 Google Antigravity 时，请求现在通过命令行直接传给 `agy`，不再经剪贴板粘贴。

## 修复

- **不可点的「开始」按钮显示为灰色。** 在 **自动监测就绪任务** 中，没有选中任何智能体时，**开始** 按钮（以及其他禁用的主按钮）显示为灰色。

## 其他

- **正在运行的监测** 从窗口菜单移到了视图菜单，正在运行的监测对话框底部不再显示说明文字。

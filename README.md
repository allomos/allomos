# Allomos

**Switch between AI agents and teammates, and keep the project.** When one AI coding agent or account runs out (Claude Code, Codex, …), another picks up where it stopped; when the work passes to a teammate, the tasks and handoff notes go with it. The project lives in a *taskbag* of plain files in its own repository. Two more sets build on it: **AI skills** (getting better at working with agents) and **progress management** (progress by area, a burndown with a forecast finish date, on desktop, browser and phone). Local projects need no sign-in; cloud projects add live teamwork. See [decision 0014](docs/decisions/0014-main-purpose-and-three-sets.md).

**Status:** Iteration 1 in progress: a macOS desktop app that opens a taskbag and shows its tasks by area. How to run it: [docs/workflow/CODING_RULES.md § Running the app](docs/workflow/CODING_RULES.md#running-the-app).

# 肩代 Allomos

**エージェントもチームメイトも替えられる。プロジェクトはすべて記録に。**

ある AI エージェントやアカウントの使用量が尽きたら、別のエージェントが止まったところから続けます。タスク、その状態、引き継ぎメモは、チャットに散らばらず一か所に書き残されます。プロジェクトの**タスクバッグ**、あなた自身のリポジトリにある、ただのファイルです。

## 課題：バイブコーディングの経緯は、無数のチャットに散らばる

一つのプロジェクトはたくさんのセッションを通ります。Claude Code、Codex、いくつものアカウント、何人もの人。使用量の上限で予告なくセッションが終わり、次のセッションはゼロから始まります。決めたことは古い会話の中に、プロジェクトの状況は手で書いた Markdown と人の頭の中にあります。実際のマルチエージェントの移行プロジェクト（2026 年 9 月）では：

- 新しいセッションが再開のたびに読み直す **185 KB** の引き継ぎメモ
- 一枚のカードの状況を手で写していた場所が **6** か所
- 同時にカードを取り合う **3** つのセッション、決着はマージの衝突
- 「いつ終わるのか」に答えられた人は **0** 人

## 「肩代」がすること：四つの特長

| | 何のためか | |
|---|---|---|
| **切り替え** | AI エージェント（とアカウント）の間、チームメイトの間でプロジェクトを渡し、止まったところから続ける。 | どのエージェントにも同じコマンド · 引き継ぎも再開も一歩で · チームメイトにプロジェクトを渡す |
| **タスク管理** | バイブコーディングの過程をすべて記録に：タスクとその状態を、チャットに散らさず一か所に。 | 人の目で確かめやすい · 開発中も、何年先の保守も楽 |
| **AI スキル** *（開発中）* | エージェントと、だんだん上手に働く。 | エージェントごとに知る · きれいに切り替える · バイブコーディングの進め方 · 成果を良くする |
| **進捗管理** *（開発中）* | プロジェクトがどこまで進み、いつ終わるかを見る。 | エリアごとの進捗 · あなたを待っていること · バーンダウンと完了日 · デスクトップ、ブラウザー、スマートフォン |

四つとも同じタスクバッグで動きます。

### AI エージェントの間で切り替える：Claude が尽きたら、Codex が続ける

- **どのエージェントにも同じコマンド。** Claude Code、Codex などが `alm` コマンドでタスクを取り、更新し、手放します（MCP *（予定、v0.3）*）。
- **再開は一歩で。** 新しいセッションは次のタスクを尋ねるだけで、その段階と最後の引き継ぎメモを受け取ります。
- **セッションを始める・開き直す。** タスクから、選んだエージェントでそのまま *（予定、v0.8）*。

```text
# Claude Code · アカウント 1 · 使用量がもうすぐ尽きる
alm label A01-03 "implemented"
alm release A01-03 --note "form done; tests next"

# Codex · アカウント 2 · 1 分後
alm next
A01-03  Sign-in page  ready · note: tests next
alm claim A01-03
```

### チームメイトの間で切り替える：渡すのはメモの山ではなく、プロジェクト

同じタスクバッグが、仕事をあなたからチームメイトへ、そしてまた戻します。それぞれが自分のエージェントを使い、全員が同じタスクを見ます。どのタスクも、**誰が持っているか**（人か、エージェントのセッション）、**確かめた段階**（実装済み … 人が確認済み）、**何を待っているか**、そして**引き継ぎメモ**を連れて動きます。共有リポジトリなら、タスクバッグは Git と一緒に無料で動きます。クラウドのプロジェクトでは、リアルタイムの共有、メールでの招待、役割が加わります *（予定）*。

### タスク管理：チャットに隠れるものはない

タスクは `.allomos/taskbag/` にある読めるファイルで、あなた自身の Git でバージョン管理されます。一つのエージェントの記憶や一つのアカウントには閉じ込められません。タスクバッグに残るもの：

- **すべてのタスクとその状態**（準備済み、進行中、待ち、ブロック、完了）を一か所に。担当は常に一人。
- **確かめた段階**：各タスクははしごを上ります（実装済み → ローカルで確認 → デプロイして確認 → 人が確認）。進捗は主張ではなく証拠で示します。
- **引き継ぎメモと AI 自身の判断**：何をしたか、次は何か、エージェントが下した日常の判断のすべて。あとから見直せます。
- **あなた宛ての一覧**：あなたの確認、回答、レビューを待つものを一つのリストに。

何か月後かにあなたや新しいチームメイトがコードに戻ってきても、変更ごとの理由がそこに残っています。

### AI スキル：エージェントともっと上手に働く *（開発中）*

Claude Code と Codex それぞれの得意なことと、プロジェクトに合わせた設定の仕方。タスクを別のエージェントやアカウントに移すときに渡すもの。バイブコーディングの進め方（一つの成果に一枚のカード、セッションごとの作業コピー、段階ごとの確認、何かがあなたのマシンを出る前のあなたの承認）。タスクごとのモデルと推論の強さの選び方。のちには、エージェントがプロジェクト全体を下書きし、「肩代」が確認とプレビューをしてから、あなたが採用を決められるようにします。

### 進捗管理：どこまで進み、いつ着くか *（開発中、v0.4〜v0.10）*

エリアごとの進捗と、各タスクの確かめた段階。あなたにしか決められないことを、根拠と一緒に。実際のペースから出す完了日：50% の見込みで間に合う日と、85% の見込みで間に合う日。机でも、ブラウザーでも、スマートフォンでも、デスクトップのアプリにつないで見られます。

## 料金：手元では無料、払うのはクラウドだけ

| ローカルアプリ：**無料** | クラウド：**任意** |
|---|---|
| アカウント不要 · カード不要 · 試用期限なし | 欲しいときだけ · 料金は後日発表 |
| AI エージェントとアカウントの間で切り替え、コマンドラインで（MCP は予定） | チームメイトとリアルタイムに切り替え：どのコンピューターにもクラウドのコピー |
| macOS と Windows のデスクトップアプリ | チームのサインイン、メールでの招待、役割 |
| あなた自身のリポジトリにあるローカルのプロジェクト | リアルタイムの共同作業と、編集の自動マージ |
| バーンダウン、完了予測、自宅でのスマートフォンとブラウザー | |

あなたが共有を選ばない限り、データは手元に残ります。

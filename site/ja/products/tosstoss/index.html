投桃 Tosstoss

投桃（Tosstoss）はブラウザだけで端末間のファイルをやり取りできます。ページを開いた端末はお互いに自動で表示され、相手を選び、ファイルを選ぶかドロップして「送信」を押すと、相手は自動で受け取ります。スマホのブラウザでも使えます。

投桃を開く GitHub のソース
対応: Web · どのブラウザでも  ·  ライセンス: MIT

インストール不要

PC とスマホで同じページを開くだけ。同じネットワークの端末は自動で見つかり、「やさしいレモン」のような覚えやすい名前が付きます。

自動で受信

ファイルは相手が何もしなくても届いてダウンロードされます。進捗は双方に表示され、大きなファイルも送れます。

できれば直接接続

まず WebRTC で直接つなぎ、つながらなければサーバが中継します。ファイルは保存されません。

ルームと広場

ルームのリンクや QR コードを共有すれば別のネットワーク間でも送れます。広場に参加することも、いつでもオフラインにすることもできます。

自分で動かす

自分の PC で npm start すれば家の LAN 用に、Cloudflare Workers にデプロイもできます。

使い方

同じ Wi-Fi の 2 台で tosstoss.allomos.com を開いてください。自分の LAN で動かすには Node.js 18 以降を入れ、ソースフォルダで npm install と npm start を実行し、表示されたアドレスを開きます。

作られた経緯を読む

23 分で投桃（Tosstoss）ができるまで (中国語) — 作りたいアプリを一段落で書き、Allomos で「開始」、Claude で Enter を一回。Claude は 2 つのバージョン・9 つのタスクに分けて順に仕上げ、深夜にはスマホから PC へスクリーンショットを送れました。

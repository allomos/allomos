Tatakikun

Tatakikun は、英字で入力した文字列を英単語・中国語のピンイン・日本語のローマ字として同時に解釈し、英語・中国語・ひらがな・カタカナ・漢字の候補を 1 本の横長の候補バーに並べます。入力したままの英字列も、常に候補のひとつです。

インストーラをダウンロード GitHub のソース
対応: macOS  ·  ライセンス: MIT

3 言語を 1 本のバーに

ai と打てば 爱・愛・あい・アイ・ai がいっしょに出ます。一致した言語の最良候補は必ずバーに残ります。

下に広げてスクロール

↓ か Tab で複数行に展開。部分一致の候補も出ます：zhongg → 中国、compu → computer。

学習します

選んだ候補は次から上位に。学習内容はこの Mac の 1 ファイルだけに保存され、消せばリセットされます。

言語に合う句読点

中国語・日本語のあとは全角、英語のあとは半角になります。

子音だけの省略入力

子音だけでも候補が出ます：nh → 你好、wtx → わたし。

言語パック

インストール時に中国語・日本語・英語のパックを選べます。辞書はオープンデータ（pinyin-data、Mozc、SCOWL）から作ります。

インストール

インストーラを開き、使う言語パックにチェックを入れます。そのあと一度だけ追加します：システム設定 → キーボード → テキスト入力 → 入力ソース → 編集… → + → 中国語（簡体字）→ Tatakikun。Apple の Developer ID 署名がないため、初回は システム設定 → プライバシーとセキュリティ でこのまま開くをクリックしてください。

作られた経緯を読む

29 分で英中日の入力メソッドができるまで (中国語) — 2 回目の実験：一段落の説明だけで、Claude が Allomos のタスク管理を使って、英語・中国語・日本語の候補を並べて出す macOS 入力メソッドを作りました。犬の散歩と皿洗いから戻ると、3 つのバージョンができていました。

Ticker

Ticker はブラウザで使う株のウォッチリストです。株、ETF、為替、暗号資産を検索して、自分だけのリストにいくつでも入れられ、どの銘柄も開けば価格、チャート、主な指標が見られます。ログインはメールで届くリンクから。覚えるパスワードはありません。

Ticker を開く GitHub のソース
プラットフォーム：Web · どのブラウザでも  ·  ライセンス：MIT

なんでも検索

株、ETF、通貨ペア、暗号資産を名前かシンボルで探し、そのままリストに追加できます。

複数の非公開リスト

保有銘柄、気になる銘柄など、リストをいくつでも作り、名前や順番を変えられます。見えるのは自分だけです。

銘柄ごとのページ

最新の価格と騰落、1 日から全期間までのチャート、主な指標。

メールでログイン

リンクを頼み、開いて、ボタンを押すだけ。リンクは 15 分以内に一度だけ使え、ログインは 30 日続きます。

自分で動かす

Cloudflare Workers と D1 データベースで動きます。ソースとデプロイ方法は GitHub にあります。

価格について

Ticker は市場データサービス Twelve Data の無料プランを使っています。このプランの対象は米国株と米国 ETF、為替、暗号資産で、価格は遅延しておりリアルタイムではありません。1 分あたり数回のリクエストを Ticker の利用者全員で分け合うため、価格はしばらく保存して使い回します。上限に達したときは手元の最新の価格を表示し、古い可能性があることを示します。ウォッチリストであって、売買のためのツールではありません。

作られた経緯

投桃（Tosstoss）や Tatakikun と同じく、Ticker も AI エージェントが「肩代」を通してタスクを一つずつ進めて作りました。その一歩一歩はリポジトリに記録されています。

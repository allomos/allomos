バイブコーディングの経緯は、無数のチャットに散らばる

一つのプロジェクトはたくさんのセッションを通ります。Claude Code、Codex、いくつものアカウント、何人もの人。使用量の上限で予告なくセッションが終わり、次はゼロから始まります。決めたことは古い会話の中にしか残りません。実際のマルチエージェントのプロジェクトでは：

  • 新しいセッションが再開のたびに読み直す 185 KB の引き継ぎメモ
  • 一つのタスクの状況を手で写していた場所が 6 か所
  • 同時にタスクを取り合う 3 つのセッション、決着はマージの衝突
  • 「いつ終わるのか」に答えられた人は 0 人

タスク管理：チャットに隠れるものはない

タスクは .allomos/taskbag/ にある読めるファイルで、あなた自身の Git でバージョン管理されます。一つのエージェントの記憶や一つのアカウントには閉じ込められません。タスクバッグに残るもの：

  • すべてのタスクとその状態——準備済み、進行中、待ち、ブロック、完了——を一か所に。担当は常に一人（または一つのエージェント）。
  • 確かめた段階——各タスクははしごを上ります（実装済み → ローカルで確認 → デプロイ済み → 人が確認）。進捗は主張ではなく証拠で示します。
  • 引き継ぎメモと AI 自身の判断——何をしたか、次は何か、エージェントが下した日常の判断のすべて。あとから見直せます。
  • あなた宛ての一覧——あなたの確認、回答、レビューを待つものを一つのリストに。

何か月後かにあなたや新しいチームメイトがコードに戻ってきても、変更ごとの理由がそこに残っています。

エージェントとの協力は技術で、積み重なっていきます。肩代は、エージェントごとの得意なこと、切り替えで渡すべきこと、そしてシンプルな進め方——一つの成果に一つのタスク、段階ごとの確認、何かがあなたのマシンを出る前のあなたの承認——を身につける手助けをし、プロジェクトのたびに前よりうまく進むようにします。

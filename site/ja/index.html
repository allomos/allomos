エージェントを替えても、
チームメイトに渡しても、
プロジェクトは途切れない。

ある AI エージェントやアカウントの使用量が尽きたら、別のエージェントが止まったところから続けます。仕事をチームメイトに渡しても、チャットの中に置き去りになるものはありません。プロジェクトはタスクバッグに入って移動します。あなた自身のリポジトリにある、ただのファイルです。

手が替わるたびに、流れが途切れる

バイブコーディングはたくさんのセッションで進みます。Claude Code、Codex、いくつものアカウント、何人もの人。使用量の上限で予告なくセッションが終わり、次のセッションはゼロから始まります。実際のマルチエージェントのプロジェクトでは：

  • 新しいセッションが再開のたびに読み直す 185 KB の引き継ぎメモ
  • 一枚のカードの状況を手で写していた場所が 6 か所
  • 同時にカードを取り合う 3 つのセッション、決着はマージの衝突
  • 「いつ終わるのか」に答えられた人は 0 人

一つの本題と、それを支える二つ

切り替え

エージェントとチームメイト

AI エージェントとチームメイトの間でプロジェクトを渡し、何も失いません。どのエージェントにも同じ alm コマンド。引き継ぎも再開も一歩で。

AI スキル

エージェントともっと上手に

エージェントごとの得意なこと、切り替えで渡すもの、そして進め方：一つの成果に一枚のカード、段階ごとの確認、何かがあなたのマシンを出る前のあなたの承認。

進捗管理

どこまで進み、いつ着くか

エリアごとの進捗、あなたを待っていること、実際のペースから完了日を見込むバーンダウン。（予定）

Claude が尽きたら、Codex が続ける

タスク、確かめた段階、引き継ぎメモは .allomos/taskbag/ の読めるファイルで、あなた自身の Git でバージョン管理されます。一つのエージェントの記憶や一つのアカウントの中には閉じ込められません。

# Claude Code · アカウント 1 · 使用量がもうすぐ尽きる
alm label A01-03 "implemented"
alm release A01-03 --note "form done; tests next"

# Codex · アカウント 2 · 1 分後
alm next
A01-03  Sign-in page  ready · note: tests next
alm claim A01-03

これから作る予測機能のイメージで、実際のデータではありません。

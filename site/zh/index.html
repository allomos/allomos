每换一次手，线索就断一次

Vibe Coding 靠很多会话一起推进：Claude Code、Codex、好几个账号、好几个人。额度可能毫无预警地让会话中断，下一个会话只能从零开始。在一个真实的多智能体项目里：

  • 185 KB 的交接笔记，每个新会话接手都得从头读一遍；
  • 6 个地方要手工同步同一张任务卡的状态；
  • 3 个会话同时抢任务，最后靠 Git 合并冲突来裁决；
  • 0 人能回答“到底什么时候能做完？”

一条主线，两组助力

切换

智能体和队友

在 AI 智能体和队友之间来回切换，项目一点不丢。所有智能体用同一套 alm 命令；一步交接，一步接手。

AI 技能

和智能体合作，越做越好

了解每个智能体擅长什么，切换时该交接什么，把流程跑顺：一个成果一张任务卡，一级一级地验证，任何东西离开你的电脑前都要你同意。

进度管理

走到哪了，何时落地

按领域看进度，列出等你处理的事项，燃尽图按真实速度给出预计交付日期。（计划中）

Claude 额度用完，Codex 接着干

任务、验证阶段和交接笔记都是 .allomos/taskbag/ 下的普通文本文件，用你自己的 Git 管理版本，不锁在某个智能体的记忆或某个账号里。

# Claude Code · 账号 1 · 额度快用完
alm label A01-03 "implemented"
alm release A01-03 --note "form done; tests next"

# Codex · 账号 2 · 一分钟后
alm next
A01-03  Sign-in page  ready · note: tests next
alm claim A01-03

这是将来预测功能的示意图，不是真实数据。

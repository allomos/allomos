Ticker

Ticker 是在浏览器里用的股票自选列表。搜索股票、ETF、外汇和加密货币，放进任意多个只有你能看到的列表，点开任何一个代码看价格、走势图和关键数据。登录用邮件里的链接，不用记密码。

打开 Ticker GitHub 上的源码
平台：网页 · 任何浏览器  ·  许可证：MIT

什么都能搜

按名称或代码找股票、ETF、货币对或币种，一步加进列表。

多个私人列表

持仓、关注，或者别的什么，各建一个列表；可以改名、调整顺序。只有你自己能看到。

每个代码一页

最新价格和涨跌，从一天到全部历史的走势图，还有关键数据。

邮件登录

要一个链接，打开它，按一下按钮。链接只能用一次，15 分钟内有效；登录状态保持 30 天。

自己部署

运行在 Cloudflare Workers 和 D1 数据库上；源码和部署方法都在 GitHub 上。

关于价格

Ticker 用的是行情数据服务 Twelve Data 的免费套餐。这个套餐覆盖美股和美国 ETF、外汇和加密货币，价格有延迟，不是实时的。每分钟只有几次请求，由所有 Ticker 用户共用，所以价格会保存一段时间重复使用；额度用完时，Ticker 显示手上最新的价格，并提示它可能不是最新。它是自选列表，不是交易工具。

它是怎么做出来的

和投桃、Tatakikun 一样，Ticker 是 AI 智能体通过「换肩」一个任务一个任务做出来的，每一步都记录在它的代码仓库里。

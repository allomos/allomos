投桃 Tosstoss

投桃在浏览器里就能在设备之间互传文件。打开这个网页的设备会自动互相看到；勾选对方、选择或拖放文件、点“发送”，对方自动接收。电脑和手机浏览器都能用。

打开投桃 GitHub 上的源码
平台: 网页 · 任何浏览器  ·  许可证: MIT

什么都不用装

电脑和手机打开同一个网页即可。同一网络里的设备自动互相发现，每台都有一个好认的名字，比如“温柔的柠檬”。

自动接收

文件到了自动下载，对方不用点。双方都能看到进度，大文件也能传完。

能直连就直连

先尝试 WebRTC 直连；连不上就经服务器中转，文件不落盘。

房间和广场

分享房间链接或二维码，不同网络之间也能传；也可以去广场，或者随时下线。

自己部署

在自己的电脑上 npm start 就是家里局域网的版本，也可以部署到 Cloudflare Workers。

使用

在同一个 Wi-Fi 下的两台设备上打开 tosstoss.allomos.com。想在自己的局域网里运行：装好 Node.js 18 或更新版本，在源码文件夹里运行 npm install 和 npm start，打开终端打印的网址。

读它是怎么做出来的

二十三分钟，做出一个投桃 — 写一段话描述想要的应用，在换肩里点“开始”，再在 Claude 里按一次回车。Claude 自己拆成两个版本、九个任务，一个接一个做完；午夜过后，我用手机把一张截图发到了电脑上。

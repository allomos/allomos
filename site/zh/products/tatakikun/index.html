Tatakikun

Tatakikun 把你用英文字母键入的内容同时当作英文单词、汉语拼音和日文罗马字来理解，英文、中文、平假名、片假名和日文汉字候选并排显示在一条横向候选条里。键入的原始字母串始终是候选之一。

下载安装器 GitHub 上的源码
平台: macOS  ·  许可证: MIT

三种语言，一条候选条

键入 ai，爱、愛、あい、アイ、ai 一起出现；每种匹配到的语言的最佳候选都保证在候选条里。

向下展开，可以滚动

按 ↓ 或 Tab 展开成多行，包括不完全匹配的候选：zhongg → 中国，compu → computer。

会学习

选过的候选下次排得更前。学到的内容只存在这台 Mac 上的一个文件里，删掉即可清除。

标点跟着语言走

中文、日文后面用全角标点，英文后面用半角。

首字母缩写

只打辅音也能出词：nh → 你好，wtx → わたし。

语言包

安装时勾选中文、日文、英文语言包，词库来自开源数据（pinyin-data、Mozc、SCOWL）。

安装

打开安装器，在“自定”页勾选要装的语言包；然后添加一次：系统设置 → 键盘 → 文字输入 → 输入法 → 编辑… → + → 简体中文 → Tatakikun。安装包没有 Apple 开发者签名，第一次打开会被拦下：到 系统设置 → 隐私与安全性，点仍要打开。

读它是怎么做出来的

二十九分钟，做出一个英中日输入法 — 第二次实验：只给一段描述，让 Claude 借着换肩的任务管理做一个 macOS 输入法，英文、中文、日文候选并排出现。我去遛狗、洗碗，回来时三个版本已经做完。

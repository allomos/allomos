Tosstoss

Tosstoss sends files between devices straight from the browser. Every device that opens the page shows up for the others; tick one, choose or drop files, press send, and the other side receives them on its own. It works on phones too.

Open Tosstoss Source on GitHub
Platform: Web · any browser  ·  Licence: MIT

Nothing to install

Open the page on your computer and your phone. Devices on the same network find each other, each with a friendly name like “gentle lemon”.

Received on its own

Files arrive and download without anyone clicking. Both sides see the progress, and large files make it through.

Direct when it can

Devices try a direct WebRTC connection first; if that fails, the server relays the file without storing it.

Rooms and the square

Share a room link or QR code to send between networks, or meet in the open square; or go offline whenever you like.

Run your own

Run it on your own computer for your home network with npm start, or deploy it to Cloudflare Workers.

Use it

Open tosstoss.allomos.com on two devices on the same Wi-Fi. To run it on your own network, install Node.js 18 or newer and run npm install and npm start in the source folder; open the address it prints.
